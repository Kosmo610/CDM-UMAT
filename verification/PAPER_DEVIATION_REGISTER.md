## 1. 구성방정식 (Constitutive model)

### 1.1 기지 인장 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.15: von Mises 등가 유효응력 / X_m,t , 조건 I₁ ≥ 0 |
| V2_4 이하 | 최대주응력(Rankine) / X_m,t , I₁ 게이트 없음 |
| V2_5 이후 | `PROPS(24)=MCRIT=1` 로 논문 Eq.15 그대로 구현 |
| 잔여 차이 | 논문은 I₁=0 에서 하드 스위치. 구현은 ±BAND(=0.1·Xc) 완만 램프 |

램프를 쓴 이유: I₁=0 하드 스위치는 구성방정식의 불연속이며, 실제로
V2_3 에서 260.2 °C 발산의 원인이었다. BAND→0 이면 논문과 일치한다.

**미확인**: 이 변경이 손상량을 늘리는지 줄이는지 아직 실측 안 됨.
냉각 직후 기지는 Mises 170.4 / MaxPrin 201.9 로 **Mises 가 더 작아서**
인장 손상이 오히려 줄어들 가능성이 있다. `23C_PAPERCRIT` 덱으로 판정 예정.

### 1.2 기지 압축 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.16: von Mises / X_m,c , 조건 I₁ ≤ 0 |
| V2_4 이하 | `max( 최대주응력/Xc , Mises/(√3·Xc) )` |
| 문제 | **√3 이 논문에 없다.** 압축 기준이 1.73배 느슨했다 |
| V2_5 이후 | 논문 Eq.16 그대로 |

고온에서 기지가 잔류압축으로 전환되므로 500/1000 °C 결과에 직접 영향.

### 1.3 기지 소성 — **미구현**

논문은 기지에 탄소성-손상 모델(Eq.6~10)을 쓴다. 현재 모델은 **탄성-손상만**
구현했다. 소성은 응력을 낮추고 재분배 경로를 바꾸므로, 잔류응력 분포와
손상 위치에 영향이 있을 수 있다. 미구현 사유: 구현 우선순위.

### 1.4 얀 종방향 손상진화 — **부분 해결 (V2_6)**

| | 내용 |
|---|---|
| 논문 | Eq.17/18 혼합 선형-지수형 |
| 현재 | 단순 지수형 `d = 1 − exp[A(1−r)]/r` |
| V2_6 추가 | `PROPS(32)=GF1T` 크랙밴드 정규화 |

V2_5 까지 얀 종방향에는 크랙밴드 정규화가 없어서 연화가 요소 하나로
국부화됐다. 이것이 **eta 비수렴과 메쉬 비수렴의 공통 원인**이었다.

실측된 eta 비수렴:

| eta | 최대응력 | halving당 변화 |
|---|---|---|
| 1.00× | 160.490 MPa | — |
| 0.50× | 154.558 MPa | −3.70% |
| 0.25× | 147.678 MPa | **−4.45%** (커짐 = 수렴 안 함) |

V2_6 의 재료점 검증(`verify_yarn_crackband.py`)에서 요소크기
0.0285~0.2000 mm 범위에 대해 소산에너지 편차 **1.00000배**, GF1T 대비
오차 **0.000%** 로 메쉬 무관성이 확인되었다.

**남은 차이**: Eq.17/18 의 혼합 선형-지수 형태는 여전히 미구현.

### 4.1 점성 정규화 — Zhang 본문에 없음 (원전 Ge 2018 에는 있음)

수렴을 위해 `GAM = Δt/(η+Δt)` 형태의 점성 정규화를 넣었다. Zhang 2022
본문에는 언급이 없으나, **2026-08-06 Ge 2018 [17] 확보로 원전 확인:
Ge Eq.29–30 의 Duvaut–Lions 정규화가 정확히 이 식이다** (§5.15).
즉 우리 eta 는 임의 추가가 아니라 계보-충실 구현이다. 다만
**결과가 하중속도에 의존**하는 성질은 그대로이므로, 서로 다른
목표변형률로 돌린 해석은 여전히 비교할 수 없다.

실측된 속도 의존성 (초기 접선강성):

| 목표변형률 span | 초기 접선 |
|---|---|
| 0.004617 | 66.56 GPa |
| 0.005617 | 73.48 GPa |
| 0.010617 | 88.55 GPa |

→ **온도별 비교 시 반드시 기계변형률 span 을 통일해야 한다.**

### 5.3 파손기준 가설의 기각 (냉각 odb 진단, 2026-08-04)

`diagnose_cooling_criterion.py` 로 CSIC_t23.odb 의 냉각 Step 102 프레임을
전부 읽어 기지 적분점 91,554 개의 최대주응력과 von Mises 를 직접 비교했다.

| T [°C] | MaxPrin avg / p99 / max | Mises avg / p99 / max | Xm=310 초과율 MaxPrin / Mises |
|---|---|---|---|
| 846.4 | 90.9 / 130.7 / **140.0** | 77.1 / 146.4 / **155.5** | **0.00% / 0.00%** |
| 620.5 | — | — | 0.003% / 0.006% (최초 개시) |
| 427.9 | 254.8 / 405.5 / 520.1 | 214.9 / 427.7 / 537.7 | **20.42% / 16.75%** (최대) |
| 23.0 | 191.9 / 382.5 / 492.5 | 167.5 / 475.7 / 760.9 | 7.05% / 8.64% |

**결론: 파손기준은 845 °C 갭의 원인이 아니다.**

- 845 °C 에서 **가장 응력이 높은 단 하나의 적분점조차** MaxPrin 140.0 /
  Mises 155.5 MPa 로, Xm=310 의 45% / 50% 에 불과하다. 어느 기준을 써도
  손상은 0% 다.
- Mises/MaxPrin 비는 평균 0.848, p99 1.12~1.24 다. 즉 von Mises 는
  평균적으로는 **덜** 가혹하고 핫스팟에서만 더 가혹하다. 23 °C 에서
  기준을 바꿔도 초과율은 7.05% → 8.64% (+1.59 pp) 로 바뀔 뿐이다.
- **I1 ≥ 0 인 적분점이 전 온도구간에서 99.95% 이상**이다. 즉 논문
  Eq.15(인장 분기)가 사실상 항상 지배하고 Eq.16 은 냉각 중 발동하지
  않는다. V2_5 의 MCRIT=1 경로는 논문 충실도 목적으로는 유지할 가치가
  있으나 손상률 갭은 해결하지 못한다.
- (2026-08-04 감사) V2_5/V2_6 의 MCRIT=1 완만밴드는 |I1|<0.1Xc 에서
  두 분기를 동시에 희석하는 결함이 있었다 (I1=0 에서 개시응력 2배).
  **V2_7 에서 지배가중치 정규화로 수정** — MCRIT=1 을 처음 실전 투입할
  때는 반드시 V2_7 을 쓸 것. 완료된 해석은 전부 MCRIT 미사용이라 무영향.

**Weibull 산포와의 정합성 확인.** 진단은 Xm=310 고정으로 세지만 UMAT 은
요소마다 Weibull(m=5.1, 평균 310, σ0=337.2) 로 샘플링한다. 평균응력에
Weibull 파손확률을 적용하면

| T [°C] | 평균 MaxPrin | Weibull 예측 손상률 | FE 실측 |
|---|---|---|---|
| 846.4 | 90.9 | 0.125% | **0.147%** |
| 427.9 | 254.8 | 21.3% | 20.42% |
| 23.0 | 191.9 | 5.48% | 7.05% |

세 온도 모두 일치한다. **845 °C 의 0.147% 는 Weibull 하단 꼬리
(최약 요소 기대강도 35.9 MPa) 로 완전히 설명된다.**

**남은 원인은 잔류응력 크기 자체다.** 845 °C 에서 손상률 ~100% 가
되려면 평균 Xm 이 **58~62 MPa (현재의 0.19 배)** 여야 하는데, 이는
논문 Table 2 의 310 MPa 와 정면으로 배치된다. 따라서 논문 쪽 기지
잔류응력이 우리보다 크다고 보는 편이 타당하다.

| 항목 | 값 |
|---|---|
| 모델 응력 증가율 (1050→845 °C) | 90.9/205 = **0.443 MPa/K** |
| 1축 완전구속 상한 E_m·Δα | 350000 × 3.43e-6 = 1.20 MPa/K |
| 모델의 구속효율 | **37%** |
| 845 °C 에서 310 MPa 도달에 필요 | **1.51 MPa/K** |
| 등2축 구속 E_m·Δα/(1−ν) | 1.20/0.80 = **1.50 MPa/K** |

논문이 요구하는 1.51 MPa/K 는 **등2축 완전구속** 값과 거의 정확히
같다. 우리 RVE 는 그 30% 밖에 안 나온다.

## 5.5 사전등록 예측 — job B (noTRS) 가 나오기 전에 적는다

결과를 본 뒤에 설명을 맞추면 어떤 결과든 설명이 된다. 그래서 **숫자를
먼저 박아둔다.** job B 는 얀 CTE 를 기지와 같게 만들어 열잔류응력을
0 으로 없앤 23 °C 인장이다.

**측정된 입력 (FE 실측):**

| 항목 | 23 °C | 500 °C |
|---|---|---|
| 얀 축방향 잔류응력 | −341.8 MPa | −151.2 MPa |
| 기지 잔류응력 | +156.7 MPa | +66.9 MPa |
| 거시 최대응력 | 129.12 (하한) | 129.23 |

**가설 A — 강도는 전적으로 "얀 잔류압축 여유분" 이 만든다.**

얀이 XT=421 에 닿으려면 −341.8 에서 762.8 MPa 를 올라와야 한다.
잔류응력이 없으면 421 MPa 만 올라오면 된다. 거시응력이 얀 응력증분에
비례한다면

```
sigma_noTRS = 129.12 x 421.0 / 762.8 = 71.3 MPa
```

**가설 B — 잔류응력은 강도에 거의 기여하지 않는다.**

```
sigma_noTRS ~ 129 MPa  (거의 변화 없음)
```

**판정 기준**

| job B 실측 | 결론 |
|---|---|
| ~71 MPa | 가설 A 확정. 500 °C 미강화는 여유분 상실로 완전히 설명됨 |
| 71~129 사이 | 두 기구가 공존. 위치가 곧 기여도 |
| ~129 MPa 이상 | 가설 A 기각. 다른 기구를 찾아야 함 |

**주의 — 가설 A 는 이미 500 °C 에서 한 번 어긋났다.** 같은 선형
스케일링을 500 °C 에 적용하면 129.12 × 572.2/762.8 = **96.9 MPa** 를
예측하는데, 실측은 **129.23 MPa** 였다. 즉 여유분이 줄었는데도 강도가
안 떨어졌다.

상쇄 기구가 있다는 뜻이다. 유력한 후보는 **기지 잔류응력 완화**다.
승온하면 기지 여유가 늘어(+156.7 → +66.9) 기지 손상이 늦게 시작되고,
그래서 복합재가 더 뻣뻣해진다. 실제로 초기 접선계수가 **62.5 → 90.1
GPa (+44%)** 로 올랐다. 얀 여유분 감소(−)와 기지 손상 지연(+)이
거의 정확히 상쇄되어 129 MPa 로 같아진 것으로 보인다.

job B 는 이 상쇄를 깬다. 잔류응력을 **양쪽 다** 0 으로 만들기 때문에
얀 여유분도 없고 기지 손상 지연도 없다. 따라서

- 71 MPa 에 가까우면 → 얀 여유분이 지배
- 129 MPa 에 가까우면 → 기지 손상 지연이 지배 (얀 여유분은 상쇄됨)

**어느 쪽이든 논문 4.2/4.3 절(열잔류응력의 효과)에 직접 쓸 수 있는
정량 데이터가 된다.**

### 5.6 job B 결과 — 두 가설 모두 기각 (2026-08-05)

| | 예측 | 실측 |
|---|---|---|
| 가설 A (얀 여유분 지배) | 71.3 MPa | — |
| 가설 B (기여 없음) | ~129 MPa | — |
| **noTRS 실측** | — | **212.04 MPa** |

**둘 다 틀렸다. 열잔류응력을 없앴더니 강도가 t23(129.12) 대비
+64% 올랐다.** 잔류응력은 강도를 만드는 것이 아니라 **깎고 있었다.**

원인은 손상 CSV 첫 프레임(인장 시작 = 냉각 직후)에 그대로 있다.

| 상(phase) | 정상 냉각 후 | noTRS 후 |

### 5.7 그래서 온도 강화가 왜 안 나왔나 (유력 가설)

논문의 기구는 **"승온 → 열잔류응력 완화 → 강도 증가"** 이고,
noTRS(완전 완화)가 +64% 를 준다. **크기가 논문의 +40%(500 °C) /
+55%(1000 °C) 와 같은 스케일이다. 즉 모델은 그 기구를 갖고 있다.**

문제는 **우리 해석 순서**다.

```
현재:  1050 -> 23 (기지 72% 손상) -> 500 으로 승온 -> 인장
논문:  1050 -> 500 -> 인장   (추정)
```

**손상은 비가역이다.** 23 °C 까지 내렸다가 올리면 그때 생긴 72% 손상은
그대로 남는다. 승온으로 응력은 풀려도 손상은 안 풀린다. 그래서
500/1000 °C 가 23 °C 와 같은 129 MPa 근처에 머문 것이다.

1050 -> 500 으로 **곧장** 냉각하면 ΔT 가 1027 대신 550 이므로 기지
손상이 훨씬 적게 쌓인다. 냉각 진단 CSV 상 손상 개시가 620 °C 부근이니
500 °C 직행이면 손상이 거의 없는 상태에서 인장에 들어간다.

**검증 덱: `*_500C_DIRECT_GF.inp`, `*_1000C_DIRECT_GF.inp`**
(23 °C GF 덱과 냉각 목표온도·인장온도만 다르고 나머지 전부 동일)

| DIRECT500 결과 | 결론 |
|---|---|
| ~180 MPa | 논문 기구 재현. 해석 순서가 원인이었음이 확정 |
| ~130 MPa | 순서 문제 아님. 다른 원인을 찾아야 함 |

## 5.8 GF1T 오류 발견 — 0.0570 mm 는 coarse 메쉬 값이었다 (2026-08-05)

`mesh_celent_stats.py` 로 덱의 C3D4 체적을 직접 적분해 CELENT 분포를
구했다 (Abaqus 3-D CELENT = 요소체적^(1/3)). 총 체적 5.390000 mm^3 로
검증완료 RVE 체적과 정확히 일치하므로 파싱은 신뢰할 수 있다.

| 상(phase) | 요소수 | CELENT 중앙 | 체적가중평균 |
|---|---|---|---|
| 얀 (Yarn0-3) | 82,851 | 0.03154 | **0.03269** |
| 기지 | 91,554 | 0.03050 | 0.03226 |
| 전체 (V/N)^(1/3) | 174,405 | — | **0.03138** |

**GF1T=0.03962 은 "fine 메쉬 le=0.0570 에서 A1TEFF=2.0" 을 목표로
역산한 값인데, 0.0570 은 fine 메쉬 값이 아니다.**

```
5.39 mm^3 / 26,000 요소 (coarse) -> 0.05918   <- 0.0570 의 출처
5.39 mm^3 / 174,405 요소 (fine)  -> 0.03138
```

74% 큰 요소크기를 가정한 결과 실제 A1TEFF 는 2.0 이 아니라

| GF1T | A1TEFF 중앙 | 평균 | p05~p95 |
|---|---|---|---|
| 0.03962 (현재) | **0.765** | 0.775 | 0.609~0.966 |
| **0.022728 (정정)** | 1.863 | **1.920** | 1.373~2.628 |

가 되어 훨씬 연성적으로 거동했고, 그래서 23 °C 강도가
**125.81 → 139.43 MPa (+10.8%)** 로 올라갔다. V2_6 이 보정을 깨뜨린
것이 아니라 **GF1T 값 자체가 틀렸던 것**이다.

**정정값: `GF1T = 0.022728 N/mm`** ( = 2·g0·le_vw, g0=0.347576 )
snap-back 한계 le = 0.0641 mm > 실제 최대 0.0453 mm 이므로 클램프
걸리는 요소는 없다.

**진행 중인 DIRECT 배치는 그대로 둔다.** 23 °C GF 와 GF1T 가 같아
비교가 성립하므로, 온도 이력 가설 검증에는 영향이 없다. 정정값은
그 다음 최종 배치에 적용한다.

기지 PROPS(16)=0.018 은 수렴/강도를 보며 경험적으로 맞춘 값이지
A=2.0 을 재현한다고 주장한 적이 없으므로 오류가 아니다 (참고:
A=2.0 재현값은 0.008858). 클램프도 없다.

**하중속도 교란은 결론에 유리한 방향이다.** 직행은 냉각수축이 작아
인장 구간이 0.00323 (경유 0.005311) 로 **1.64배 느리다**. 과거 속도
검사에서 느릴수록 응력이 낮게 나왔으므로, 실제 효과는 +42.2% 보다
크다.

### 5.10.1 남은 두 가지 문제 — 반드시 논문에 쓸 것

**(1) 직행 냉각은 실제 시편 이력이 아니다.**

실제 C/SiC 시편은 1050 °C 에서 제작 → **상온까지 냉각** → 시험온도로
승온 → 시험한다. 즉 물리적으로 옳은 경로는 "경유" 다. 직행은 상온
체류를 생략한 모델링 단순화다.

따라서 두 가지 해석이 가능하다.

- (a) **논문이 직행 냉각을 썼다.** 우리 직행 결과가 논문에 근접하는
  것이 그 방증이다. 이 경우 논문의 온도 강화는 상온 손상을 무시한
  결과이며, 이것을 지적하는 것 자체가 기여가 된다.
- (b) **실제 재료의 손상이 우리 모델만큼 비가역이 아니다.** 고온에서
  균열 닫힘·재소결로 강성이 일부 회복될 수 있다. 그렇다면 모델에
  온도 의존 손상회복을 넣어야 한다.

어느 쪽이든 **"비가역 손상 가정 하에서는 상온 경유가 온도 강화를
소멸시킨다"** 는 정량 결과는 논문에 없는 내용이다.

**(2) 파괴변형률이 너무 작다.**

| | 최대점 변형률 |
|---|---|
| 23 °C GF | 0.2818% |
| 1000 °C 직행 | **0.0882%** |

승온으로 강도는 +24.6% 올랐는데 파괴변형률은 **3.2배 작아졌다.**
직행은 냉각손상이 없어 매우 뻣뻣하고(할선 232.8 GPa) 낮은 변형률에서
기지 손상이 몰려 파괴한다.

최대점에서의 손상 구성도 다르다.

| | 기지 | 얀 종 | 얀 횡 |
|---|---|---|---|
| 23 °C GF | 84.3% | 25.9% | 80.1% |
| 1000 °C 직행 | 36.9% | **0.15~0.20%** | 5.9~6.3% |

**1000 °C 직행의 파괴는 얀 파단이 아니라 기지 손상 집중이다.**
23 °C 와 파손 기구가 다르므로, 강도가 맞았다고 해서 같은 물리를
재현했다고 말할 수 없다. 논문 Fig.15 의 곡선 형상·파괴변형률과
직접 대조해서 확인해야 한다.

## 5.12 DIRECT 배치 완결 — 직행 경로도 논문 추세를 못 낸다 (2026-08-05)

500 °C 직행이 나오면서 세 온도가 모두 채워졌다. 전부 같은 카드
(V2_6 GF1T=0.03962), 냉각 목표온도만 다르다.

| T [°C] | 냉각 ΔT | 냉각 직후 기지손상 | 강도 (국부최대) | 23 °C 대비 |
|---|---|---|---|---|
| 23 | 1027 K | 72.0% | 139.43 | — |
| 500 | 550 K | **26.4%** | **138.49** | **−0.7%** |
| 1000 | 50 K | 0.0% | 173.74 | +24.6% |
| **논문** | | 100% (전 온도) | 128.45 / 179.42 / 199.15 | +39.7 / +55.0% |

**23 → 500 °C 가 평평하다 (−0.7%). 논문은 +39.7% 다.**
1000 °C 만 오르는데, 그건 ΔT=50 K 라 냉각손상이 아예 0 이기 때문이다.

즉 직행 경로의 강도는 "냉각손상이 얼마나 적은가" 를 따라갈 뿐이고,
논문이 말하는 **응력상태 반전에 의한 강화** 와는 다른 기구다.
500 °C 에서 손상이 72 → 26% 로 크게 줄었는데도 강도가 안 오른 것이
그 증거다 (잔류압축 여유분이 함께 줄어 상쇄).

**결론: DIRECT 경로는 폐기한다.** 1000 °C 하나가 우연히 논문에
가까웠을 뿐, 온도 추세·파괴변형률·손상 구성 어느 것도 재현하지
못한다. 논문 절차(23 °C 경유)로 돌아가는 PAPERFAITH 체인이 옳다.

**직행 데이터의 남은 가치**: "비가역 손상이 온도 이력에 얼마나
의존하는가" 의 정량 데이터로는 유효하다 (논문에 없는 내용).

세부:
- 500 °C 직행 최대점 워프 종손상 **11.13%** (논문 44.38%).
- 강성 E11: 500 °C 직행 30.5 GPa. 단 `diagnostics_homog_500cmp.txt`
  의 비교줄은 500 °C 직행 vs 1000 °C **경유** 를 나란히 놓은 것이라
  경로가 섞여 있다. 경로별로 갈라서 읽을 것.
- 500 °C 직행 곡선은 급강하 8.0% 뒤 재상승(끝 +8.71 GPa)으로 기존
  런들과 같은 DMAX 재상승 패턴.

### (A) 세 손잡이 모두 기지 손상을 **줄였다** — 방향이 반대

기준선 72.0 % 에서 P0 60.2 / P1 59.6 / P2 58.8 % 로 내려갔다.
논문과의 격차가 **28 → 41 포인트로 벌어졌다.**

**Weibull 가설의 기각 사유**: 산포에는 강한 꼬리만 있는 것이 아니라
**약한 꼬리도 있고, 손상요소율은 요소를 세는 통계이므로 약한 꼬리가
지배한다.** m=5.1 산포에서 XTE < 310 인 요소들이 먼저 손상되어
개수를 올리고 있었다. 결정론적 310 으로 바꾸니 그 요소들이 사라졌다.
"강한 꼬리가 생존해서 손상률을 깎는다" 는 §5.11(E) 1번 가설은 틀렸다.

**MCRIT=1 의 효과**: 개시온도를 540.9 → 602.5 °C 로 **62 K 앞당겼으나**
최종값은 60.2 → 59.6 % 로 거의 안 변했다. 논문 기준(Eq.15/16)은
냉각 손상량을 바꾸는 요인이 아니다.

### (B) Yt 는 유일하게 의도대로 움직였으나 목표에 못 닿는다

얀 횡손상 19.70 → 34.08 % (Yt 80 → 50 MPa). 2점 보간:

| 보간 | 88 % 에 필요한 Yt |
|---|---|
| 선형 (−0.479 %/MPa) | **−62.5 MPa** |
| 지수 (ln P, k=0.01828 /MPa) | **−1.9 MPa** (Yt=0 이어도 85.0 %) |

**양수 Yt 로는 88 % 에 도달하지 않는다.** 얀 횡방향 응력 분포 자체가
"88 % 의 적분점이 넘어설 만한 문턱" 을 갖고 있지 않다. 기지의 100 %
문제와 **같은 원인** 이며, 강도값 조정으로 풀 수 없다.

### (C) 얀 횡방향 강성도 기각 — 마지막 물성 후보 소멸

§5.4/§3 의 진단("얀이 물러서 기지를 구속하지 못한다")을 그대로 손잡이로
쓰면 되는지 `residual_stress_budget.py` [5] 절에서 직접 쓸었다.

| 얀 E2 | Voigt 기지 응력증가율 | 목표(1.512) 대비 |
|---|---|---|
| 44 GPa (현재 Chamis) | 0.323 MPa/K | 21.4 % |
| 99 GPa (혼합률 상한) | 0.327 | 21.7 % |
| 350 GPa (기지와 동일) | 0.344 | 22.7 % |
| **무한대** | **0.411** | **27.2 %** |

**얀이 무한히 단단해도 27 % 다.** E2→∞ 이면 등변형률 평균 CTE 가 얀
횡방향 CTE(3.325e−6)로 수렴하고, 기지(4.5e−6)와의 차 1.175e−6 에
Em 을 곱한 **0.411 MPa/K 가 천장**이기 때문이다.

절대 상한 비교:

```
Em*(am-a1)          = 1.200 MPa/K     (1축 완전구속)
Em*(am-a1)/(1-nu)   = 1.500 MPa/K     (등2축 완전구속)
논문 요구            = 1.512 MPa/K     <- 등2축 완전구속과 같다
```

**논문 Fig.4 는 기지가 "강체 위 박막" 처럼 완전히 갇혀 있어야만
나오는 값이다.** 기지가 체적의 50 % 를 차지하는 3D RVE 에서는 어떤
얀 물성으로도 원리적으로 불가능하다.

### (D) 체인 정합성 검증 — 부수 소득

P1 과 P2 의 `Matrix_PctDamaged` 가 **프레임 0~68 까지 52프레임 중
35프레임 비트단위로 완전히 같고**, 얀 횡손상이 개시되는 프레임 70
(338 °C, P1 0.0048 % vs P2 0.4810 %) 에서 정확히 갈라진다.

## 5.15 Ge 2018 [17] 완독 — 모델 원전의 전모 (2026-08-06)

사용자가 Ge 2018 (CST 157:86–98, 13쪽) PDF 를 제공, 전문 완독.

(SDV 번호까지 동일: SDV1=종손상, SDV2=횡손상, SDV14=기지손상 —
Zhang Fig.5/8/10 범례와 Ge Fig.8/10 범례가 같음).

### 수확 5건

**(1) Eq.18 보조변수의 완전한 정의 — B2 해소 (사양 확보)**

Zhang 이 [30] Zhong 2015 로 미룬 혼합 선형-지수 법이 Ge Eq.16–17 에
그대로 있다:

```
d_1t = 1 − (1−d^L_1t)/r^E_1t · exp[A_1t(1−r^E_1t)]
d^L_1t = 1 + K1/E1 − (1 + K1/E1)·(1/r^L_1t)          (선형 구간)
r^L_1t = max{1, min(r_1t, r^E_1t)}
r^E_1t = max{1, (1−d^E_1t)·(X_1t/X_PO)·r_1t}          (전환점)
```

K1 = 선형연화 기울기 (섬유 브리징), X_PO = 선형→지수 전환응력
(풀아웃 개시). 즉 **선형(브리징) 후 지수(풀아웃)** 2단 연화다.
파라미터 K1, X_PO 는 SiC 얀에 대해 미기재 → 보정 대상 (C층).

**(2) 연화계수 A 는 자유 파라미터가 아니다 — 전부 크랙밴드 유도**

Ge Eq.19–21: 모든 모드의 A_M 은 Bazant 크랙밴드로
`g_M = G_M / l*` 을 적분해 결정한다. 파괴인성 테이블 (페놀릭 카드):
기지 G_m,t(c)=1.0 / 얀 종 G_1t=G_1c=12.5 / 얀 횡 G_2(3)t(c)=1.0 N/mm.
**우리 V2_2(기지 Gf)/V2_6(GF1T) 크랙밴드가 계보 원전 방식과 정확히
일치한다.** §5.14(C) 의 "A 계수들 미기재" 는 "SiC 의 G 값들 미기재"
로 대체된다 (구조는 확보, 수치만 보정).

**(3) 점성 정규화는 원전에 있다 — §4.1 정정**

Ge Eq.29–30 Duvaut–Lions: `d^v_{n+1} = Δt/(η+Δt)·d_{n+1} +
η/(η+Δt)·d^v_n` — **우리 GAM=Δt/(η+Δt) 와 동일식.** 우리 eta 는
임의 추가가 아니었다. Zhang 본문에서 생략됐을 뿐이다.

**(4) 기지 소성의 완전한 구조 (수치 제외)**

유효응력 공간 von Mises 항복 F = σ̄_eq − σ̃_s(ε̄p), 연합유동,
등방경화 σ̃_s 는 "실험 경화곡선" (페놀릭은 Ref[27] 단행본에서;
**SiC 경화곡선은 Zhang/Ge 어디에도 없음** — V2_8 의 유일 미지수).
수치해법: 백워드 오일러 반환사상 + 일관 접선 (Ge Eq.25–28, 31–33).
손상은 등방 단일 d_m (전단 포함 1/(1−d_m)) — 우리와 동일 구조.

**(5) 대수적 귀결 — 소성만으로는 Fig.4 냉각 손상이 안 나온다**

Ge 결합구조에서 기지 손상 개시는 여전히 **유효응력 von Mises 가
X_m 에 도달**해야 한다 (φ_m = σ̄_eq/X_m ≥ 1). 소성은 σ̄_eq 를
경화응력으로 **캡할 뿐 낮출 수는 있어도 올리지 못한다.**
따라서 §5.13(C) 의 천장 계산(어떤 물성으로도 845 °C 까지 기지 응력
310 도달 불가)은 소성을 넣어도 그대로 유효하다.

- 논문 Fig.4 의 개시 ~1000-1030 °C (ΔT≈20-50 K 에 첫 손상) 는 국부
  응력집중(얀 랩)으로 설명 가능할 수 있으나, **845 °C 에서 100 %**
  (평균 1.51 MPa/K 필요) 는 공개된 물성·식으로는 불가능하다.
- 결론 강화: **Fig.4 재현에는 미공개 파라미터가 필요하다** (낮은

## 5.17 PAPERFAITH 3자 비교 — **MCRIT=1 이 기지 100 % 를 연다** (2026-08-07)

P1(=P0+MCRIT=1) / P2(=P1+Yt=50) 가 완주했다. **세 런의 기계변형률
span 이 0.8539 / 0.8538 / 0.8495 % 로 사실상 같다** — §4.1 의 속도
교란이 없으므로 **이번 3자 비교는 유효하다.** (§5.16D 의 P0-vs-GF
비교가 무효였던 것과 대비된다.)

### (A) 최대 발견 — 기지 손상률 100.00 %

| | 기지 손상률 최대 | 도달 프레임 |
|---|---|---|
| P0 (MCRIT=0) | 88.70 % | 200 (곡선 끝) |
| **P1 (MCRIT=1)** | **100.00 %** | 200 |
| P2 (MCRIT=1 + Yt=50) | 99.99 % | 198 |

**논문 Fig.A1 의 "기지 100 %" 를 처음으로 재현했다.** §5.16C 는 이
벽을 열잔류응력 크기 탓으로 돌렸는데 **틀렸다.** 필요한 것은
**논문 자신의 파손기준**이었다.

기구는 DMC(압축손상) 값이 말해 준다.

| 프레임 200 | 기지 손상률 | DMT_avg | DMC_avg |
|---|---|---|---|
| P0 | 88.70 % | 0.818 | **0.0765** |
| P1 | 100.00 % | 0.948 | **0.0138** |

- **MCRIT<0.5** (V2_4 경로): 인장 = Rankine(최대주응력/Xt),
  압축 = max(최대주응력, Mises/(√3·Xc)) + I₁ 게이트. 두 분기가
  동시에 작동하고, I₁<0 요소는 **실효 537 MPa** 문턱에 갇힌다.
- **MCRIT≥0.5** (논문 Eq.15/16): 양 분기 모두 von Mises, **I₁ 부호로
  배타 분할**, √3 없음. 인장 중 기지는 대부분 I₁>0 이므로 갇혀
  있던 요소가 전부 인장분기로 넘어가 Mises/Xt 로 판정된다.

P0 의 DMC 0.0765 → P1 의 0.0138 이 바로 "압축분기에 갇혀 있던
요소가 인장분기로 이동한" 증거다. 진단은 맞았고 처방이 틀렸다.

**단, 냉각은 여전히 못 연다.** 인장 프레임 0(=냉각 끝) 기지
손상률은 P0 60.17 / P1 59.56 / P2 58.73 % 로 **MCRIT 이 냉각을
거의 바꾸지 않는다.** 냉각 중 기지는 거의 등방인장(I₁>0)이라 두
기준이 같은 답을 내기 때문이다. **§5.13 의 냉각 벽은 그대로 유효**
하고, 이번 발견은 인장 쪽에만 적용된다.
