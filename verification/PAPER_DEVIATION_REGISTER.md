## 1. 구성방정식 (Constitutive model)

### 1.1 기지 인장 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.15: von Mises 등가 유효응력 / X_m,t , 조건 I₁ ≥ 0 |
| V2_4 이하 | 최대주응력(Rankine) / X_m,t , I₁ 게이트 없음 |
| V2_5 이후 | `PROPS(24)=MCRIT=1` 로 논문 Eq.15 그대로 구현 |
| 잔여 차이 | 논문은 I₁=0 에서 하드 스위치. 구현은 ±BAND(=0.1·Xc) 완만 램프 |

램프를 쓴 이유: I₁=0 하드 스위치는 구성방정식의 불연속이며, 실제로
V2_3 에서 260.2 °C 발산의 원인이었다. BAND→0 이면 논문과 일치한다.

**미확인**: 이 변경이 손상량을 늘리는지 줄이는지 아직 실측 안 됨.
냉각 직후 기지는 Mises 170.4 / MaxPrin 201.9 로 **Mises 가 더 작아서**
인장 손상이 오히려 줄어들 가능성이 있다. `23C_PAPERCRIT` 덱으로 판정 예정.

### 1.2 기지 압축 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.16: von Mises / X_m,c , 조건 I₁ ≤ 0 |
| V2_4 이하 | `max( 최대주응력/Xc , Mises/(√3·Xc) )` |
| 문제 | **√3 이 논문에 없다.** 압축 기준이 1.73배 느슨했다 |
| V2_5 이후 | 논문 Eq.16 그대로 |

고온에서 기지가 잔류압축으로 전환되므로 500/1000 °C 결과에 직접 영향.

### 1.3 기지 소성 — **미구현**

논문은 기지에 탄소성-손상 모델(Eq.6~10)을 쓴다. 현재 모델은 **탄성-손상만**
구현했다. 소성은 응력을 낮추고 재분배 경로를 바꾸므로, 잔류응력 분포와
손상 위치에 영향이 있을 수 있다. 미구현 사유: 구현 우선순위.

### 1.4 얀 종방향 손상진화 — **부분 해결 (V2_6)**

| | 내용 |
|---|---|
| 논문 | Eq.17/18 혼합 선형-지수형 |
| 현재 | 단순 지수형 `d = 1 − exp[A(1−r)]/r` |
| V2_6 추가 | `PROPS(32)=GF1T` 크랙밴드 정규화 |

V2_5 까지 얀 종방향에는 크랙밴드 정규화가 없어서 연화가 요소 하나로
국부화됐다. 이것이 **eta 비수렴과 메쉬 비수렴의 공통 원인**이었다.

실측된 eta 비수렴:

| eta | 최대응력 | halving당 변화 |
|---|---|---|
| 1.00× | 160.490 MPa | — |
| 0.50× | 154.558 MPa | −3.70% |
| 0.25× | 147.678 MPa | **−4.45%** (커짐 = 수렴 안 함) |

V2_6 의 재료점 검증(`verify_yarn_crackband.py`)에서 요소크기
0.0285~0.2000 mm 범위에 대해 소산에너지 편차 **1.00000배**, GF1T 대비
오차 **0.000%** 로 메쉬 무관성이 확인되었다.

**남은 차이**: Eq.17/18 의 혼합 선형-지수 형태는 여전히 미구현.

### 4.1 점성 정규화 — Zhang 본문에 없음 (원전 Ge 2018 에는 있음)

수렴을 위해 `GAM = Δt/(η+Δt)` 형태의 점성 정규화를 넣었다. Zhang 2022
본문에는 언급이 없으나, **2026-08-06 Ge 2018 [17] 확보로 원전 확인:
Ge Eq.29–30 의 Duvaut–Lions 정규화가 정확히 이 식이다** (§5.15).
즉 우리 eta 는 임의 추가가 아니라 계보-충실 구현이다. 다만
**결과가 하중속도에 의존**하는 성질은 그대로이므로, 서로 다른
목표변형률로 돌린 해석은 여전히 비교할 수 없다.

실측된 속도 의존성 (초기 접선강성):

| 목표변형률 span | 초기 접선 |
|---|---|
| 0.004617 | 66.56 GPa |
| 0.005617 | 73.48 GPa |
| 0.010617 | 88.55 GPa |

→ **온도별 비교 시 반드시 기계변형률 span 을 통일해야 한다.**

### 5.3 파손기준 가설의 기각 (냉각 odb 진단, 2026-08-04)

`diagnose_cooling_criterion.py` 로 CSIC_t23.odb 의 냉각 Step 102 프레임을
전부 읽어 기지 적분점 91,554 개의 최대주응력과 von Mises 를 직접 비교했다.

| T [°C] | MaxPrin avg / p99 / max | Mises avg / p99 / max | Xm=310 초과율 MaxPrin / Mises |
|---|---|---|---|
| 846.4 | 90.9 / 130.7 / **140.0** | 77.1 / 146.4 / **155.5** | **0.00% / 0.00%** |
| 620.5 | — | — | 0.003% / 0.006% (최초 개시) |
| 427.9 | 254.8 / 405.5 / 520.1 | 214.9 / 427.7 / 537.7 | **20.42% / 16.75%** (최대) |
| 23.0 | 191.9 / 382.5 / 492.5 | 167.5 / 475.7 / 760.9 | 7.05% / 8.64% |

**결론: 파손기준은 845 °C 갭의 원인이 아니다.**

- 845 °C 에서 **가장 응력이 높은 단 하나의 적분점조차** MaxPrin 140.0 /
  Mises 155.5 MPa 로, Xm=310 의 45% / 50% 에 불과하다. 어느 기준을 써도
  손상은 0% 다.
- Mises/MaxPrin 비는 평균 0.848, p99 1.12~1.24 다. 즉 von Mises 는
  평균적으로는 **덜** 가혹하고 핫스팟에서만 더 가혹하다. 23 °C 에서
  기준을 바꿔도 초과율은 7.05% → 8.64% (+1.59 pp) 로 바뀔 뿐이다.
- **I1 ≥ 0 인 적분점이 전 온도구간에서 99.95% 이상**이다. 즉 논문
  Eq.15(인장 분기)가 사실상 항상 지배하고 Eq.16 은 냉각 중 발동하지
  않는다. V2_5 의 MCRIT=1 경로는 논문 충실도 목적으로는 유지할 가치가
  있으나 손상률 갭은 해결하지 못한다.
- (2026-08-04 감사) V2_5/V2_6 의 MCRIT=1 완만밴드는 |I1|<0.1Xc 에서
  두 분기를 동시에 희석하는 결함이 있었다 (I1=0 에서 개시응력 2배).
  **V2_7 에서 지배가중치 정규화로 수정** — MCRIT=1 을 처음 실전 투입할
  때는 반드시 V2_7 을 쓸 것. 완료된 해석은 전부 MCRIT 미사용이라 무영향.

**Weibull 산포와의 정합성 확인.** 진단은 Xm=310 고정으로 세지만 UMAT 은
요소마다 Weibull(m=5.1, 평균 310, σ0=337.2) 로 샘플링한다. 평균응력에
Weibull 파손확률을 적용하면

| T [°C] | 평균 MaxPrin | Weibull 예측 손상률 | FE 실측 |
|---|---|---|---|
| 846.4 | 90.9 | 0.125% | **0.147%** |
| 427.9 | 254.8 | 21.3% | 20.42% |
| 23.0 | 191.9 | 5.48% | 7.05% |

세 온도 모두 일치한다. **845 °C 의 0.147% 는 Weibull 하단 꼬리
(최약 요소 기대강도 35.9 MPa) 로 완전히 설명된다.**

**남은 원인은 잔류응력 크기 자체다.** 845 °C 에서 손상률 ~100% 가
되려면 평균 Xm 이 **58~62 MPa (현재의 0.19 배)** 여야 하는데, 이는
논문 Table 2 의 310 MPa 와 정면으로 배치된다. 따라서 논문 쪽 기지
잔류응력이 우리보다 크다고 보는 편이 타당하다.

| 항목 | 값 |
|---|---|
| 모델 응력 증가율 (1050→845 °C) | 90.9/205 = **0.443 MPa/K** |
| 1축 완전구속 상한 E_m·Δα | 350000 × 3.43e-6 = 1.20 MPa/K |
| 모델의 구속효율 | **37%** |
| 845 °C 에서 310 MPa 도달에 필요 | **1.51 MPa/K** |
| 등2축 구속 E_m·Δα/(1−ν) | 1.20/0.80 = **1.50 MPa/K** |

논문이 요구하는 1.51 MPa/K 는 **등2축 완전구속** 값과 거의 정확히
같다. 우리 RVE 는 그 30% 밖에 안 나온다.

## 5.5 사전등록 예측 — job B (noTRS) 가 나오기 전에 적는다

결과를 본 뒤에 설명을 맞추면 어떤 결과든 설명이 된다. 그래서 **숫자를
먼저 박아둔다.** job B 는 얀 CTE 를 기지와 같게 만들어 열잔류응력을
0 으로 없앤 23 °C 인장이다.

**측정된 입력 (FE 실측):**

| 항목 | 23 °C | 500 °C |
|---|---|---|
| 얀 축방향 잔류응력 | −341.8 MPa | −151.2 MPa |
| 기지 잔류응력 | +156.7 MPa | +66.9 MPa |
| 거시 최대응력 | 129.12 (하한) | 129.23 |

**가설 A — 강도는 전적으로 "얀 잔류압축 여유분" 이 만든다.**

얀이 XT=421 에 닿으려면 −341.8 에서 762.8 MPa 를 올라와야 한다.
잔류응력이 없으면 421 MPa 만 올라오면 된다. 거시응력이 얀 응력증분에
비례한다면

```
sigma_noTRS = 129.12 x 421.0 / 762.8 = 71.3 MPa
```

**가설 B — 잔류응력은 강도에 거의 기여하지 않는다.**

```
sigma_noTRS ~ 129 MPa  (거의 변화 없음)
```

**판정 기준**

| job B 실측 | 결론 |
|---|---|
| ~71 MPa | 가설 A 확정. 500 °C 미강화는 여유분 상실로 완전히 설명됨 |
| 71~129 사이 | 두 기구가 공존. 위치가 곧 기여도 |
| ~129 MPa 이상 | 가설 A 기각. 다른 기구를 찾아야 함 |

**주의 — 가설 A 는 이미 500 °C 에서 한 번 어긋났다.** 같은 선형
스케일링을 500 °C 에 적용하면 129.12 × 572.2/762.8 = **96.9 MPa** 를
예측하는데, 실측은 **129.23 MPa** 였다. 즉 여유분이 줄었는데도 강도가
안 떨어졌다.

상쇄 기구가 있다는 뜻이다. 유력한 후보는 **기지 잔류응력 완화**다.
승온하면 기지 여유가 늘어(+156.7 → +66.9) 기지 손상이 늦게 시작되고,
그래서 복합재가 더 뻣뻣해진다. 실제로 초기 접선계수가 **62.5 → 90.1
GPa (+44%)** 로 올랐다. 얀 여유분 감소(−)와 기지 손상 지연(+)이
거의 정확히 상쇄되어 129 MPa 로 같아진 것으로 보인다.

job B 는 이 상쇄를 깬다. 잔류응력을 **양쪽 다** 0 으로 만들기 때문에
얀 여유분도 없고 기지 손상 지연도 없다. 따라서

- 71 MPa 에 가까우면 → 얀 여유분이 지배
- 129 MPa 에 가까우면 → 기지 손상 지연이 지배 (얀 여유분은 상쇄됨)

**어느 쪽이든 논문 4.2/4.3 절(열잔류응력의 효과)에 직접 쓸 수 있는
정량 데이터가 된다.**

### 5.6 job B 결과 — 두 가설 모두 기각 (2026-08-05)

| | 예측 | 실측 |
|---|---|---|
| 가설 A (얀 여유분 지배) | 71.3 MPa | — |
| 가설 B (기여 없음) | ~129 MPa | — |
| **noTRS 실측** | — | **212.04 MPa** |

**둘 다 틀렸다. 열잔류응력을 없앴더니 강도가 t23(129.12) 대비
+64% 올랐다.** 잔류응력은 강도를 만드는 것이 아니라 **깎고 있었다.**

원인은 손상 CSV 첫 프레임(인장 시작 = 냉각 직후)에 그대로 있다.

| 상(phase) | 정상 냉각 후 | noTRS 후 |

### 5.7 그래서 온도 강화가 왜 안 나왔나 (유력 가설)

논문의 기구는 **"승온 → 열잔류응력 완화 → 강도 증가"** 이고,
noTRS(완전 완화)가 +64% 를 준다. **크기가 논문의 +40%(500 °C) /
+55%(1000 °C) 와 같은 스케일이다. 즉 모델은 그 기구를 갖고 있다.**

문제는 **우리 해석 순서**다.

```
현재:  1050 -> 23 (기지 72% 손상) -> 500 으로 승온 -> 인장
논문:  1050 -> 500 -> 인장   (추정)
```

**손상은 비가역이다.** 23 °C 까지 내렸다가 올리면 그때 생긴 72% 손상은
그대로 남는다. 승온으로 응력은 풀려도 손상은 안 풀린다. 그래서
500/1000 °C 가 23 °C 와 같은 129 MPa 근처에 머문 것이다.

1050 -> 500 으로 **곧장** 냉각하면 ΔT 가 1027 대신 550 이므로 기지
손상이 훨씬 적게 쌓인다. 냉각 진단 CSV 상 손상 개시가 620 °C 부근이니
500 °C 직행이면 손상이 거의 없는 상태에서 인장에 들어간다.

**검증 덱: `*_500C_DIRECT_GF.inp`, `*_1000C_DIRECT_GF.inp`**
(23 °C GF 덱과 냉각 목표온도·인장온도만 다르고 나머지 전부 동일)

| DIRECT500 결과 | 결론 |
|---|---|
| ~180 MPa | 논문 기구 재현. 해석 순서가 원인이었음이 확정 |
| ~130 MPa | 순서 문제 아님. 다른 원인을 찾아야 함 |

## 5.8 GF1T 오류 발견 — 0.0570 mm 는 coarse 메쉬 값이었다 (2026-08-05)

`mesh_celent_stats.py` 로 덱의 C3D4 체적을 직접 적분해 CELENT 분포를
구했다 (Abaqus 3-D CELENT = 요소체적^(1/3)). 총 체적 5.390000 mm^3 로
검증완료 RVE 체적과 정확히 일치하므로 파싱은 신뢰할 수 있다.

| 상(phase) | 요소수 | CELENT 중앙 | 체적가중평균 |
|---|---|---|---|
| 얀 (Yarn0-3) | 82,851 | 0.03154 | **0.03269** |
| 기지 | 91,554 | 0.03050 | 0.03226 |
| 전체 (V/N)^(1/3) | 174,405 | — | **0.03138** |

**GF1T=0.03962 은 "fine 메쉬 le=0.0570 에서 A1TEFF=2.0" 을 목표로
역산한 값인데, 0.0570 은 fine 메쉬 값이 아니다.**

```
5.39 mm^3 / 26,000 요소 (coarse) -> 0.05918   <- 0.0570 의 출처
5.39 mm^3 / 174,405 요소 (fine)  -> 0.03138
```

74% 큰 요소크기를 가정한 결과 실제 A1TEFF 는 2.0 이 아니라

| GF1T | A1TEFF 중앙 | 평균 | p05~p95 |
|---|---|---|---|
| 0.03962 (현재) | **0.765** | 0.775 | 0.609~0.966 |
| **0.022728 (정정)** | 1.863 | **1.920** | 1.373~2.628 |

가 되어 훨씬 연성적으로 거동했고, 그래서 23 °C 강도가
**125.81 → 139.43 MPa (+10.8%)** 로 올라갔다. V2_6 이 보정을 깨뜨린
것이 아니라 **GF1T 값 자체가 틀렸던 것**이다.

**정정값: `GF1T = 0.022728 N/mm`** ( = 2·g0·le_vw, g0=0.347576 )
snap-back 한계 le = 0.0641 mm > 실제 최대 0.0453 mm 이므로 클램프
걸리는 요소는 없다.

**진행 중인 DIRECT 배치는 그대로 둔다.** 23 °C GF 와 GF1T 가 같아
비교가 성립하므로, 온도 이력 가설 검증에는 영향이 없다. 정정값은
그 다음 최종 배치에 적용한다.

기지 PROPS(16)=0.018 은 수렴/강도를 보며 경험적으로 맞춘 값이지
A=2.0 을 재현한다고 주장한 적이 없으므로 오류가 아니다 (참고:
A=2.0 재현값은 0.008858). 클램프도 없다.

**하중속도 교란은 결론에 유리한 방향이다.** 직행은 냉각수축이 작아
인장 구간이 0.00323 (경유 0.005311) 로 **1.64배 느리다**. 과거 속도
검사에서 느릴수록 응력이 낮게 나왔으므로, 실제 효과는 +42.2% 보다
크다.

### 5.10.1 남은 두 가지 문제 — 반드시 논문에 쓸 것

**(1) 직행 냉각은 실제 시편 이력이 아니다.**

실제 C/SiC 시편은 1050 °C 에서 제작 → **상온까지 냉각** → 시험온도로
승온 → 시험한다. 즉 물리적으로 옳은 경로는 "경유" 다. 직행은 상온
체류를 생략한 모델링 단순화다.

따라서 두 가지 해석이 가능하다.

- (a) **논문이 직행 냉각을 썼다.** 우리 직행 결과가 논문에 근접하는
  것이 그 방증이다. 이 경우 논문의 온도 강화는 상온 손상을 무시한
  결과이며, 이것을 지적하는 것 자체가 기여가 된다.
- (b) **실제 재료의 손상이 우리 모델만큼 비가역이 아니다.** 고온에서
  균열 닫힘·재소결로 강성이 일부 회복될 수 있다. 그렇다면 모델에
  온도 의존 손상회복을 넣어야 한다.

어느 쪽이든 **"비가역 손상 가정 하에서는 상온 경유가 온도 강화를
소멸시킨다"** 는 정량 결과는 논문에 없는 내용이다.

**(2) 파괴변형률이 너무 작다.**

| | 최대점 변형률 |
|---|---|
| 23 °C GF | 0.2818% |
| 1000 °C 직행 | **0.0882%** |

승온으로 강도는 +24.6% 올랐는데 파괴변형률은 **3.2배 작아졌다.**
직행은 냉각손상이 없어 매우 뻣뻣하고(할선 232.8 GPa) 낮은 변형률에서
기지 손상이 몰려 파괴한다.

최대점에서의 손상 구성도 다르다.

| | 기지 | 얀 종 | 얀 횡 |
|---|---|---|---|
| 23 °C GF | 84.3% | 25.9% | 80.1% |
| 1000 °C 직행 | 36.9% | **0.15~0.20%** | 5.9~6.3% |

**1000 °C 직행의 파괴는 얀 파단이 아니라 기지 손상 집중이다.**
23 °C 와 파손 기구가 다르므로, 강도가 맞았다고 해서 같은 물리를
재현했다고 말할 수 없다. 논문 Fig.15 의 곡선 형상·파괴변형률과
직접 대조해서 확인해야 한다.

## 5.12 DIRECT 배치 완결 — 직행 경로도 논문 추세를 못 낸다 (2026-08-05)

500 °C 직행이 나오면서 세 온도가 모두 채워졌다. 전부 같은 카드
(V2_6 GF1T=0.03962), 냉각 목표온도만 다르다.

| T [°C] | 냉각 ΔT | 냉각 직후 기지손상 | 강도 (국부최대) | 23 °C 대비 |
|---|---|---|---|---|
| 23 | 1027 K | 72.0% | 139.43 | — |
| 500 | 550 K | **26.4%** | **138.49** | **−0.7%** |
| 1000 | 50 K | 0.0% | 173.74 | +24.6% |
| **논문** | | 100% (전 온도) | 128.45 / 179.42 / 199.15 | +39.7 / +55.0% |

**23 → 500 °C 가 평평하다 (−0.7%). 논문은 +39.7% 다.**
1000 °C 만 오르는데, 그건 ΔT=50 K 라 냉각손상이 아예 0 이기 때문이다.

즉 직행 경로의 강도는 "냉각손상이 얼마나 적은가" 를 따라갈 뿐이고,
논문이 말하는 **응력상태 반전에 의한 강화** 와는 다른 기구다.
500 °C 에서 손상이 72 → 26% 로 크게 줄었는데도 강도가 안 오른 것이
그 증거다 (잔류압축 여유분이 함께 줄어 상쇄).

**결론: DIRECT 경로는 폐기한다.** 1000 °C 하나가 우연히 논문에
가까웠을 뿐, 온도 추세·파괴변형률·손상 구성 어느 것도 재현하지
못한다. 논문 절차(23 °C 경유)로 돌아가는 PAPERFAITH 체인이 옳다.

**직행 데이터의 남은 가치**: "비가역 손상이 온도 이력에 얼마나
의존하는가" 의 정량 데이터로는 유효하다 (논문에 없는 내용).

세부:
- 500 °C 직행 최대점 워프 종손상 **11.13%** (논문 44.38%).
- 강성 E11: 500 °C 직행 30.5 GPa. 단 `diagnostics_homog_500cmp.txt`
  의 비교줄은 500 °C 직행 vs 1000 °C **경유** 를 나란히 놓은 것이라
  경로가 섞여 있다. 경로별로 갈라서 읽을 것.
- 500 °C 직행 곡선은 급강하 8.0% 뒤 재상승(끝 +8.71 GPa)으로 기존
  런들과 같은 DMAX 재상승 패턴.

### (A) 세 손잡이 모두 기지 손상을 **줄였다** — 방향이 반대

기준선 72.0 % 에서 P0 60.2 / P1 59.6 / P2 58.8 % 로 내려갔다.
논문과의 격차가 **28 → 41 포인트로 벌어졌다.**

**Weibull 가설의 기각 사유**: 산포에는 강한 꼬리만 있는 것이 아니라
**약한 꼬리도 있고, 손상요소율은 요소를 세는 통계이므로 약한 꼬리가
지배한다.** m=5.1 산포에서 XTE < 310 인 요소들이 먼저 손상되어
개수를 올리고 있었다. 결정론적 310 으로 바꾸니 그 요소들이 사라졌다.
"강한 꼬리가 생존해서 손상률을 깎는다" 는 §5.11(E) 1번 가설은 틀렸다.

**MCRIT=1 의 효과**: 개시온도를 540.9 → 602.5 °C 로 **62 K 앞당겼으나**
최종값은 60.2 → 59.6 % 로 거의 안 변했다. 논문 기준(Eq.15/16)은
냉각 손상량을 바꾸는 요인이 아니다.

### (B) Yt 는 유일하게 의도대로 움직였으나 목표에 못 닿는다

얀 횡손상 19.70 → 34.08 % (Yt 80 → 50 MPa). 2점 보간:

| 보간 | 88 % 에 필요한 Yt |
|---|---|
| 선형 (−0.479 %/MPa) | **−62.5 MPa** |
| 지수 (ln P, k=0.01828 /MPa) | **−1.9 MPa** (Yt=0 이어도 85.0 %) |

**양수 Yt 로는 88 % 에 도달하지 않는다.** 얀 횡방향 응력 분포 자체가
"88 % 의 적분점이 넘어설 만한 문턱" 을 갖고 있지 않다. 기지의 100 %
문제와 **같은 원인** 이며, 강도값 조정으로 풀 수 없다.

### (C) 얀 횡방향 강성도 기각 — 마지막 물성 후보 소멸

§5.4/§3 의 진단("얀이 물러서 기지를 구속하지 못한다")을 그대로 손잡이로
쓰면 되는지 `residual_stress_budget.py` [5] 절에서 직접 쓸었다.

| 얀 E2 | Voigt 기지 응력증가율 | 목표(1.512) 대비 |
|---|---|---|
| 44 GPa (현재 Chamis) | 0.323 MPa/K | 21.4 % |
| 99 GPa (혼합률 상한) | 0.327 | 21.7 % |
| 350 GPa (기지와 동일) | 0.344 | 22.7 % |
| **무한대** | **0.411** | **27.2 %** |

**얀이 무한히 단단해도 27 % 다.** E2→∞ 이면 등변형률 평균 CTE 가 얀
횡방향 CTE(3.325e−6)로 수렴하고, 기지(4.5e−6)와의 차 1.175e−6 에
Em 을 곱한 **0.411 MPa/K 가 천장**이기 때문이다.

절대 상한 비교:

```
Em*(am-a1)          = 1.200 MPa/K     (1축 완전구속)
Em*(am-a1)/(1-nu)   = 1.500 MPa/K     (등2축 완전구속)
논문 요구            = 1.512 MPa/K     <- 등2축 완전구속과 같다
```

**논문 Fig.4 는 기지가 "강체 위 박막" 처럼 완전히 갇혀 있어야만
나오는 값이다.** 기지가 체적의 50 % 를 차지하는 3D RVE 에서는 어떤
얀 물성으로도 원리적으로 불가능하다.

### (D) 체인 정합성 검증 — 부수 소득

P1 과 P2 의 `Matrix_PctDamaged` 가 **프레임 0~68 까지 52프레임 중
35프레임 비트단위로 완전히 같고**, 얀 횡손상이 개시되는 프레임 70
(338 °C, P1 0.0048 % vs P2 0.4810 %) 에서 정확히 갈라진다.

## 5.15 Ge 2018 [17] 완독 — 모델 원전의 전모 (2026-08-06)

사용자가 Ge 2018 (CST 157:86–98, 13쪽) PDF 를 제공, 전문 완독.

(SDV 번호까지 동일: SDV1=종손상, SDV2=횡손상, SDV14=기지손상 —
Zhang Fig.5/8/10 범례와 Ge Fig.8/10 범례가 같음).

### 수확 5건

**(1) Eq.18 보조변수의 완전한 정의 — B2 해소 (사양 확보)**

Zhang 이 [30] Zhong 2015 로 미룬 혼합 선형-지수 법이 Ge Eq.16–17 에
그대로 있다:

```
d_1t = 1 − (1−d^L_1t)/r^E_1t · exp[A_1t(1−r^E_1t)]
d^L_1t = 1 + K1/E1 − (1 + K1/E1)·(1/r^L_1t)          (선형 구간)
r^L_1t = max{1, min(r_1t, r^E_1t)}
r^E_1t = max{1, (1−d^E_1t)·(X_1t/X_PO)·r_1t}          (전환점)
```

K1 = 선형연화 기울기 (섬유 브리징), X_PO = 선형→지수 전환응력
(풀아웃 개시). 즉 **선형(브리징) 후 지수(풀아웃)** 2단 연화다.
파라미터 K1, X_PO 는 SiC 얀에 대해 미기재 → 보정 대상 (C층).

**(2) 연화계수 A 는 자유 파라미터가 아니다 — 전부 크랙밴드 유도**

Ge Eq.19–21: 모든 모드의 A_M 은 Bazant 크랙밴드로
`g_M = G_M / l*` 을 적분해 결정한다. 파괴인성 테이블 (페놀릭 카드):
기지 G_m,t(c)=1.0 / 얀 종 G_1t=G_1c=12.5 / 얀 횡 G_2(3)t(c)=1.0 N/mm.
**우리 V2_2(기지 Gf)/V2_6(GF1T) 크랙밴드가 계보 원전 방식과 정확히
일치한다.** §5.14(C) 의 "A 계수들 미기재" 는 "SiC 의 G 값들 미기재"
로 대체된다 (구조는 확보, 수치만 보정).

**(3) 점성 정규화는 원전에 있다 — §4.1 정정**

Ge Eq.29–30 Duvaut–Lions: `d^v_{n+1} = Δt/(η+Δt)·d_{n+1} +
η/(η+Δt)·d^v_n` — **우리 GAM=Δt/(η+Δt) 와 동일식.** 우리 eta 는
임의 추가가 아니었다. Zhang 본문에서 생략됐을 뿐이다.

**(4) 기지 소성의 완전한 구조 (수치 제외)**

유효응력 공간 von Mises 항복 F = σ̄_eq − σ̃_s(ε̄p), 연합유동,
등방경화 σ̃_s 는 "실험 경화곡선" (페놀릭은 Ref[27] 단행본에서;
**SiC 경화곡선은 Zhang/Ge 어디에도 없음** — V2_8 의 유일 미지수).
수치해법: 백워드 오일러 반환사상 + 일관 접선 (Ge Eq.25–28, 31–33).
손상은 등방 단일 d_m (전단 포함 1/(1−d_m)) — 우리와 동일 구조.

**(5) 대수적 귀결 — 소성만으로는 Fig.4 냉각 손상이 안 나온다**

Ge 결합구조에서 기지 손상 개시는 여전히 **유효응력 von Mises 가
X_m 에 도달**해야 한다 (φ_m = σ̄_eq/X_m ≥ 1). 소성은 σ̄_eq 를
경화응력으로 **캡할 뿐 낮출 수는 있어도 올리지 못한다.**
따라서 §5.13(C) 의 천장 계산(어떤 물성으로도 845 °C 까지 기지 응력
310 도달 불가)은 소성을 넣어도 그대로 유효하다.

- 논문 Fig.4 의 개시 ~1000-1030 °C (ΔT≈20-50 K 에 첫 손상) 는 국부
  응력집중(얀 랩)으로 설명 가능할 수 있으나, **845 °C 에서 100 %**
  (평균 1.51 MPa/K 필요) 는 공개된 물성·식으로는 불가능하다.
- 결론 강화: **Fig.4 재현에는 미공개 파라미터가 필요하다** (낮은

## 5.17 PAPERFAITH 3자 비교 — **MCRIT=1 이 기지 100 % 를 연다** (2026-08-07)

P1(=P0+MCRIT=1) / P2(=P1+Yt=50) 가 완주했다. **세 런의 기계변형률
span 이 0.8539 / 0.8538 / 0.8495 % 로 사실상 같다** — §4.1 의 속도
교란이 없으므로 **이번 3자 비교는 유효하다.** (§5.16D 의 P0-vs-GF
비교가 무효였던 것과 대비된다.)

### (A) 최대 발견 — 기지 손상률 100.00 %

| | 기지 손상률 최대 | 도달 프레임 |
|---|---|---|
| P0 (MCRIT=0) | 88.70 % | 200 (곡선 끝) |
| **P1 (MCRIT=1)** | **100.00 %** | 200 |
| P2 (MCRIT=1 + Yt=50) | 99.99 % | 198 |

**논문 Fig.A1 의 "기지 100 %" 를 처음으로 재현했다.** §5.16C 는 이
벽을 열잔류응력 크기 탓으로 돌렸는데 **틀렸다.** 필요한 것은
**논문 자신의 파손기준**이었다.

기구는 DMC(압축손상) 값이 말해 준다.

| 프레임 200 | 기지 손상률 | DMT_avg | DMC_avg |
|---|---|---|---|
| P0 | 88.70 % | 0.818 | **0.0765** |
| P1 | 100.00 % | 0.948 | **0.0138** |

- **MCRIT<0.5** (V2_4 경로): 인장 = Rankine(최대주응력/Xt),
  압축 = max(최대주응력, Mises/(√3·Xc)) + I₁ 게이트. 두 분기가
  동시에 작동하고, I₁<0 요소는 **실효 537 MPa** 문턱에 갇힌다.
- **MCRIT≥0.5** (논문 Eq.15/16): 양 분기 모두 von Mises, **I₁ 부호로
  배타 분할**, √3 없음. 인장 중 기지는 대부분 I₁>0 이므로 갇혀
  있던 요소가 전부 인장분기로 넘어가 Mises/Xt 로 판정된다.

P0 의 DMC 0.0765 → P1 의 0.0138 이 바로 "압축분기에 갇혀 있던
요소가 인장분기로 이동한" 증거다. 진단은 맞았고 처방이 틀렸다.

**단, 냉각은 여전히 못 연다.** 인장 프레임 0(=냉각 끝) 기지
손상률은 P0 60.17 / P1 59.56 / P2 58.73 % 로 **MCRIT 이 냉각을
거의 바꾸지 않는다.** 냉각 중 기지는 거의 등방인장(I₁>0)이라 두
기준이 같은 답을 내기 때문이다. **§5.13 의 냉각 벽은 그대로 유효**
하고, 이번 발견은 인장 쪽에만 적용된다.

**(F-1) P1 이 논문의 두 특징을 동시에 만족한 최초의 런이다.**
기지 손상요소율 99.88 % 이면서 저손상 꼬리(d<0.40)가 0.29 % 뿐이다.

**(F-2) 그러나 P2 의 기지 분포가 형태로는 가장 논문답다.**

**점진 손상**에 가까워졌다. Yt=50 이 얀 횡손상을 늘려 응력을
재분배시킨 간접 효과로 보인다.

**둘 중 하나가 우월하지 않다** — P1 은 sum 과 꼬리, P2 는 평균과
형태. 논문에 쓸 때 둘 다 제시하는 것이 정직하다.

**(F-3) 상한은 여전히 DMAX 0.95 다.** 세 런 모두 p95_d = 0.9500
(기지·얀 종) / 0.9000 (얀 횡). 논문이 시사하는 0.85 와 0.10 차이가
그대로 남아 있다 → **§5.16F-5 의 DMAX 후보는 살아 있다.**

**(F-4) 얀 횡은 완전 포화.** P2 위프횡 99.85 %, d<0.85 가 **0.01 %**.
논문 99.29 와 사실상 일치. 위프 종은 셋 다 평균 0.47, d<0.40 이
39~43 % 로 유일하게 넓게 퍼져 있으나 개체수가 1.4~1.7 % 뿐이라
그림에서만 눈에 띈다.

**다음 링크는 워프 종방향을 겨냥해야 한다.** 워프 종 손상은
XT·GF1T·A1T 가 지배하는데, 이 셋 중 XT=2835 는 §5.14 에서 이미
"Table 1 로 유도 가능" 으로 분류돼 있으므로 손댈 수 없다.
**GF1T 정정값 0.022728 (§5.8) 이 아직 미적용이고, 그것이 정확히
워프 종 연화를 무르게 만드는 방향이다.** P3 후보로 DMAX 보다
GF1T 가 우선한다.

## 5.18 승온 이력 (논문 Fig.6) — **300 °C 위는 완벽, 아래는 eta 잔재**

`CSIC_t500.odb` / `CSIC_t1000.odb` 의 승온 스텝을 뽑았다
(`heating_damage_500C.csv` / `_1000C.csv`). 논문 Fig.6 의 주장은
**"승온해도 손상요소율이 변하지 않는다"** 이다.

### (A) 결과

| 23 °C → 목표 | 기지 | 얀 횡(워프) | 얀 횡(위프) | 얀 종 |
|---|---|---|---|---|
| **→ 500 °C** | 71.949 → **75.150** (+3.20) | 20.990 → 28.057 (**+7.07**) | 20.699 → 27.990 (+7.29) | +0.15 |
| **→ 1000 °C** | 71.949 → **73.737** (+1.79) | 20.990 → 25.308 (**+4.32**) | 20.699 → 25.315 (+4.62) | +0.10 |
| 논문 Fig.6 | 100 → 100 (**0**) | ~88 → ~89 (**0**) | 동일 | 0 |

**두 런의 프레임 0 이 전 열에서 비트 일치한다.** 냉각 1050→23 이
두 덱에서 완전히 같다는 뜻 — §5.13(B) 에 이은 결정론 검증 통과.

### (B) 판정이 두 구간으로 갈린다

```
~300 °C 위 : 변화량 정확히 0        <- 논문과 완전 일치
~300 °C 아래: 기지 +3.2 / 얀횡 +7.1  <- 논문에 없는 상승
```

동결이 소수점 14자리까지 완전하다 (500 런은 291.8 °C 부터
`75.15018459051488` 로 고정, 1000 런은 341.9 °C 부터
`73.73681106232388`). **고온 구간은 논문 주장을 그대로 재현한다.**
문제는 승온 초기 300 °C 구간뿐이다.

### (C) 그 상승은 물리가 아니라 **eta 점성 지연의 뒤늦은 따라잡기**다

승온은 냉각으로 생긴 인장 잔류응력을 *풀어주는* 방향이므로 손상이
늘 이유가 없다. 그런데도 초기에 늘고 급정지한다. 세 가지가 이를
가리킨다.

1. **정지가 계단식이다.** 응력구동이면 온도에 따라 계속 변해야
   하는데, 목표를 따라잡는 순간 딱 멈춘다 — 완화 과도현상의 형태다.
2. **빠른 승온이 덜 늘어난다.** 두 스텝 모두 스텝시간 0→1 인데
   ΔT 는 477 vs 977 (**2.05 배**). 상승량은 기지 3.20/1.79 =
   **1.79 배**, 얀 횡 7.07/4.32 = **1.64 배** — 승온이 빠를수록
   반비례로 작다.
3. **따라잡는 데 걸린 *시간* 이 비율을 설명한다.** 동결까지 스텝시간
   0.564 vs 0.326 = **1.73 배**. 상승량 비 1.64~1.79 와 거의 같다.
   즉 늘어난 양은 온도가 아니라 **머문 시간**에 비례한다 —
   `GAM=Δt/(η+Δt)` 지연의 서명이다.

즉 냉각 중 eta 가 억눌러 두었던 손상이 승온 초기에 목표치까지
올라온 것이고, 떨어지는 목표와 올라오는 d 가 만나는 지점에서
멈춘다. **논문에는 점성 정규화가 없으므로 (§4.1) 논문 Fig.6 이
평평한 것이 당연하다.**

### (D) 실무적 파장 — **온도 비교가 오염된다**

500 °C 인장과 1000 °C 인장은 **서로 다른 손상상태에서 출발한다.**

| 500 °C 시점 | 기지 | 얀 횡 |
|---|---|---|
| 500 런 (도착) | 75.150 | 28.06 |
| 1000 런 (통과) | 73.737 | 25.31 |
| 차이 | **1.41 pp** | **2.75 pp** |

**이 차이는 온도가 아니라 승온 속도가 만든 인공물이다.** Table 3
의 온도별 비교에 그대로 실린다. §4.1 이 "인장 span 을 통일하라"
고 했는데, **승온 램프 속도도 통일 대상이라는 것이 이번에 처음
드러났다.**

**정정 방법 (덱 한 줄):** 1000 °C 덱의 승온 스텝 시간을 2 배로
주어 dT/dt 를 500 °C 덱과 맞춘다. 새 물리가 아니라 시간축 정렬이므로
논쟁 여지가 없다. 다음 배치에 반드시 포함할 것.

### (E) 논문에 쓸 문장

> 승온 구간에서 손상요소율은 약 300 °C 이상에서 완전히 일정하며
> 이는 Zhang et al. 의 Fig.6 과 일치한다. 300 °C 이하에서 관찰되는
> 소폭 증가(기지 +3.2 %p, 얀 횡 +7.1 %p)는 냉각 시 점성 정규화가
> 지연시킨 손상이 회복되는 수치적 과도현상이며, 승온 속도에
> 반비례한다(2.05 배 빠른 승온에서 1.6~1.8 배 작음).

## 5.20 기존 500/1000 런 진단 — 온도 추세가 뒤집혀 있다 (2026-08-10)

배치 준비로 t500/t1000 의 인장 곡선을 다시 열어 보니, 드라이버 목표
계산 외에 **결과 자체에서 두 가지가 나왔다.**

### (A) 드라이버 목표 산식 — 프리스트레인을 몰라도 된다

드라이버는 스텝 안에서 선형 램프이므로 `eps_mech / StepTime` 이
상수다 (두 런 모두 **9자리까지 일정**하게 확인됨). 그 값이 곧
"완주 기준 span" 이고, 프리스트레인을 거치지 않고 바로 쓸 수 있다.

```
새 목표 = 현재 목표 + (원하는 span − 현재 span)
```

| | 현재 목표 | 현재 span | **새 목표 (span 0.008495)** |
|---|---|---|---|
| 500 °C | 0.0041 | 0.00528726 | **0.0073077** |
| 1000 °C | 0.0052 | 0.00531101 | **0.0083840** |

`extract_tension.py` 가 이 세 줄을 이제 자동으로 찍는다.

**역산 프리스트레인이 물리와 정합한다** — 1050 °C 무응력 기준
(1050−T) 로 나누면 세 온도가 −2.16 ~ −2.43e−6 으로 같은 크기다.
독립적으로 얻은 세 값이 한 직선에 놓이므로 산식이 옳다.

| T | 프리스트레인 | /(1050−T) |
|---|---|---|
| 23 °C (P2) | −0.0024950 | −2.43e−6 |
| 500 °C | −0.0011873 | −2.16e−6 |
| 1000 °C | −0.0001110 | −2.22e−6 |

**span 만으로는 부족하다 — 스텝시간도 맞춰야 한다.** 점성 정규화가
보는 것은 **속도 = span / 스텝시간**이다. P 시리즈는 인장 스텝시간이
**2.0** (`.sta` 의 "2.00 / 2.00" 로 확인) 인데 500/1000 덱은 1.0 이라,
span 만 맞추면 속도가 **2 배** 어긋난다. 새 덱은 스텝시간도 2.0 으로
간다. (현재 구 런의 속도는 P2 의 1.24 / 1.25 배였다 — 아래 (C) 의
500 vs 1000 비교가 유효한 이유이기도 하다: 둘끼리는 1 % 안에서 같다.)

### (B) 500 °C 런은 **완주하지 않았다** — 스텝시간 0.7702 / 1.0

기존 500 °C 결과는 인장 스텝의 77 % 지점에서 끝났다. 최대점
129.23 MPa @ 0.1958 % 는 국부최대(연화 확인)라서 **강도값 자체는
유효**하지만, 그 뒤 거동과 HOM 강성은 없거나 불완전하다.
§5.9 의 500 °C 강성값을 인용할 때 이 점을 확인할 것.

### (C) **온도 추세가 논문과 반대다** — 이번 배치의 진짜 이유

| 온도 | 우리 (구 카드) | 논문 FE | 논문 실험 |
|---|---|---|---|
| 23 | 118.7~123.9 (P0~P2) | 128.45 | 116.17 ± 8.78 |
| 500 | **129.23** @ 0.1958 % | 179.42 | 160.19 ± 14.83 |
| 1000 | **122.19** @ 0.1495 % | 199.15 | 173.28 ± 12.94 |

**논문은 23 → 1000 °C 에서 강도가 +55 % 오른다. 우리는 사실상
평평하고, 500 → 1000 구간은 오히려 −5.4 % 로 내려간다.**

이 500 vs 1000 비교는 **§4.1 조건을 만족한다** — 두 런의 span 이
0.00528726 vs 0.00531101 로 **0.4 % 차이**밖에 안 나기 때문이다.
즉 하중속도 교란으로 변명할 수 없는, 유효한 비교다.

23 °C 만 span 이 0.008495 로 달라 세 점 전체 비교는 아직 무효이고,
그래서 P2 카드 온도 시리즈를 span 통일해 다시 돌린다.

**최대점 변형률도 반대 방향이다**: 논문 0.32 / 0.26 / 0.31 %
(온도와 무관하게 비슷) 인데 우리는 0.25 / 0.196 / 0.150 % 로
**온도가 오를수록 짧아진다.** 고온에서 더 취성이 되고 있다는 뜻으로,
물리적으로 C/SiC 의 알려진 거동과 어긋난다. 새 배치가 이것도
바꾸지 못하면 **온도 의존 물성(고온 강도·CTE) 자체를 의심해야 한다.**

## 5.23 온도 의존 물성 감사 — **가설 기각. 그래서 범인이 좁혀진다** (2026-08-12)

§5.21C 가 남긴 두 용의자 중 첫째("고온 물성 카드를 안 쓰고 있는 것
아닌가")를 해석 없이 소스·덱만 읽어 판정했다.
도구: `verification/audit_temperature_props.py` (재실행 가능).

### (A) 세 층 전부 "온도 의존 0"

**1. UMAT 오염추적.** `TEMP`/`DTEMP` 에서 출발해 대입문을 따라
고정점까지 전파했다. 원소 단위(`SV(12)`)·루틴 단위로 구분해
과전파를 막았다. 결과가 **전부**다:

```
[KYARN_UPDATE]   TEND=TEMP+DTEMP -> SV(12), SV(15)
[KMATRIX_UPDATE] TEND=TEMP+DTEMP -> SV(8),  SV(13)
물성/거동(E, XT, C0, CTAN, STRESS...)에 닿는 것: 없음
```

**온도는 손상개시온도를 기록할 뿐 어떤 물성도 건드리지 않는다.**

**2. 덱 물성카드.** 세 덱 × 두 재료 전부 데이터행 1 줄, `dependencies=`
없음 → 온도표 0 건. 덧붙여 **`*User Material` 은 Abaqus 문법상 온도표를
가질 수 없다** — UMAT 물성을 온도 의존으로 만들려면 코드 안에서 TEMP 로
직접 보간하는 길밖에 없고, 우리는 그것을 안 한다(위 1).

**3. 논문 Table 1/2.** 14 항목 전부 단일값. 온도 의존으로 준 값 **0 건**.
3.2.3 절은 α_m 을 명시적으로 "temperature independent" 라고 쓴다.

### (B) 판정 — 기각. 그리고 그 기각이 문제를 좁힌다

**우리 0, 논문 0 — 양쪽이 일치한다. "고온 물성 누락" 은 원인이 아니다.**
누락할 것이 애초에 없다. 32 코어를 태우기 전에 30 분으로 끝났다.

여기서 논리가 한 칸 조여진다. 양쪽 다 물성이 온도 무관이고,
양쪽 다 1050→23→승온→인장이며(§5.11A), 양쪽 다 손상이 비가역이면,
**인장 시작 시점에 온도에 따라 달라지는 것은 열잔류응력 상태 하나뿐이다.**

```
논문: 잔류응력 완화  ->  강도 +55 %
우리: 잔류응력 완화  ->  강도 -7.9 %
```

**같은 입력 변화에 부호가 반대다.** 더 이상 "온도 물리 일반" 이 아니라
**"잔류응력 완화가 왜 우리에게는 손해인가"** 라는 한 문장짜리 질문이다.

### (C) 답 — 잔류응력은 두 상에 **반대 부호**의 여유를 준다

| 상 | 23 °C 잔류 | 승온하면 | 강도에 |
|---|---|---|---|
| 기지 | **+156.7 MPa 인장** | 완화 → 여유 **증가** | **+** |
| 얀 축방향 | **−341.8 MPa 압축** | 완화 → 여유 **감소** | **−** |

**어느 상이 강도를 결정하느냐가 부호를 정한다.** 그리고 우리가 어느
쪽인지는 §5.22A 가 이미 답했다 — 1000 °C 에서 기지는 최대점까지
60.59 → 60.59 로 **미동도 없고**, 위프 횡이 41 → 68 % 로 움직인다.
**우리 강도를 정하는 것은 기지가 아니라 얀이다.** 그래서 완화가
얀 여유만 깎고 돌려받는 것이 없다.

논문은 반대다. 논문의 워프 종손상은 60.67 → 32.12 % 로 **줄어들고**
(§5.21D), 본문은 그 원인을 반복해서 전단/응력집중이라 쓴다
(§5.14 A2′). 전단은 열팽창 불일치에서 나오므로 승온하면 함께
풀린다 → 하중축 얀이 덜 깨진다 → 강해진다. **논문 기구는
자기무모순으로 닫힌다.**

### (D) 그 차이를 만든 단일 숫자 — XT=421

얀 종방향 인장 기준은 Eq.11 그대로다(V2_7 확인):

```
FI1T = sqrt( (SE1/XT)^2 + (SE4/S12)^2 + (SE5/S13)^2 )
```

`XT` 만 421 이고 `S12=S13=120` 이다. **σ11 항과 전단항의 상대 크기가
XT 하나로 정해진다.**

기존 데이터로 σ11 지배를 정량화할 수 있다. §3.2 의 보정 회귀
`σ = 0.11565·XT + 80.02` 에서 XT=421 일 때 σ=128.71,

```
탄성도 = (dσ/dXT)(XT/σ) = 0.11565 x 421/128.71 = 0.378
순수 σ11 기준선 = XT/(XT+341.8) = 421/762.8 = 0.552
비 = 0.378/0.552 = 0.69
```

**최대점을 정하는 기구의 약 69 % 가 σ11 이다** (나머지가 XT 에
둔감하다는 가정 아래의 개략 분해 — 정밀값 아님).

논문 자신의 값을 쓰면 이 비가 뒤집힌다. Table 1 의 X_f,t=3580 에
Chamis 를 적용하면 X_y,1t = 0.79194 × 3580 = **2835 MPa** 이고,
같은 응력 상태(SE1≈421)에서 σ11 항은

```
(421/2835)^2 = 0.022   ->  기준값의 2.2 %
```

**사실상 0 이다. XT=2835 에서는 얀 종방향 파괴가 전단으로만 일어난다 —
논문이 서술하는 그 기구다.** 즉 XT=421 은 강도 숫자를 맞추는 대신
**파괴 기구를 σ11 로 바꿔놓았고, 그 바뀐 기구가 온도 추세의 부호까지
뒤집고 있다**는 것이 §5.14(A2′)에서 여기까지 이어지는 한 줄기다.

   나온다"는 뜻이 되어 이 프로젝트에서 가장 큰 결과가 된다.**

### (D) t23 추출 함정 — 물리 이상 아님, 이름이 한 세대 낡았다

**증상**: t23 만 냉각·인장 내내 `Warp/Weft_PctTrans = 0`,
`DYTT_avg/max = 0`. t500/t1000 은 정상(냉각 끝 34.23/33.86 %).

**원인 사슬** (전부 실측):
1. V2_7P 가 얀 `SV(2)↔SV(3)` 을 맞바꿨다 (SDV2=횡손상 표시,
   §5.19). V2_7D 도 같은 배치다.
2. t23 덱(구 Try_P2 계보)만 `*Depvar` 에 **옛 배치 이름**이 붙어
   있다: 슬롯2=DY1C, 슬롯3=DYTT. t500/t1000 덱(P2 온도 시리즈에서
   재생성)은 이름이 없다.
3. 추출기는 이름을 번호보다 먼저 잡는다. 그래서 t23 에서
   `SDV_DYTT` = 슬롯 3 = **지금은 D1C** (냉각 중 |−341.8|/1956=0.17
   이라 항상 0) 를 "횡손상"으로 읽었다. 이름 없는 t500/t1000 은
   번호 폴백 SDV2 = 진짜 DTT 를 읽어 정상.

**교차 검증**: t23 vs t500 냉각의 matrix/warpL/weftL 은 소수점
끝자리까지 동일(물리 동일 증명), t23 YARN0 `PctDamaged`(슬롯 10
DYT 경유, 이름 불변) = 34.35 % ≈ t500 냉각 끝 trans 34.33 % —
손상은 있고 열만 어긋났다. SDV17 은 이름 없이 덧붙인 슬롯이라
`SDV17` 번호로 잡혀 **전 온도에서 유효** (B 의 표 포함).

**P2 이전 데이터는 전부 무사하다**: 구 P2 odb 는 V2_7(옛 배치) +
옛 이름 = 짝이 맞았고, P2T500/P2T1000 은 이름 없는 덱 + 번호 폴백.
어긋나는 조합은 "옛 이름 덱 + V2_7P 이후 UMAT" = **P3 t23 하나뿐**.

**1차 수정은 실패했다 (2026-08-18, 기록으로 남긴다).** "이름 없이
덧붙인 17번 슬롯이 `SDV17` 로 뜬다"를 낡음의 표식으로 삼았는데,
`check_sdv_fields.py` 로 실제 odb 를 읽어보니 **`SDV_YSHR1T` 였다.**
`patch_depvar_yarn.py` 가 이름줄 있는 덱에는 17번 설명줄까지
붙이기 때문이다(132행). 즉 t23 덱은 **"옛 이름(2/3) + 이름 있는
17번"** 이라 그 표식이 원리적으로 안 생긴다. 가드는 한 번도
발동하지 않았고, 재추출 결과가 그대로였던 이유다.

**왜 이름만으로는 불가능한가.** 옛 배치와 새 배치는 *이름 집합이
같고 슬롯 번호만 다르다* (옛 2=DY1C·3=DYTT / 새 2=DYTT·3=DY1C).
odb 필드 키에는 번호가 없으므로 **odb 만 보고는 원리적으로 구분할
수 없다.**

**2차 수정 (확정)**: 판정 근거를 odb 가 아니라 **덱의 `*Depvar`
번호줄**로 옮겼다. 추출기 4개 + 진단기에 `read_yarn_sdv_layout()` /
`find_deck()` / `--sdv-layout auto|old|new` 를 넣어, odb 옆 `.inp`
를 읽어 슬롯 2/3 이름으로 배치를 판정하고 화면에 찍는다. 덱을 못
찾으면 `new` 로 가되 경고한다. 단위시험 27개 통과.

**근본 원인도 막았다**: `patch_depvar_yarn.py` 가 17번을 붙일 때
슬롯 2/3 이 옛 배치면 **같이 바로잡는다**(`fix_slot23`). 이 함정을
만든 것이 이 도구였다. 자체시험 12개(신규 6개 포함) 통과.

**t23 odb 는 재해석 불요, 재추출만 필요.**

**실측 증거** (`check_sdv_fields.py`, 냉각 끝 frame 101, YARN0,
n=20734): `SDV_DY1C` avg 0.276708 / max **0.900000**(=DMAXT 클램프)

`SDV_DYT`(조합 횡, 슬롯 10, 이름 불변) avg 0.276769 로 `DY1C` 와
일치. 필드 키 31개 = 기지 14 + 얀 17 로 실측치와 정확히 맞는다.

## 5.27 23 °C 강성 60 vs 92 GPa — **이상이 아니다. 잔류응력이다** (2026-08-18, 해석 불필요)

### 인장 시작 시점(frame 0)의 국부 S11 [MPa]

| T | Matrix | Warp | Weft | 측정 E0 |
|---|---|---|---|---|
| 23 °C | **+170.8** | **−356.5** | −357.4 | **60 GPa** |
| 500 °C | +79.5 | −167.9 | −167.8 | 92 GPa |
| 1000 °C | **+7.2** | **−15.3** | −15.3 | 93 GPa |

RVE 는 1050 °C 에서 무응력이고, 23 °C 까지 냉각하며 CTE 불일치로
**Matrix 인장 / Yarn 압축** 잔류응력이 쌓인다. 다시 가열하면 풀린다 —
1000 °C 에서는 사실상 0 이다.

### 그래서 23 °C 가 무른 것은 당연하다

23 °C 에서 Warp 는 **−356 MPa 에서 출발**해 인장으로 넘어가기까지
약 0.14 % 변형률을 쓴다 (P3 기준 frame 30 −47.2 → frame 40 +48.5).
E0 는 0~0.05 % 구간에서 재므로 **전 구간이 "실이 아직 압축인" 영역**

1000 °C 는 −15 MPa 에서 출발해 0.086 % 만에 +191 MPa 로 인장에
들어간다 → 실의 온전한 강성이 즉시 참여한다 → 93 GPa.

**즉 60 vs 92 는 버그가 아니라 절차의 결과다.** 그리고 우리 23 °C
값은 논문 자신의 눈금 판독치(~50–60 GPa, §A5)와 맞는다.

### 23 °C 강도 문제와 **같은 뿌리**다

같은 잔류압축이 강도에도 그대로 작용한다. 어떤 인가변형률에서든
23 °C 의 Yarn 응력은 잔류압축만큼 낮으므로, 실이 훨씬 늦게 끊어진다.
실측이 그대로다 — 23 °C 는 0.85 % 에서 Warp 381.7 MPa 인데,
1000 °C 는 0.34 % 에서 이미 404 MPa 다.

**§5.26 의 "23 °C 만 봉우리가 없다" 와 §5.27 의 "23 °C 만 무르다"
는 하나의 현상이다: 관측창(0.85 %) 안에서 실이 인장을 충분히 못
받는다.** 논문 23 °C 는 0.32 % 에서 파단하므로, 논문 쪽 잔류응력이
우리보다 작거나 실이 더 일찍 끊어져야 한다.

### 다음 질문 (뒤집힌 형태)

"왜 23 °C 가 무른가" 가 아니라 **"논문도 고온에서 초기 기울기가

  다르다는 뜻이고, CTE·무응력온도 감사가 다음 배치가 된다

**해석 없이 논문 그림만으로 갈린다.**

거동이며, 우리는 오히려 덜 오른다. **"23 °C 가 무르다"는 이탈이
아니다 — 이 항목은 닫는다.** 23 °C 는 55 vs 59.6 으로 논문과 맞고,
고온은 우리가 논문보다 16~7 % 무르다(같은 방향, 작은 크기).

### (B) 진짜 원인 — 인장 **시작 시점**의 손상이 논문의 절반이다

Fig.13/15 는 손상요소율 곡선을 통째로 준다. strain=0 에서 읽으면:

| | matrix | warpL | warpT | weftL | weftT |
|---|---|---|---|---|---|
| **논문 (Fig.13/15 둘 다)** | **100** | ~1 | **~88** | ~0 | **~88** |
| 우리 P4T500 | **60.60** | 0.31 | **41.26** | 0.32 | 41.34 |
| 우리 P4T1000 | 60.60 | 0.31 | 41.27 | 0.32 | 41.34 |
| 우리 P4 (23 °C) | 58.73 | 0.19 | 34.29 | 0.18 | 33.95 |

**논문은 인장을 시작하기도 전에 Matrix 가 100 %, 얀 횡손상이 88 %
에 도달해 있다. 우리는 60.6 % 와 41.3 % 다.** 즉 논문의 냉각이
우리 냉각보다 훨씬 많은 손상을 만든다 (§5.13 이 세 손잡이로
공략했다가 전부 실패한 그 항목).

**이것이 변형률 배율 2.65~2.96 배의 정체다.** 논문이 냉각으로
이미 끝낸 일을 우리는 인장 중에 하고 있다. 그래서 같은 손상상태에
도달하는 데 3 배 가까운 변형률이 든다.

### (C) 그래서 우선순위가 바뀐다

| 항목 | 상태 |
|---|---|
| 23 °C 강성 60 vs 92 | **닫힘** (A) — 이탈이 아니다 |
| 500/1000 °C 강도 | **닫힘** (§5.26) — −2.7 % / −0.1 % |
| 곡선 재경화 | 열림 — A1T 로는 못 고침(§5.26B) |
| 23 °C 강도·봉우리 부재 | 열림 |
| **냉각 손상 100 %/88 % 미달** | **열림. 이제 1순위** — 위 둘의 공통 뿌리 |

§5.13 은 강도 손잡이 셋(Weibull·MCRIT·Yt)으로 냉각 손상을 올리려다
전부 실패했고 "3D RVE 에서 원리적으로 불가능" 으로 결론냈다. 그
결론을 재검토해야 한다 — 당시엔 이것이 **인장 결과까지 지배한다**는
정량 근거가 없었으나, 이제 (B)가 그것을 준다.

## 5.29 §5.13 재검토 — **결론은 유지. 논증 하나를 고치고 수치를 붙였다** (2026-08-18, 해석 불필요)

§5.28(C) 가 냉각 손상을 1순위로 올렸으므로, "3D RVE 에서 원리적으로
불가능" 이라던 §5.13 의 결론을 다시 검증했다. 새 해석은 쓰지 않았다.

### (A) §5.13(C) 의 "Voigt 천장" 논증은 **틀렸다**

§5.13(C) 는 얀 E2→∞ 에서도 기지 응력 상승률이 **0.411 MPa/K 가
천장**이라 했다. 그러나 우리 FE 의 실측 개시온도가 그것을 넘는다:

| | 상승률 | 근거 |
|---|---|---|
| Voigt 체적평균 (현 E2) | 0.323 | §5.13(C) |
| Voigt E2→∞ ("천장") | 0.411 | §5.13(C) |
| **실측 기지 개시 592.2 °C** | **0.677** | 310/(1050−592.2) |

**Voigt 는 체적평균이고 손상은 적분점별로 판정된다.** 국부 응력집중이
평균을 넘으므로 "천장" 은 개시에 적용되지 않는다. 실제로 우리 FE 는
그 값을 68 % 초과한다.

### (B) 그러나 결론은 **더 강하게** 성립한다

100 % 도달은 **가장 응력이 낮은 점**도 X_m 을 넘어야 한다는 뜻이다.
논문 요구 1.512 MPa/K 는 **우리의 최대 국부값 0.677 의 2.18 배**다.
즉 "가장 안 받는 점" 이 "우리의 가장 많이 받는 점" 보다 2.2 배 빨리
올라야 한다 — 응력집중이 있는 구조에서 불가능한 요구다.

논증을 바꿔야 하지만 판정은 그대로다.

### (C) 새 정량치 — 유효 기지 강도가 얼마여야 하는가

냉각 곡선을 **"문턱 상승률 r_th = 310/ΔT 를 넘는 적분점 비율"**
로 다시 읽으면 국부 응력 분포의 누적분포가 된다.

| r_th [MPa/K] | 손상률 [%] | T [°C] |
|---|---|---|
| 0.677 | 2.19 | 592 |
| 0.467 | 38.15 | 387 |
| 0.381 | 46.66 | 236 |
| **0.302** | **58.75** | **23 (끝)** |

측정 꼬리 기울기 **−152.8 %/(MPa/K)** 로 외삽하면:

| 목표 | 필요한 r_th | **필요한 유효 X_m** |
|---|---|---|
| 88 % (논문 얀 횡) | 0.110 | **113 MPa** |
| 100 % (논문 기지) | 0.032 | **33 MPa** |

**논문 자신의 Table 2 기지 인장강도는 310 MPa 다.** 즉 논문 Fig.4 를
내려면 유효 강도가 자기 Table 2 값의 **1/3 ~ 1/10** 이어야 한다.

*주의*: 로그-로그 적합도 시도했으나 잔차가 양 끝에서 +300 % / +28 %
라 외삽 근거로 못 쓴다 (그 적합은 X_m=278 MPa 라는 낙관적 값을 준다).
**신뢰할 것은 측정 꼬리 기울기 쪽이다.** 또한 손상 후 응력 재분배를
무시한 근사이므로 자릿수 판단용으로만 쓴다.

### (D) 집계 정의 가설 — **이번에 확실히 닫았다**

§5.13(E)-2 는 "damage element ratio 의 집계 정의가 다를 가능성" 을
d 문턱 차이만 보고 "거의 닫혀 있다" 고 넘겼다. **덜 검토된 지점이
있었다**: 논문이 *요소* 를 세고 우리가 *적분점* 을 센다면, 적분점
58.75 % 가 요소 기준으로는 훨씬 높을 수 있다 (8점 요소라면 무작위
분포 가정에서 99.9 %).

**덱을 확인했다: `*Element, Type=C3D4`.** 사면체 1적분점이므로
**적분점 = 요소이고 이 경로는 완전히 닫힌다.** §5.13 보다 나은
근거로 같은 결론에 도달했다.

### (E) 소성은 잊힌 것이 아니라 기각된 것이다

§5.13(E) 가 "다음 사이클은 기지 소성을 겨냥해야 한다" 고 했는데
P3/P4 는 얀 파라미터로 갔다. 확인 결과 **§5.15(5) 가 그 사이에
소성을 해석적으로 기각했다**: 소성은 σ̄_eq 를 경화응력으로 **캡할
뿐 올리지 못하고**, 손상 개시는 여전히 σ̄_eq ≥ X_m 을 요구한다.
따라서 냉각에는 무효다. 경로 선택은 옳았다.

**단, §5.15(5) 는 소성의 값어치가 냉각이 아니라 인장 곡선에 있다고
명시했다** — 기지 응력 캡, 비선형 형상, 파괴변형률. 그것이 §5.28 이
남긴 두 미결(재경화·23 °C 강도)과 정확히 겹친다.

### (F) 재검토 결론

| 항목 | 판정 |
|---|---|
| 냉각 손상을 논문 수준으로 올리기 | **불가능 확정.** 공개 물성으로는 X_m 이 1/3~1/10 이어야 함 |
| §5.13(C) 논증 | **수정함** — Voigt 천장은 개시에 부적용. 결론은 유지 |
| 집계 정의 | **완전히 닫힘** — C3D4 1적분점 |
| 소성 | 냉각엔 무효(§5.15), **인장엔 유효 — 다음 후보** |

**냉각 격차는 더 쫓지 않는다. 논문 재현의 한계로 기록한다.**
이것은 사용자 본인 논문에 쓸 수 있는 결과다: **논문 Fig.4 는 같은
논문의 Table 2 물성과 양립하지 않는다.**

## 6. 논문으로 쓸 때 반드시 명시할 것

1. **얀 강도 7개와 손상 파라미터 전부가 논문에 없다.** 강도 일치는
   역보정 결과이며 예측 성능이 아니다.
2. **Weibull 산포는 논문에 없는 추가 모델링이다.**
