## 1. 구성방정식 (Constitutive model)

### 1.1 기지 인장 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.15: von Mises 등가 유효응력 / X_m,t , 조건 I₁ ≥ 0 |
| V2_4 이하 | 최대주응력(Rankine) / X_m,t , I₁ 게이트 없음 |
| V2_5 이후 | `PROPS(24)=MCRIT=1` 로 논문 Eq.15 그대로 구현 |
| 잔여 차이 | 논문은 I₁=0 에서 하드 스위치. 구현은 ±BAND(=0.1·Xc) 완만 램프 |

램프를 쓴 이유: I₁=0 하드 스위치는 구성방정식의 불연속이며, 실제로
V2_3 에서 260.2 °C 발산의 원인이었다. BAND→0 이면 논문과 일치한다.

**미확인**: 이 변경이 손상량을 늘리는지 줄이는지 아직 실측 안 됨.
냉각 직후 기지는 Mises 170.4 / MaxPrin 201.9 로 **Mises 가 더 작아서**
인장 손상이 오히려 줄어들 가능성이 있다. `23C_PAPERCRIT` 덱으로 판정 예정.

### 1.2 기지 압축 파손기준 — **해결됨 (V2_5)**

| | 내용 |
|---|---|
| 논문 | Eq.16: von Mises / X_m,c , 조건 I₁ ≤ 0 |
| V2_4 이하 | `max( 최대주응력/Xc , Mises/(√3·Xc) )` |
| 문제 | **√3 이 논문에 없다.** 압축 기준이 1.73배 느슨했다 |
| V2_5 이후 | 논문 Eq.16 그대로 |

고온에서 기지가 잔류압축으로 전환되므로 500/1000 °C 결과에 직접 영향.

### 1.3 기지 소성 — **미구현**

논문은 기지에 탄소성-손상 모델(Eq.6~10)을 쓴다. 현재 모델은 **탄성-손상만**
구현했다. 소성은 응력을 낮추고 재분배 경로를 바꾸므로, 잔류응력 분포와
손상 위치에 영향이 있을 수 있다. 미구현 사유: 구현 우선순위.

### 1.4 얀 종방향 손상진화 — **부분 해결 (V2_6)**

| | 내용 |
|---|---|
| 논문 | Eq.17/18 혼합 선형-지수형 |
| 현재 | 단순 지수형 `d = 1 − exp[A(1−r)]/r` |
| V2_6 추가 | `PROPS(32)=GF1T` 크랙밴드 정규화 |

V2_5 까지 얀 종방향에는 크랙밴드 정규화가 없어서 연화가 요소 하나로
국부화됐다. 이것이 **eta 비수렴과 메쉬 비수렴의 공통 원인**이었다.

실측된 eta 비수렴:

| eta | 최대응력 | halving당 변화 |
|---|---|---|
| 1.00× | 160.490 MPa | — |
| 0.50× | 154.558 MPa | −3.70% |
| 0.25× | 147.678 MPa | **−4.45%** (커짐 = 수렴 안 함) |

V2_6 의 재료점 검증(`verify_yarn_crackband.py`)에서 요소크기
0.0285~0.2000 mm 범위에 대해 소산에너지 편차 **1.00000배**, GF1T 대비
오차 **0.000%** 로 메쉬 무관성이 확인되었다.

**남은 차이**: Eq.17/18 의 혼합 선형-지수 형태는 여전히 미구현.

### 4.1 점성 정규화 — 논문에 없음

언급이 없다. **결과가 하중속도에 의존**하게 되므로, 서로 다른 목표변형률로
돌린 해석은 비교할 수 없다.

### 5.3 파손기준 가설의 기각 (냉각 odb 진단, 2026-08-04)

`diagnose_cooling_criterion.py` 로 CSIC_t23.odb 의 냉각 Step 102 프레임을
전부 읽어 기지 적분점 91,554 개의 최대주응력과 von Mises 를 직접 비교했다.

| T [°C] | MaxPrin avg / p99 / max | Mises avg / p99 / max | Xm=310 초과율 MaxPrin / Mises |
|---|---|---|---|
| 846.4 | 90.9 / 130.7 / **140.0** | 77.1 / 146.4 / **155.5** | **0.00% / 0.00%** |
| 620.5 | — | — | 0.003% / 0.006% (최초 개시) |
| 427.9 | 254.8 / 405.5 / 520.1 | 214.9 / 427.7 / 537.7 | **20.42% / 16.75%** (최대) |
| 23.0 | 191.9 / 382.5 / 492.5 | 167.5 / 475.7 / 760.9 | 7.05% / 8.64% |

**결론: 파손기준은 845 °C 갭의 원인이 아니다.**

- 845 °C 에서 **가장 응력이 높은 단 하나의 적분점조차** MaxPrin 140.0 /
  Mises 155.5 MPa 로, Xm=310 의 45% / 50% 에 불과하다. 어느 기준을 써도
  손상은 0% 다.
- Mises/MaxPrin 비는 평균 0.848, p99 1.12~1.24 다. 즉 von Mises 는
  평균적으로는 **덜** 가혹하고 핫스팟에서만 더 가혹하다. 23 °C 에서
  기준을 바꿔도 초과율은 7.05% → 8.64% (+1.59 pp) 로 바뀔 뿐이다.
- **I1 ≥ 0 인 적분점이 전 온도구간에서 99.95% 이상**이다. 즉 논문
  Eq.15(인장 분기)가 사실상 항상 지배하고 Eq.16 은 냉각 중 발동하지
  않는다. V2_5 의 MCRIT=1 경로는 논문 충실도 목적으로는 유지할 가치가
  있으나 손상률 갭은 해결하지 못한다.
- (2026-08-04 감사) V2_5/V2_6 의 MCRIT=1 완만밴드는 |I1|<0.1Xc 에서
  두 분기를 동시에 희석하는 결함이 있었다 (I1=0 에서 개시응력 2배).
  **V2_7 에서 지배가중치 정규화로 수정** — MCRIT=1 을 처음 실전 투입할
  때는 반드시 V2_7 을 쓸 것. 완료된 해석은 전부 MCRIT 미사용이라 무영향.

**Weibull 산포와의 정합성 확인.** 진단은 Xm=310 고정으로 세지만 UMAT 은
요소마다 Weibull(m=5.1, 평균 310, σ0=337.2) 로 샘플링한다. 평균응력에
Weibull 파손확률을 적용하면

| T [°C] | 평균 MaxPrin | Weibull 예측 손상률 | FE 실측 |
|---|---|---|---|
| 846.4 | 90.9 | 0.125% | **0.147%** |
| 427.9 | 254.8 | 21.3% | 20.42% |
| 23.0 | 191.9 | 5.48% | 7.05% |

세 온도 모두 일치한다. **845 °C 의 0.147% 는 Weibull 하단 꼬리
(최약 요소 기대강도 35.9 MPa) 로 완전히 설명된다.**

**남은 원인은 잔류응력 크기 자체다.** 845 °C 에서 손상률 ~100% 가
되려면 평균 Xm 이 **58~62 MPa (현재의 0.19 배)** 여야 하는데, 이는
논문 Table 2 의 310 MPa 와 정면으로 배치된다. 따라서 논문 쪽 기지
잔류응력이 우리보다 크다고 보는 편이 타당하다.

| 항목 | 값 |
|---|---|
| 모델 응력 증가율 (1050→845 °C) | 90.9/205 = **0.443 MPa/K** |
| 1축 완전구속 상한 E_m·Δα | 350000 × 3.43e-6 = 1.20 MPa/K |
| 모델의 구속효율 | **37%** |
| 845 °C 에서 310 MPa 도달에 필요 | **1.51 MPa/K** |
| 등2축 구속 E_m·Δα/(1−ν) | 1.20/0.80 = **1.50 MPa/K** |

논문이 요구하는 1.51 MPa/K 는 **등2축 완전구속** 값과 거의 정확히
같다. 우리 RVE 는 그 30% 밖에 안 나온다.

### 5.4 원인 규명: CTE 가 아니라 강성 배분이다

`residual_stress_budget.py` 로 "우리가 바꿀 수 있는 물성" 을 전부
흔들어 봤다 (등변형률 3상 모델: 기지 / 하중축 얀 / 직교 얀).

| Schapery | 3.952e-6 | 5.48e-7 | 0.313 |

세 식 모두 α₂ ≥ 3.33e-6 이라 기지 4.5e-6 과의 차가 최대 1.17e-6
이다. **최대라도 목표의 21%.** Schapery 는 오히려 더 나쁘다.

**(2) 축방향 CTE 를 섬유값까지 낮춰도 안 된다**

| α₁ [1/K] | 잔류응력률 | 목표 대비 |

| 1.071e-6 (현재) | 0.323 | 21% |

**(4) 진짜 원인**

```
기지     Em = 350 GPa
얀 축방향 E1 = 255 GPa   (기지의 0.73배)
얀 횡방향 E2 =  44 GPa   (기지의 0.13배)   <-- 8배 무르다
```

**보강재가 기지보다 무르면 기지를 구속하지 못한다.** 기지가 제
마음대로 수축하고 얀이 끌려간다. 잔류응력이 등2축 완전구속의 30%
밖에 안 생기는 구조적 이유이며, **논문 Table 1/2 물성의 직접적
귀결이지 우리 구현의 오류가 아니다.**

> **앞선 추정 정정.** 5.3 절 초안에서 "1순위 용의자는 얀 횡방향
> CTE" 라고 적었으나 (1)에서 기각되었다. CTE 를 어떻게 바꿔도
> 목표의 21~29% 를 넘지 못한다. 이 항목으로 FE 를 돌릴 필요는 없다.

**따라서 이 항목은 "재현 실패" 가 아니라 "논문 물성으로는 도달할 수
없는 값" 으로 논문에 명시하는 것이 옳다.** 남은 설명 후보:

- (a) 논문의 100% 가 d>0(부분손상) 집계일 가능성
- (b) 논문이 기지 소성/크리프를 넣어 응력 이력이 다를 가능성
- (c) 논문이 섬유/기지 계면 손상을 별도로 세었을 가능성

## 5.5 사전등록 예측 — job B (noTRS) 가 나오기 전에 적는다

결과를 본 뒤에 설명을 맞추면 어떤 결과든 설명이 된다. 그래서 **숫자를
먼저 박아둔다.** job B 는 얀 CTE 를 기지와 같게 만들어 열잔류응력을
0 으로 없앤 23 °C 인장이다.

**측정된 입력 (FE 실측):**

| 항목 | 23 °C | 500 °C |
|---|---|---|
| 얀 축방향 잔류응력 | −341.8 MPa | −151.2 MPa |
| 기지 잔류응력 | +156.7 MPa | +66.9 MPa |
| 거시 최대응력 | 129.12 (하한) | 129.23 |

**가설 A — 강도는 전적으로 "얀 잔류압축 여유분" 이 만든다.**

얀이 XT=421 에 닿으려면 −341.8 에서 762.8 MPa 를 올라와야 한다.
잔류응력이 없으면 421 MPa 만 올라오면 된다. 거시응력이 얀 응력증분에
비례한다면

```
sigma_noTRS = 129.12 x 421.0 / 762.8 = 71.3 MPa
```

**가설 B — 잔류응력은 강도에 거의 기여하지 않는다.**

```
sigma_noTRS ~ 129 MPa  (거의 변화 없음)
```

**판정 기준**

| job B 실측 | 결론 |
|---|---|
| ~71 MPa | 가설 A 확정. 500 °C 미강화는 여유분 상실로 완전히 설명됨 |
| 71~129 사이 | 두 기구가 공존. 위치가 곧 기여도 |
| ~129 MPa 이상 | 가설 A 기각. 다른 기구를 찾아야 함 |

**주의 — 가설 A 는 이미 500 °C 에서 한 번 어긋났다.** 같은 선형
스케일링을 500 °C 에 적용하면 129.12 × 572.2/762.8 = **96.9 MPa** 를
예측하는데, 실측은 **129.23 MPa** 였다. 즉 여유분이 줄었는데도 강도가
안 떨어졌다.

상쇄 기구가 있다는 뜻이다. 유력한 후보는 **기지 잔류응력 완화**다.
승온하면 기지 여유가 늘어(+156.7 → +66.9) 기지 손상이 늦게 시작되고,
그래서 복합재가 더 뻣뻣해진다. 실제로 초기 접선계수가 **62.5 → 90.1
GPa (+44%)** 로 올랐다. 얀 여유분 감소(−)와 기지 손상 지연(+)이
거의 정확히 상쇄되어 129 MPa 로 같아진 것으로 보인다.

job B 는 이 상쇄를 깬다. 잔류응력을 **양쪽 다** 0 으로 만들기 때문에
얀 여유분도 없고 기지 손상 지연도 없다. 따라서

- 71 MPa 에 가까우면 → 얀 여유분이 지배
- 129 MPa 에 가까우면 → 기지 손상 지연이 지배 (얀 여유분은 상쇄됨)

**어느 쪽이든 논문 4.2/4.3 절(열잔류응력의 효과)에 직접 쓸 수 있는
정량 데이터가 된다.**

### 5.6 job B 결과 — 두 가설 모두 기각 (2026-08-05)

| | 예측 | 실측 |
|---|---|---|
| 가설 A (얀 여유분 지배) | 71.3 MPa | — |
| 가설 B (기여 없음) | ~129 MPa | — |
| **noTRS 실측** | — | **212.04 MPa** |

**둘 다 틀렸다. 열잔류응력을 없앴더니 강도가 t23(129.12) 대비
+64% 올랐다.** 잔류응력은 강도를 만드는 것이 아니라 **깎고 있었다.**

원인은 손상 CSV 첫 프레임(인장 시작 = 냉각 직후)에 그대로 있다.

| 상(phase) | 정상 냉각 후 | noTRS 후 |
|---|---|---|
| 기지 손상요소율 | **72.01%** (DMT 0.512) | **0.00%** |
| 얀 손상요소율 | 20.5~20.7% | 0.00% |
| 초기 할선(0~0.05%) | 57.9 GPa | **234.1 GPa** |

**냉각만으로 이미 기지의 72% 가 손상되고 강성의 3/4 이 사라진다.**
얀 잔류압축(−341.8 MPa)이 주는 여유분보다 냉각 손상의 해악이 훨씬
크다. 가설 A 는 손상을 계산에 넣지 않은 것이 오류였다.

### 5.7 그래서 온도 강화가 왜 안 나왔나 (유력 가설)

논문의 기구는 **"승온 → 열잔류응력 완화 → 강도 증가"** 이고,
noTRS(완전 완화)가 +64% 를 준다. **크기가 논문의 +40%(500 °C) /
+55%(1000 °C) 와 같은 스케일이다. 즉 모델은 그 기구를 갖고 있다.**

문제는 **우리 해석 순서**다.

```
현재:  1050 -> 23 (기지 72% 손상) -> 500 으로 승온 -> 인장
논문:  1050 -> 500 -> 인장   (추정)
```

**손상은 비가역이다.** 23 °C 까지 내렸다가 올리면 그때 생긴 72% 손상은
그대로 남는다. 승온으로 응력은 풀려도 손상은 안 풀린다. 그래서
500/1000 °C 가 23 °C 와 같은 129 MPa 근처에 머문 것이다.

1050 -> 500 으로 **곧장** 냉각하면 ΔT 가 1027 대신 550 이므로 기지
손상이 훨씬 적게 쌓인다. 냉각 진단 CSV 상 손상 개시가 620 °C 부근이니
500 °C 직행이면 손상이 거의 없는 상태에서 인장에 들어간다.

**검증 덱: `*_500C_DIRECT_GF.inp`, `*_1000C_DIRECT_GF.inp`**
(23 °C GF 덱과 냉각 목표온도·인장온도만 다르고 나머지 전부 동일)

| DIRECT500 결과 | 결론 |
|---|---|
| ~180 MPa | 논문 기구 재현. 해석 순서가 원인이었음이 확정 |
| ~130 MPa | 순서 문제 아님. 다른 원인을 찾아야 함 |

## 6. 논문으로 쓸 때 반드시 명시할 것

1. **얀 강도 7개와 손상 파라미터 전부가 논문에 없다.** 강도 일치는
   역보정 결과이며 예측 성능이 아니다.
2. **Weibull 산포는 논문에 없는 추가 모델링이다.**
3. **점성 정규화 때문에 결과가 하중속도에 의존한다.** 사용한 span 을
   명시해야 재현 가능하다.
4. **메쉬 수렴성은 V2_6 이후에만 논할 수 있다.** 그 이전 결과는
   요소 크기에 직접 의존한다.
5. **845 °C 기지 손상 100% 는 재현하지 못했다.** 원인은 파손기준이
   아니라 열잔류응력 크기다 (§5.3). 모델의 구속효율 37% vs 논문이
   요구하는 등2축 완전구속 수준.
6. **23 °C 인장은 목표변형률 0.003 안에서 연화에 진입하지 않는다.**
   최대응력 129.12 MPa 가 곡선의 마지막 점이므로 이는 강도의
   **하한**이며, Fig.11 의 하강 구간은 아직 재현하지 못했다.
