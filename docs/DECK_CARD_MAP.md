# 덱 `*User Material` 자리표 — 어느 숫자가 무엇인가

2026-08-10 확정. UMAT V2_7 소스의 `P(n)` 대입과 실제 덱 diff 를
대조해 검증했다. **덱을 고칠 때 값을 세지 말고 이 표를 볼 것.**

한 줄에 8개씩 들어간다. `constants=N` 이 곧 P 의 개수다.

## PAPERFAITH 체인 검증 — **각 링크가 정말 숫자 하나만 바꿨다**

| 링크 | 위치 | 변경 |
|---|---|---|
| LONG → P0 | 기지 P17 | 5.1 → **0.0** (WEIBM) |
| P0 → P1 | 기지 P24 신설 | `constants=23` → `24`, 끝에 **1.0** 추가 (MCRIT) |
| P1 → P2 | 얀 P13 | 80.0 → **50.0** (Yt) |

덱 헤더 주석 한 줄씩도 같이 바뀌었을 뿐이다. **§5.16~5.17 의 인과
귀속(“MCRIT 이 기지 100 % 를 열었다” 등)은 이 diff 로 확정된다.**

## 스텝 설정 (2026-08-10 실측)

| | P2 (23 °C) | 500/1000 원본 | 새 배치 |
|---|---|---|---|
| 인장 `*Step` | `inc=16000` | `inc=8000` | **16000** (P2 복사) |
| 인장 `*Static` | `0.001, 2.0, 1.0E-7, 0.002` | `0.001, 1.0, ...` | **P2 와 동일** |
| 인장 드라이버 | `0.006` | 500 `0.0041` / 1000 `0.0052` | **0.0073077 / 0.0083840** |
| 승온 `*Static` | (없음) | `0.005, 1.0, 1.0E-8, 0.02` | 500 그대로 / **1000 은 2.05** |

세 런의 변형률 속도가 **0.008495 / 2.0 = 0.0042475** 로 같아지고,
증분당 변형률도 `0.0042475 × 0.002 = 8.50e−6` 으로 같아진다.
최소 증분 수 = 2.0/0.002 = 1000, P0 실적 5182 → `inc=16000` 충분.
