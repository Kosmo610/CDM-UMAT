# P4 배치 — 얀 종방향 연화지수 A1T 를 크랙밴드 상당값으로 (2.0 → 50.0)

**변수는 하나.** 얀 카드 `PROPS(18)`. 나머지 전부 P3 과 동일 —
같은 XT(2835), 같은 Depvar(17), 같은 메쉬, 같은 span, 같은 eta,
같은 UMAT(V2_7D).

**사전등록 완료.** 예측은 `verification/PAPER_DEVIATION_REGISTER.md`
§5.25 에 배치 전에 적혀 있다.

## 왜 이 배치인가

P3 가 남긴 실패항목 셋이 **같은 뿌리**를 가리킨다.

1. 곡선 형상 — 23/500 °C 가 국소최대 후 **재경화**해 0.85 % 끝까지
   상승 마감 (논문은 ~0.3 % 에서 종국 파단)
2. 절대 강도 초과 — +53/+20/+22 %
3. warpL 온도 추세 — 논문 하강(60.67→32.12), 우리 평탄~상승

뿌리: **얀 종방향이 개시(전단 주도, SDV17 실측 0.92~0.97)는 하는데
그 뒤 연화가 너무 완만해(A1T=2.0) 관측창 안에서 안 끊어진다.**

수치로: `d = 1 − exp[A(1−r)]/r` 에서 r=1.05 일 때
A=2 → d=0.14, **A=50 → d=0.92.** A=50 이면 개시 5 % 뒤 사실상 절단.

## 왜 하필 50 인가 — 자의적 값이 아니다

V2_6 크랙밴드가 논문 XT 에서 주는 값이 정확히 50 이다:

```
g0 = XT^2/(2*E1) = 2835^2/(2*254967) = 15.76 N/mm^2
g0*le (le~0.059mm) = 0.93  >>  GF1T = 0.03962
-> A1TEFF = 2*g0*le/(GF1T - g0*le) < 0  ->  클램프 50   (전 요소)
```

이 메쉬의 모든 요소에서 클램프에 걸리므로 **"크랙밴드 켜기" 와
"A1T=50" 은 수치적으로 동일하다.** 슬롯 32 를 늘리는 덱 수술 대신
기존 슬롯 18 하나를 바꾼다. UMAT 수정도 없다.

## 한 배치로 답하는 질문 (§5 요건 — 7개)

1. 재경화가 사라지는가 (곡선 형상)
2. 강도 절대값이 논문 쪽으로 내려오는가
3. 최대점 변형률이 논문(0.32/0.26/0.31 %)에 접근하는가
4. warpL 손상요소율과 그 온도 추세가 바뀌는가 (국부화 예상)
5. 냉각이 P3 와 비트 일치를 유지하는가 (A1T 는 개시 r 에 안 들어감)
6. SDV17 전단분율이 유지되는가 (개시 기구는 A1T 무관이어야 함)
7. 손상 후 HOM E11 이 P3(27.6 GPa)보다 낮아지는가
