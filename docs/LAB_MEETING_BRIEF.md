## 2. 대상 논문

| 항목 | 내용 |
|---|---|
| 저자 | Q. Zhang, J. Ge, B. Zhang, C. He, Z. Wu, J. Liang |
| 제목 | Effect of thermal residual stress on the tensile properties and damage process of C/SiC composites at high temperatures |
| 출처 | *Ceramics International* **48** (2022) 3109–3124 |
| 재료 | 2D 평직 C/SiC, PIP 공정, 제조온도 1050 °C, Vf ≈ 40% |
| 실험 | 진공, 승온 50 °C/min + 10 min 유지, ASTM C1359-13, 크로스헤드 0.5 mm/min, 온도당 시편 5개 |

### 논문의 핵심 주장

1. 제조 후 상온까지 냉각하면 SiC 기지에 **인장** 잔류응력, 탄소섬유
   얀에 **압축** 잔류응력이 생긴다 (CTE 불일치).
2. 이 인장 잔류응력이 상온에서 기지를 **미리 손상**시켜 강도를 깎는다.
3. 시험온도를 올리면 잔류응력이 **완화·반전**되어 강도가 **오른다**.
4. 그래서 C/SiC 는 특이하게 **고온에서 더 강하다**.

### 논문 Table 3 (재현 목표)

| 온도 | 논문 해석 | 실험 평균 | 실험 표준편차 |
|---|---|---|---|
| 23 °C | 128.45 MPa | 116.17 | 8.78 |
| 500 °C | 179.42 MPa | 160.19 | 14.83 |
| 1000 °C | 199.15 MPa | 173.28 | 12.94 |

→ 23 °C 대비 **+39.7 % (500 °C)**, **+55.0 % (1000 °C)**

### 3.2 재료모델 (연속체손상역학, CDM)

```
손상변수      d = 1 − exp[A(1−r)] / r          r = 유효응력 / 강도
손상강성      Cd = R · C0 · R                   R = diag(√(1−di))
크랙밴드      A_eff = 2·g0·le / (Gf − g0·le),   g0 = XT²/(2E)
점성 정규화   GAM = Δt / (η + Δt)
```

- 기지 파손기준: von Mises / X_m , I₁ 부호로 인장·압축 분기 (논문 Eq.15/16)
- 얀: 종방향 / 횡방향 각각 인장·압축, 4모드
- 손상은 **비가역** (한번 생기면 안 풀림)

### 3.3 해석 절차 (논문과 동일 — 원문 3.2.4 절)

```
Step 1  냉각    1050 °C → 23 °C
Step 2  승온    23 °C → 시험온도 (500 / 1000 °C)
Step 3  인장    시험온도 유지, 주기경계 x방향 인장
Step 4~9 (추가) HOM_E11 ~ HOM_G23 선형섭동 6스텝
                → 손상 후 균질화 강성 6×6 을 같은 해석에서 뽑음
```

### 4.3 열잔류응력을 지우면? (noTRS 검증)

| | 강도 | 냉각 후 기지 손상 | 초기 할선강성 |
|---|---|---|---|
| 정상 냉각 | 129.12 MPa | **72.01 %** | 57.9 GPa |

1050 → 시험온도 **직행** (23 °C 를 안 거침). 같은 카드, 냉각목표만 다름.

| T | 냉각 ΔT | 냉각 후 기지손상 | 강도 | 23 °C 대비 |
|---|---|---|---|---|
| 23 °C | 1027 K | 72.0 % | 139.43 | — |
| 500 °C | 550 K | 26.4 % | 138.49 | **−0.7 %** |
| 1000 °C | 50 K | 0.0 % | 173.74 | +24.6 % |
| 논문 | | 100 % (전 온도) | 128.45 / 179.42 / 199.15 | +39.7 / +55.0 % |

- **500 °C 가 평평하다** (−0.7 %, 논문 +39.7 %)
- **파괴변형률 0.088 %** vs 논문 ~0.31 % (**3.5배 작음**)

유효하며 **논문에 없는 내용**이다.

## 5. 밝혀낸 것 — **발표의 뼈대**

### 발견 1. 우리 모델에서 열잔류응력은 강도를 깎는다 (논문은 반대)

noTRS 로 +64 %. 논문이 말한 "잔류응력 완화 → 강화" 기구를 모델이
갖고 있음을 직접 보였다. **사전등록한 두 가설(71.3 MPa / ~129 MPa)이
둘 다 틀렸고**, 잔류응력이 주는 얀 압축 여유분보다 냉각손상의 해악이
훨씬 크다는 것이 실측으로 나왔다.

### 발견 2. 손상 비가역성 + 23 °C 경유가 온도 강화를 소멸시킨다

논문 절차대로 23 °C 를 거치면 그 시점에 생긴 손상이 승온해도 남는다.
직행으로 바꾸면 1000 °C 에서 +42.2 % (122.19 → 173.74). 같은 카드,
같은 메쉬, 냉각 목표온도 2개만 다름.

**이건 논문에 없는 결과다.**

### 발견 3. 손상의 비용은 이방적이다 (균질화 강성 6×6)

E11 은 안 변하고 E22/E33/G23 만 2–4 배 변한다. 강도 곡선 하나만
봐서는 절대 안 보이는 정보를 같은 odb 에서 뽑았다.

### 발견 4. 845 °C 갭의 원인은 파손기준도 CTE 도 아니다

가설을 하나씩 기각한 기록:

| 가설 | 검증 방법 | 결과 |
|---|---|---|
| 파손기준 형태 (Rankine vs Mises) | 냉각 odb 91,554 적분점 전수 비교 | **기각.** 846 °C 최대응력점 140.0 MPa vs Xm 310 |
| 열팽창계수 (CTE) 설정 | 3상 iso-strain 잔류응력 예산 계산 | **기각.** 어떤 CTE 조합도 필요값의 21–29 % |
| **강성 배분** | 논문 Table 1/2 로부터 직접 | **유력.** 기지 350 GPa 가 얀 횡 44 GPa 의 8배 → 구속효율 30 % |

필요 기울기 1.51 MPa/K vs 모델 0.354 MPa/K.

### 발견 5. 논문의 강화 기구는 "손상 회피" 가 아니라 "응력상태 반전"

원문 Fig.4/6/11 판독 결과: 논문에서도 손상요소율은 전 온도에서
~100 % 로 **같다**. 그런데도 강한 이유는 승온 시 기지 잔류응력이
인장 → **압축**으로 반전되고 고르게 분포하기 때문. 요소가 "손상됨"
판정이어도 손상변수 d 는 중간 수준이라 하중을 계속 지지한다.

**우리가 못 낸 이유가 이걸로 정리된다**: 잔류응력이 작아 반전이
안 일어나고(500 °C 기지 +66.9 MPa, 1000 °C −27), 동시에 손상변수가
커서(DMT 0.512) 강성이 이미 죽어 있다.

## 6. 약점 — **먼저 말해야 할 것** (안 밝히면 질문으로 돌아온다)

### 6.1 강도 일치는 예측이 아니라 보정이다

얀 종방향 인장강도 **X_y,1t = 421 MPa** 는 논문에 없다. Table 3 의
128.45 MPa 에 맞춰 4점(400/500/600/650) 회귀

```
σ_peak = 0.11565 × XT + 80.02      (4점 오차 0.4 % 이내)
```

로 역산했다. Chamis 이론값 2835 MPa 의 **14.8 %** 다.
C/SiC 는 고온 공정에서 섬유가 열화되고 PyC 계면이 약해 in-situ 얀
강도가 원사 대비 20–40 % 로 떨어진다는 보고가 있으나, 14.8 % 는
그보다도 낮다.

### 6.2 논문에 없어 임의로 정한 물성 19건

| 물성 | 값 | 영향 |
|---|---|---|
| 얀 횡방향 인장강도 Y_t | 80 MPa | 횡손상률을 직접 좌우 (논문 88 %) |
| 전단강도 S12/S13/S23 | 120/120/100 MPa | 미확인 |
| 기지 파괴에너지 G_f | 0.018 N/mm | 크랙밴드 계수 결정 |
| 손상 상한 DMAX | 0.95 / 0.90 | 최대점 이후 비물리적 재상승의 원인 |

### 6.3 논문에 없는 기능을 추가했다

**Weibull 강도 산포** (형상모수 m = 5.1). 논문은 기지 강도를
결정론적 310 MPa 로 쓴다. 요소 좌표 해시 기반 샘플링 (평균 310.093,
오차 0.030 %). 손상 개시 위치와 진행에 영향을 준다.

### 6.4 점성 정규화 때문에 결과가 하중속도에 의존한다

논문에 없는 수치 안정화. 초기 접선강성이 목표변형률 span 에 따라
66.56 / 73.48 / 88.55 GPa 로 변한다.
→ **온도별 비교 시 반드시 span 을 통일해야 한다.** (우리는 통일함)

### 6.5 미구현

- **기지 소성** (논문 Eq.6–10, von Mises 항복 + 등방경화) — 탄성-손상만 구현
- **얀 종방향 Eq.17/18** 혼합 선형-지수형 — 단순 지수형으로 대체
- **메쉬 수렴성 미검증** (V2_6 의 얀 크랙밴드 정규화 이후에만 논할 수 있음)
- **점성 파라미터 η 미수렴** — halving 당 −3.70 % → −4.45 % (발산 방향)
- **연화 구간 미도달** — 곡선이 하강 뒤 DMAX 잔류강성으로 재상승

## 7. 예상 질문과 답

**Q. 강도가 23 °C 에서 −2 % 면 잘 맞은 것 아닌가?**
> 맞춘 것입니다. 얀 강도 421 MPa 를 그 숫자에 맞춰 역산했습니다.
> 예측 성능이 아니라 보정 결과라 그렇게 발표합니다. 진짜 검증은
> 보정에 안 쓴 500/1000 °C 인데, 거기서 −28 % / −39 % 로 벗어납니다.

**Q. 왜 논문처럼 고온에서 안 세지나?**
> 두 가지가 겹쳐 있습니다. (1) 우리 잔류응력이 작아 승온해도
> 인장→압축 반전이 안 일어납니다 (구속효율 30 %). (2) 그런데도
> 냉각 손상변수는 커서 강성이 이미 죽어 있습니다. 논문은
> 손상요소율 100 % 이면서 d 값은 중간이라 하중을 지지합니다.

**Q. 요소 크기가 논문보다 촘촘한데 그게 원인 아닌가?**
> 요소 수는 1.49배입니다. 다만 V2_6 에서 얀 크랙밴드 정규화를 넣기
> 전에는 수렴점 자체가 없었으므로, 메쉬 연구는 그 이후에만 의미가
> 있습니다. 재료점 수준에서는 요소크기 0.0285–0.2000 mm 에 대해
> 소산에너지 편차 1.00000배로 검증했습니다. RVE 수준 메쉬 수렴은
> 아직 안 했고, 이건 명시적으로 남은 과제입니다.

**Q. 주기경계조건이 제대로 걸린 건 확인했나?**
> 예. Driver 반력 6개 전부 0, 전역좌표계 체적가중 평균응력 잔차
> 4.0e−8 (기계정밀도), 횡방향 응력 전 증분 정확히 0.000 입니다.
> 추가로 손상 후 균질화 강성 6×6 의 **대칭성 위반이 0.0000 %** 인데,
> 이건 PBC 와 UMAT 야코비안이 동시에 옳아야만 나오는 값입니다.

**Q. 그래서 이 연구의 기여가 뭔가?**
> 재현 자체가 아니라 **재현이 안 되는 지점을 정량화한 것**입니다.
> ① 비가역 손상 가정 하에서 상온 경유가 온도 강화를 소멸시킨다는
> 정량 데이터 (+42.2 %), ② 열잔류응력 손상의 비용이 하중방향이 아닌
> 횡방향·전단에 있다는 균질화 강성 증거 (E11 불변, G23 +305 %),
> ③ 845 °C 손상률 갭의 원인이 파손기준이나 CTE 가 아니라 강성 배분
> 이라는 배제 실험. 셋 다 논문에 없습니다.

**Q. 다음에 뭘 할 건가?**
> §8 참조.
