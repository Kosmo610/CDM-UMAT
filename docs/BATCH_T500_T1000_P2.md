## 반드시 같이 고칠 두 가지 — 안 고치면 비교가 무효다

### (1) 승온 램프 속도 통일 (§5.18D)

승온 스텝의 `*Static` 줄에서 **두 번째 값이 스텝 시간**이다.

```
*Step, Name=Heating_1000C, ...
*Static
0.005, 1.0, 1.0E-8, 0.02        <- 1.0 이 스텝 시간
```

**1000 °C 덱만** 이렇게 바꾼다 (500 덱은 그대로):

```
0.005, 2.05, 1.0E-8, 0.02
```

`2.05 = 977 K / 477 K`. **증분 크기(0.02)는 그대로 둔다** — 그래야
증분당 온도 상승까지 500 덱과 같아진다 (477×0.02 = 9.5 K,
977×0.02/2.05 = 9.5 K). 증분 수만 2배로 늘어나는 것이 목적이다.

### (2) 인장 기계변형률 span 통일 (§4.1)

인장 스텝의 드라이버 목표는 여기다:

```
*Step, Name=Tension_500C, ...
*Boundary
ConstraintsDriver0, 1, 1, 0.0041        <- 이 값
```

현재 값: 23 °C(XT421) `0.003`, 500 °C `0.0041`, P 시리즈 `0.006`.

P2 의 실측 span 은 **0.008495**. 관계식 (P0 에서 검증):

```
기계 span = 드라이버 목표 − 냉각 프리스트레인
0.008539 = 0.006        − (−0.002617)
```

프리스트레인은 시험온도마다 다르므로 온도별로 다시 계산한다.
값은 기존 t500/t1000 의 진단파일에서 그대로 읽는다.

```bat
cd /d "E:\LTH\Try_0805까지\Try_1430"
abaqus python E:\LTH\extract_tension.py CSIC_t500.odb  --step Tension_500C  --nodamage --tag _500C
abaqus python E:\LTH\extract_tension.py CSIC_t1000.odb --step Tension_1000C --nodamage --tag _1000C
findstr /C:"Step 시작" diagnostics_tension_500C.txt diagnostics_tension_1000C.txt
```

```
새 드라이버 목표 = (나온 e_x, 음수) + 0.008495
```
