# 다음 배치 — P2 카드로 500 °C / 1000 °C (Table 3 나머지 두 점)

## 목적

23 °C 는 P2 로 확보했다 (118.71 MPa, 최대점 0.2519 %). **같은 카드로**
500 / 1000 °C 를 돌려야 Table 3 세 점이 서로 비교 가능해진다.
현재 갖고 있는 500/1000 데이터는 **옛날 카드**(Weibull 있음,
MCRIT=0)라 P 시리즈와 나란히 못 놓는다.

동시에 얻는 것 (§5 정보 최대화):

| 항목 | 논문 대응 |
|---|---|
| 강도 2점 | Table 3 (500, 1000 행) |
| 응력-변형률 + 손상률 | Fig.13 / Fig.15 |
| 단계점 컨투어 | Fig.14 / Fig.16 |
| 단계점 히스토그램 | Fig.A2 / Fig.A3 |
| 승온 이력·컨투어 | Fig.6 / Fig.7·8 / Fig.9·10 |
| 손상 후 6×6 강성 | (우리 추가) |

**한 배치로 논문 그림 10장 이상이 채워진다.**

## 바뀌는 것 = 온도뿐 (§4 준수)

기존 500/1000 경유 덱에서 **세 값을 P2 와 같게** 맞춘다. 값은 추측하지
말고 실제 diff 로 읽는다.

경로는 `RUN_LAYOUT.md` 의 덱 표에 실측으로 박아 두었다. 체인 diff 를
차례로 떠서 **각 링크가 정말 숫자 하나만 바꿨는지** 확인하고, 그
숫자의 위치를 읽는다.

```bat
cd /d E:\LTH
fc "Try_C\CSIC_PLAIN_WEAVE_RVE_23C_XT421_LONG.inp" "Try_P0\CSIC_PLAIN_WEAVE_RVE_23C_P0.inp" > diff_chain.txt
fc "Try_P0\CSIC_PLAIN_WEAVE_RVE_23C_P0.inp"        "Try_P1\CSIC_PLAIN_WEAVE_RVE_23C_P1.inp" >> diff_chain.txt
fc "Try_P1\CSIC_PLAIN_WEAVE_RVE_23C_P1.inp"        "Try_P2\CSIC_PLAIN_WEAVE_RVE_23C_P2.inp" >> diff_chain.txt
```

각각 WEIBM / MCRIT / Yt 한 자리씩만 나와야 한다. 그 **숫자 그대로**
500/1000 덱의 같은 위치에 적용한다.

**온도 덱의 구조 차이**도 같이 뜬다 (승온 스텝·드라이버 목표가
어디에 있는지 = 아래 두 정정을 어디에 적용할지):

```bat
fc "Try_0805까지\Try_1430\CSIC_PLAIN_WEAVE_RVE_23C_XT421.inp" ^
   "Try_0805까지\Try_1430\CSIC_PLAIN_WEAVE_RVE_500C_XT421.inp" > diff_temp.txt
```

⚠️ 500/1000 덱은 P 시리즈보다 **오래된 계보(XT421)** 다. 물성 카드
상수 개수가 다르면(예: 얀 38개가 아님) 값 위치가 어긋난다 —
diff 로 반드시 확인하고, 다르면 P2 덱의 `*User Material` 블록
전체를 통째로 옮겨 붙이는 편이 안전하다.

## 반드시 같이 고칠 두 가지 — 안 고치면 비교가 무효다

### (1) 승온 램프 속도 통일 (§5.18D)

현재 두 덱 모두 승온 스텝시간이 1.0 인데 ΔT 가 477 vs 977 이라
dT/dt 가 2.05 배 다르다. 그 결과 인장 출발 손상상태가 기지 1.41 %p /
얀 횡 2.75 %p 어긋난다 — **온도 효과가 아니라 인공물**이다.

→ **1000 °C 덱의 승온 스텝시간을 `2.05` 로.** (500 덱은 1.0 유지)

### (2) 인장 기계변형률 span 통일 (§4.1)

점성 정규화 때문에 span 이 다르면 강도를 비교할 수 없다.
P2 의 실측 span 은 **0.008495**.

드라이버 목표와 span 의 관계 (P0 에서 검증됨):

```
기계 span = 드라이버 목표 − 냉각 프리스트레인
0.008539 = 0.006        − (−0.002617)      <- P0 실측과 일치
```

프리스트레인은 시험온도마다 다르므로 **드라이버 목표를 온도별로
다시 계산**해야 한다. 값은 기존 t500/t1000 의 진단파일에서 읽는다.

```bat
findstr /C:"Step 시작" "E:\LTH\Try_0805까지\Try_1430\diagnostics_tension_500C.txt"
findstr /C:"Step 시작" "E:\LTH\Try_0805까지\Try_1430\diagnostics_tension_1000C.txt"
```

나온 `e_x` 값 (음수) 을 넣어:

```
드라이버 목표(500)  = e_x(500)  + 0.008495
드라이버 목표(1000) = e_x(1000) + 0.008495
```

진단파일이 없으면 먼저 만든다 (병렬 가능, 토큰 0개):

```bat
cd /d "E:\LTH\Try_0805까지\Try_1430"
abaqus python E:\LTH\extract_tension.py CSIC_t500.odb  --step Tension_500C  --nodamage --tag _500C
abaqus python E:\LTH\extract_tension.py CSIC_t1000.odb --step Tension_1000C --nodamage --tag _1000C
```
