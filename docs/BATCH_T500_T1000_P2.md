# 다음 배치 — P2 카드로 500 °C / 1000 °C (Table 3 나머지 두 점)

## 목적

23 °C 는 P2 로 확보했다 (118.71 MPa, 최대점 0.2519 %). **같은 카드로**
500 / 1000 °C 를 돌려야 Table 3 세 점이 서로 비교 가능해진다.
현재 갖고 있는 500/1000 데이터는 **옛날 카드**(Weibull 있음,
MCRIT=0)라 P 시리즈와 나란히 못 놓는다.

동시에 얻는 것 (§5 정보 최대화):

| 항목 | 논문 대응 |
|---|---|
| 강도 2점 | Table 3 (500, 1000 행) |
| 응력-변형률 + 손상률 | Fig.13 / Fig.15 |
| 단계점 컨투어 | Fig.14 / Fig.16 |
| 단계점 히스토그램 | Fig.A2 / Fig.A3 |
| 승온 이력·컨투어 | Fig.6 / Fig.7·8 / Fig.9·10 |
| 손상 후 6×6 강성 | (우리 추가) |

**한 배치로 논문 그림 10장 이상이 채워진다.**

## 용어 — "덱" = "인풋 파일(.inp)"

같은 말이다. **덱 수정** 은 그 `.inp` 를 열어 숫자 몇 개를 고치라는
뜻이지, 새 파일을 어디서 받아 넣으라는 뜻이 아니다. 원본 덱은
`RUN_LAYOUT.md` 의 덱 표에 있는 기존 파일이다.

## 덱 만들기 — 스크립트가 한다 (손으로 고치지 말 것)

고칠 곳이 7 군데라 손으로 하면 반드시 어딘가 틀린다.
`abaqus/make_p2t_deck.py` 가 원본을 읽어 새 덱을 만들고, **바꾼 곳을
전부 화면에 찍는다.** 앵커를 하나라도 못 찾으면 **아무 파일도 쓰지
않고 멈춘다** — 반쯤 고쳐진 덱이 나오는 일은 없다.

```bat
cd /d E:\LTH
mkdir Try_P2T500
mkdir Try_P2T1000

python make_p2t_deck.py ^
  "Try_0805까지\Try_1430\CSIC_PLAIN_WEAVE_RVE_500C_XT421.inp" ^
  "Try_P2\CSIC_PLAIN_WEAVE_RVE_23C_P2.inp" ^
  "Try_P2T500\CSIC_PLAIN_WEAVE_RVE_500C_P2.inp" --temp 500

python make_p2t_deck.py ^
  "Try_0805까지\Try_1430\CSIC_PLAIN_WEAVE_RVE_1000C_XT421.inp" ^
  "Try_P2\CSIC_PLAIN_WEAVE_RVE_23C_P2.inp" ^
  "Try_P2T1000\CSIC_PLAIN_WEAVE_RVE_1000C_P2.inp" --temp 1000
```

(인자 순서: **원본 → P2 덱 → 출력**. P2 덱은 인장 `*Static` 과
`inc=` 를 그대로 베껴 오려고 읽는다.)

### 스크립트가 고치는 7 군데

| | 내용 | 근거 |
|---|---|---|
| 1 | 기지 WEIBM `5.1` → `0.0` (P17) | P0 링크 |
| 2 | 기지 `constants=23`→`24`, 끝에 `1.0` (MCRIT P24) | P1 링크 |
| 3 | 얀 Yt `80.0` → `50.0` (P13) | P2 링크 |
| 4 | 인장 `*Static` + `inc=` ← **P2 덱에서 복사** | §4.1 속도 통일 |
| 5 | 인장 드라이버 → 500 `0.0073077` / 1000 `0.0083840` | §5.20A |
| 6 | 승온 스텝시간 → **1000 만** `2.05` | §5.18D |
| 7 | `*Depvar` 이름 줄 삭제 (개수 유지) | 논문식 SDV 표시 |

**건드리지 않는 것** (스크립트도 안 건드린다): FREEZESTEP,
HOM 스텝의 드라이버(`1.0E-4`/`0.0`), 냉각 스텝, 메쉬, `*Depvar` 개수.

## UMAT — **V2_7P 를 쓴다** (2026-08-10 변경)

이 배치가 논문 Fig.13/14/15/16 과 A2/A3 컨투어를 만드는 배치다.
V2_7 로 돌리면 라벨이 `SDV_DMT` 식으로 나와, 논문과 같은
**SDV1/SDV2/SDV14** 로 뽑으려면 수십 시간짜리 해석을 통째로 다시
돌려야 한다 (§5 위반). **처음부터 V2_7P 로 간다.**

- V2_7 대비 주석 뺀 실제 차이 **5 줄**, 전부 저장 위치. NSTATV 불변.
- **덱의 `*Depvar` 이름 줄을 지운다** (개수 숫자는 그대로).
  블록은 `SDV_PAPER_DISPLAY.md` 참조.
- 추출 스크립트 4종은 이름 우선 + V2_7P 번호 폴백이라 신구 odb 를
  같은 명령으로 처리한다.

### 검증 — 새 해석 없이 배치 안에서 끝난다

500/1000 덱의 냉각(1050→23)은 P2 와 카드·메쉬가 같다. 따라서
**냉각 끝 손상요소율이 P2 와 정확히 일치해야 한다.**

| | P2 (기준) |
|---|---|
| 기지 | 58.73 % |
| 워프 횡 | 34.25 % |
| 위프 횡 | 33.90 % |

해석 시작 후 냉각이 끝나면 바로 확인한다:

```bat
cd /d E:\LTH\Try_P2T500
abaqus python E:\LTH\extract_cooling_damage.py CSIC_t500_p2.odb --stride 5 --tag _P2T500
```

**어긋나면 V2_7P 가 뭔가 깨뜨린 것이므로 즉시 중단**하고, 두 잡을
V2_7 로 다시 띄운다 (덱의 `*Depvar` 이름 줄도 되돌린다).

## 폴더 (RUN_LAYOUT 규약)

| | 500 °C | 1000 °C |
|---|---|---|
| 폴더 | `E:\LTH\Try_P2T500` | `E:\LTH\Try_P2T1000` |
| job | `CSIC_t500_p2` | `CSIC_t1000_p2` |
| 태그 | `_P2T500` | `_P2T1000` |
| 코어 | 16 | 16 |

각 폴더에 덱 + `UMAT_CSIC_RVE_DAMAGE_V2_7P.for` + `.ori` 를 넣는다
(`.ori` 는 기존 폴더에서 복사 — 없으면 즉시 실패).

## 발사 (병렬 가능 — 창 2개, 16코어씩)

