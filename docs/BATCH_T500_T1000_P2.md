## 반드시 같이 고칠 두 가지 — 안 고치면 비교가 무효다

### (1) 승온 램프 속도 통일 (§5.18D)

승온 스텝의 `*Static` 줄에서 **두 번째 값이 스텝 시간**이다.

```
*Step, Name=Heating_1000C, ...
*Static
0.005, 1.0, 1.0E-8, 0.02        <- 1.0 이 스텝 시간
```

**1000 °C 덱만** 이렇게 바꾼다 (500 덱은 그대로):

```
0.005, 2.05, 1.0E-8, 0.02
```

`2.05 = 977 K / 477 K`. **증분 크기(0.02)는 그대로 둔다** — 그래야
증분당 온도 상승까지 500 덱과 같아진다 (477×0.02 = 9.5 K,
977×0.02/2.05 = 9.5 K). 증분 수만 2배로 늘어나는 것이 목적이다.

### (2) 인장 — span **과 스텝시간 둘 다** 맞춰야 한다 (§4.1)

점성 정규화가 보는 것은 span 이 아니라 **변형률 속도 = span / 스텝시간**
이다. span 만 맞추면 속도가 어긋나 비교가 여전히 무효다.

```
P2       span 0.008495 / 스텝시간 2.0 = 0.0042475
500 현재  span 0.0052873 / 1.0        = 0.0052873   (P2 의 1.24 배)
1000 현재 span 0.0053110 / 1.0        = 0.0053110   (P2 의 1.25 배)
```

→ **두 덱 모두 인장 스텝시간을 `1.0` → `2.0`** 으로 바꾼다.
(P 시리즈가 2.0 이다. `.sta` 에서 "step time 2.00 / 2.00" 로 확인됨.)

#### 고칠 곳 두 군데

**(가) 인장 `*Static` 줄 — 두 번째 값**

```
*Step, Name=Tension_500C, nlgeom=NO, inc=8000
*Static
0.001, 1.0, 1.0E-7, 0.002
```

**P2 덱의 인장 `*Static` 줄과 `inc=` 를 그대로 복사해 오는 것이
가장 안전하다.** 확인:

```bat
powershell -Command "Select-String -Path 'E:\LTH\Try_P2\CSIC_PLAIN_WEAVE_RVE_23C_P2.inp' -Pattern 'Tension_23C' -Context 0,8"
```

**(나) 드라이버 목표** — 계산 끝났다.

```
*Boundary
ConstraintsDriver0, 1, 1, <목표>
```

| | 현재 목표 | 현재 span | **새 목표** |
|---|---|---|---|
| 500 °C | 0.0041 | 0.00528726 | **0.0073077** |
| 1000 °C | 0.0052 | 0.00531101 | **0.0083840** |

(HOM 스텝의 `1.0E-4` / `0.0` 은 건드리지 않는다. 인장 스텝 안의
값 하나만이다.)

**역산된 프리스트레인이 물리와 맞는지 검산됨** — 1050 °C 무응력
기준으로 (1050−T) 당 −2.16~−2.43e−6 으로 세 온도가 같은 크기다.

| T | 프리스트레인 | /(1050−T) |
|---|---|---|
| 23 °C | −0.0024950 | −2.43e−6 |
| 500 °C | −0.0011873 | −2.16e−6 |
| 1000 °C | −0.0001110 | −2.22e−6 |

#### 남는 오차 (허용)

새 카드(P2)는 냉각 손상이 달라 프리스트레인이 조금 움직인다.
23 °C 에서 P0 → P2 가 −0.0025390 → −0.0024950 (**1.7 %**) 였으므로
500/1000 에서도 그 정도다. span 으로는 0.3 % 미만이라 무시한다.
**해석 후 `extract_tension.py` 로그의 "완주 기준 span" 이 0.008495
± 1 % 안인지 확인할 것.** 벗어나면 그 값으로 다시 보정한다.
