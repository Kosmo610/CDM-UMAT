Abstract — 초록

저자들이 4문장으로 압축한 논문

기지(SiC)와 얀(탄소섬유 다발)의 열팽창계수가 서로 달라서 열잔류응력이 생긴다는 것이 출발점입니다. 저자들은 점진적 손상 모델로 이 재료의 열-기계 거동을 예측하고 파손 메커니즘을 밝히겠다고 선언합니다.

절차는 네 단계입니다. ① 진공 중 세 온도에서 인장시험 → ② 탄성-소성 결합 점진적 손상 구성방정식을 ABAQUS UMAT으로 구현 → ③ 냉각·가열 과정의 열잔류응력 변화를 규명 → ④ 온도별 응력-변형률 선도를 계산하고 열잔류응력의 영향을 순차적으로 밝힘.

쉬운 말로

C/SiC = 탄소섬유를 실리콘카바이드 세라믹 속에 넣은 재료. 가볍고 안 녹아서 항공우주용입니다. 문제는 탄소섬유와 SiC가 열 받았을 때 늘어나는 정도가 다르다는 것. 그래서 만들고 식히는 동안 서로 당기고 밀면서 내부에 스스로 응력이 남습니다 — 이게 열잔류응력.

요약
  • 문제 — CTE 불일치 → 열잔류응력 → 손상 거동이 매우 복잡
  • 방법 — 실험(진공, 3개 온도) + 점진적 손상 모델(ABAQUS UMAT)
  • 결과 — 온도가 올라갈수록 잔류응력이 재분배되며 오히려 강도 상승
  • 의의 — C/SiC 강화 설계 지침

핵심 개념 ① — CTE 불일치가 모든 것의 원인

서론을 이해하려면 숫자 세 개만 알면 됩니다. 이 세 숫자가 논문 전체를 굴러가게 합니다.

CTE 불일치. 왼쪽은 “따로 있다면” 상황 — SiC가 훨씬 많이 줄어들려 합니다. 오른쪽은 “실제로는 붙어 있는” 상황 — 서로 붙잡느라 기지는 억지로 늘어나고(인장) 섬유는 눌립니다(압축). 이 그림 하나로 4.2.1절의 “식히기만 해도 기지 100 % 손상”이 왜 당연한지 설명됩니다.

핵심 개념 ②

점진적 손상 모델(Progressive Damage Model) — “부러진다 / 안 부러진다”의 이분법이 아니라, 손상변수 d (0~1)를 두고 하중이 커질수록 강성을 조금씩 깎아내리는 방식입니다. 이것이 CDM(연속체 손상역학)의 핵심이며, 이 저장소가 구현하려는 대상입니다.

1장 요약
  • C/SiC = 항공우주용 고온 구조재. 그러나 CTE 불일치로 제조 시부터 응력 잔존
  • 기존 실험 연구 = 정성적 / 기존 해석 연구 = 거시 물성만이거나 열응력 무시
  • 본 논문의 자리 — 2D 평직 C/SiC에 열잔류응력을 명시적으로 넣은 메소스케일 점진적 손상 해석

3.1

구성 모델 — 재료가 어떻게 반응하는가

Constitutive model · 이 장이 UMAT의 전부입니다

세라믹 기지 복합재는 극한강도의 20 % 미만이라는 아주 낮은 응력에서부터 응력-변형률 선도가 휘기 시작합니다. 원인은 미세균열의 성장과 구성재의 국부 손상입니다. 저자들은 얀과 기지를 완전히 다르게 모델링합니다.

얀 vs 기지. 오른쪽 상자의 ε소성 한 항이 두 모델을 가르는 전부입니다. 얀은 식 (1), 기지는 식 (6).

지배 방정식

εy = εye + εyth(1)
σy = Cy(d) : εye(2)
σ̃y = M(d) : σy(3)
M(d) = diag { 1/(1−d1), 1/(1−d2), … , 1/(1−d6) }(4)
εm = εme + εmp + εmth(6)
ε̇mp = λ̇ · ∂F(σ̃m, εmp) / ∂σ̃m(9)
ε̇th = α · Ṫ   (얀 = 식 5, 기지 = 식 10)(5,10)

식 (4)를 그림으로 — 유효응력, 이 논문 최고의 개념

이 개념을 이해하면 3장 전체가 풀립니다. 밧줄 비유로 봅시다.

유효응력. 밧줄 6가닥 중 3가닥이 끊어져도 겉보기 응력은 그대로지만, 살아남은 가닥이 받는 실제 응력은 2배입니다. 식 (4)의 1/(1−d)가 바로 이 배율입니다.

왜 유효응력을 쓰는가

다음 절의 파손 판정 기준(Hashin, von Mises)에 넣는 응력이 바로 이 유효응력이기 때문입니다. 겉보기 응력으로 판정하면 “이미 반쯤 망가진 재료도 아직 멀쩡하다”고 오판합니다. 유효응력을 쓰면 손상이 손상을 부르는 가속이 자동으로 표현됩니다.

기지에만 소성을 넣은 이유

C/SiC를 당겼다 힘을 완전히 빼도 원래 길이로 안 돌아옵니다. 세라믹은 원래 소성이 없는데도요. 진짜 원인은 미세균열이 완전히 안 닫히고 섬유가 살짝 빠져나온 채 걸려서인데, 이걸 ‘유사 소성(pseudo plasticity)’이라 부릅니다. 저자들은 이를 물리적으로 하나하나 모사하는 대신 “기지가 소성 변형한 것처럼 취급하자”는 현상학적 접근을 씁니다. 실제 메커니즘과 다르지만 결과 곡선이 실험과 맞으면 공학적으로 유효하다는 실용주의입니다.

3.1.1 요약
  • 손상 = 강성을 깎는 것, 정도는 d (0~1)로 표현
  • σ̃ = σ/(1−d) — 살아남은 단면이 실제로 받는 응력. 파손 판정은 이 값으로
  • 얀 = 탄성+열 / 기지 = 탄성+소성+열 (von Mises · 연관 유동 · 등방 경화)
  • UMAT 구현 시 소성은 손상 안 된 “유효 공간”에서 풀고, 그 결과에 손상을 곱해 공칭응력을 냄 (식 8이 Cm0를 쓰는 이유)
3.1.2

손상 개시 기준 — 언제 망가지기 시작하나

Damage initiation criteria · Hashin + von Mises

Hashin 기준의 철학은 한 문장입니다 — “복합재는 부서지는 방식이 여러 가지다. 그러니 파손 조건도 여러 개 따로 만들자.” 얀에는 4개 모드, 기지에는 2개(인장/압축)를 씁니다.

Hashin 4모드. 왼쪽 1t가 실제 강도를 지배하는 모드이고, 세 번째 2(3)t는 냉각만으로 얀의 88 %가 걸리는 모드입니다. 네 모드 모두 같은 형식(응력/강도의 제곱합 → 1과 비교)이라, 코드로는 하나의 루틴에 분기만 넣으면 됩니다.

기지 — von Mises, 그리고 제1불변량으로 인장/압축 분기

φm,t = √( σ̃vM² / Xm,t² ) ≥ 1   (Ĩm ≥ 0)(15)
φm,c = √( σ̃vM² / Xm,c² ) ≥ 1   (Ĩm ≤ 0)(16)

분자는 완전히 같고 분모만 다릅니다. Ĩm = σ̃₁₁+σ̃₂₂+σ̃₃₃ 는 정수압 성분의 부호로, 양수면 “전체적으로 팽창(인장)”, 음수면 “전체적으로 수축(압축)”입니다.

4장을 여는 열쇠

가열하면 기지 잔류응력이 인장 → 압축으로 뒤집힙니다. 그러면 판정식이 (15)에서 (16)으로 스위치됩니다. 세라믹은 압축에 훨씬 강하므로 같은 크기 응력이라도 훨씬 덜 위험합니다.

다만 이 논문의 Table 2는 Xm,t = Xm,c = 310 MPa로 같게 두었습니다. 그럼에도 강해지는 진짜 이유는 강도값이 아니라 응력이 균일하게 퍼져 응력집중이 사라지기 때문입니다 — 4.2.2.2절에서 다룹니다.

3.1.2 요약
  • 얀 = 3D Hashin 4모드 (종 인장/압축, 횡 인장/압축), α = β = 1
  • 기지 = von Mises, 제1불변량 부호로 인장/압축 분기
  • 판정에 들어가는 응력은 전부 유효응력 σ̃
  • φ ≥ 1 이면 손상 개시
3.1.3

손상 진화 법칙 — 얼마나 빨리 망가지나

Damage evolution law · 지수형 vs 선형-지수 혼합

dy,I = 1 − (1/r) · exp[ A (1 − r) ]  (I = 1c, 2t, 2c, 3t, 3c)(17)
dy,1t = 1 − (1 − dL) / rE · exp[ A (1 − rE) ](18)
dm,J = 1 − (1/r) · exp[ A (1 − r) ]  (J = t, c)(19)

식 (17) 읽는 법

r은 “손상 개시점 대비 지금 얼마나 더 왔나”입니다. r = 1이면 딱 개시 순간이고, 이때 d = 1 − (1/1)·e⁰ = 0입니다. 그런데 r이 조금만 커져도 d가 급격히 1에 다가갑니다 — 이것이 세라믹의 취성입니다.

손상 진화. 왼쪽은 d–r 곡선 — r이 조금만 커져도 d가 1로 치솟는 것이 취성입니다. 오른쪽은 그 결과가 응력-변형률에 어떻게 나타나는지 — 순수 지수형은 “툭” 끊어지고, 혼합형은 최대 응력 이후에도 한참 버티는 꼬리를 만듭니다. 이 꼬리가 세라믹 복합재가 순수 세라믹보다 훨씬 질긴 이유입니다.

A 계수의 실무적 의미

A는 “얼마나 취성적인가”를 조절하는 손잡이입니다. 실제 구현에서는 A를 파괴에너지 Gf와 요소 특성길이로부터 결정합니다. 이렇게 해야 메시를 촘촘히 바꿔도 결과가 흔들리지 않습니다(메시 의존성 제거).

“손상 100 %”가 부서졌다는 뜻이 아닙니다

손상요소 백분율 100 % = “d > 0인 요소가 전부” = 온 재료에 미세균열이 잔뜩 있다는 뜻이지, 모든 요소의 d = 1(완전 파괴)이 아닙니다. 저자들도 4.3절 첫머리에서 이 지표의 한계를 인정하고, 부록에서 손상변수 값의 히스토그램으로 갈아탑니다.

왜 얀 종방향이 멀쩡한 게 결정적인가

실제로 인장하중을 버티는 건 얀의 길이 방향입니다. 기지가 온통 금이 가 있어도 섬유가 멀쩡하면 재료는 버팁니다. 이것이 세라믹 기지 복합재의 존재 이유이자 설계 철학입니다 — “기지는 어차피 깨진다. 그래도 괜찮다. 섬유가 버티니까.” 순수 SiC였다면 냉각 중 균열이 생긴 순간 그대로 파단했을 겁니다.

  • “100 %”는 d > 0인 요소가 전부라는 뜻이지 완전 파괴가 아님

4.2.2.1 — 500 °C까지

전단만으로 종방향 손상이 켜지는 이유

먼저 알아야 할 것 — 날실과 씨실의 역할 분담

세 곡선의 비교. 원 그림들을 같은 축에 겹친 모식도입니다. 읽을 것은 출발부의 모양 — 23 °C는 원점부터 휘고, 500 °C는 짧은 직선, 1000 °C는 긴 직선으로 출발합니다. 그 직선의 길이가 곧 “미리 걸린 압축을 상쇄하는 데 쓰는 구간”이고, 그만큼 강도가 올라갑니다.

왜 1000 °C에서 날실 횡방향이 빠지나? 냉각 때 얀을 짓눌렀던 압축 잔류응력이 완전히 인장으로 뒤집혀 얀이 옆으로 짓눌리는 압박에서 해방되었기 때문입니다. 그래서 날실 옆구리가 더 이상 갈라지지 않습니다.

이 절의 최종 결론

상온에서는 “날실 혼자 다 짊어지다가 60 %나 망가져서 무너지는” 상황이고, 1000 °C에서는 “기지와 씨실이 함께 짊어져서 날실은 32 %만 망가진 채로도 더 큰 하중에 도달하는” 상황입니다. 이것이 논문의 마지막 문장 — “고온에서 하중이 기지와 얀에 의해 더 효율적이고 협력적으로 분담된다”의 정확한 의미입니다.

05

Conclusions — 결론과 한계

저자들이 직접 뽑은 세 가지 + 스스로 인정한 빈틈

결론 (a)

고온에서 극한강도가 더 우수하다. 온도가 오르면 기지 내 열잔류응력이 인장 → 압축으로 전환되고 1000 °C에서 고르게 분포하기 때문.
한 줄로 — “뜨거우면 강해진다. 나쁜 인장이 좋은 압축으로 뒤집히고 고르게 퍼지니까.”

결론 (b)

손상 진전 과정이 시험 온도에 따라 달라진다. 고온에서는 얀 횡방향과 날실 종방향 손상이 더 느리게 진전하고 손상 정도도 덜하다. 그러나 씨실 종방향 손상과 기지 손상은 더 심해진다.
한 줄로 — “고온에서 얀은 편해지고 기지는 힘들어진다. 근데 전체적으로는 이득.”

결론 (c)

파손 모드가 온도에 따라 다르다. 23·500 °C는 날실 종·횡 + 씨실 횡 + 기지, 1000 °C는 날실 종 + 씨실 횡 + 기지.
한 줄로 — “1000 °C에서는 날실 옆구리가 안 터진다. 파손 시나리오 자체가 달라진다.”

자주 헷갈리는 것

Q. “기지 손상 100 %”면 부서진 건가요?

아닙니다. “d > 0인 요소가 전부”라는 뜻입니다. d = 1이 100 %라는 게 아닙니다. 그래서 부록의 손상변수 분포가 필요합니다.

Q. 뜨거우면 약해지는 게 상식 아닌가요?

이 논문은 진공에서, 1050 °C 이하에서 시험했습니다. 산화도 없고 재료 자체가 열화되는 온도까지 가지 않았습니다. 그래서 잔류응력 효과가 지배적이었습니다. 공기 중이거나 더 고온이면 결과가 달라질 수 있습니다.

Q. 왜 날실 손상이 온도↑에 따라 줄어드나요 (60 → 44 → 32 %)?

고온에서는 기지와 씨실이 하중을 더 많이 나눠 짊어지므로, 날실이 덜 망가진 채로도 더 높은 하중에 도달합니다.
