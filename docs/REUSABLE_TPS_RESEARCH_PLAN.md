# 재사용 TPS 손상예측 연구 — 후속 연구 기획 (삭마 × 열충격 연계)

> 현재 진행 중인 **C/SiC 반복 열충격 CDM 연구**(석사 수준, `RESEARCH_SUMMARY`)의
> *다음* 연구를 위한 틀. 연구실에서 따로 진행 중인 **삭마 시뮬레이션 트랙**과
> **열충격 CDM 트랙**을 하나의 예측 사슬로 묶어, 실제 재사용 TPS 구조의
> "삭마 이후 CMC가 얼마나 버티는가"를 해석으로 답하는 것이 목표.

---

## 0. 한 문장 정의

**바깥쪽 삭마재(P50 코르크 등)가 후퇴하며 만들어 주는 열경계조건을, 안쪽
CMC(C/SiC) 열충격 CDM 코드의 입력으로 넘겨(단방향 연계), 미션(재사용)을
반복할수록 CMC의 강성·강도가 얼마나 떨어지고 언제 균열이 임계에 도달하는지를
예측하는 "재사용 TPS 손상·수명 지도" 연구.**

기존 두 트랙과의 관계:

| 트랙 | 현재 상태 | 이 연구에서의 역할 |
|---|---|---|
| 삭마 시뮬 | 성숙(석·박사 학위논문 수준, 코드+뷰어 완비) | **입력 생성기** — 본드라인 온도/열유속 이력 + 후퇴량 |
| 열충격 CDM | 초기(막 시작, 본 저장소 UMAT 기반) | **손상 엔진** — CMC의 사이클 손상 누적·잔류물성·균열 |
| **연계(이 연구)** | 신규 | 두 트랙을 순차 커플링 + 다중미션 루프 + 통합 뷰어 |

---

## 1. 왜 "단방향 순차 연계"인가 (핵심 설계 결정)

TPS 스택은 [ 삭마재(바깥) │ 본드라인 │ CMC(안쪽) ] 구조다. 물리적으로:

- 삭마재의 후퇴·차르·열분해가 **CMC 뒤쪽으로 전달되는 열량**을 결정한다.
- CMC의 손상(균열)은 한 미션 동안 삭마재의 공력가열/후퇴에는 사실상 영향을
  주지 않는다.

따라서 **삭마 → CMC 로 가는 단방향(약연계) 커플링**이 물리적으로 타당하고
계산적으로도 안전하다. 양방향 강연계는 이 연구의 노벨티에 기여하지 않으면서
비용·수렴 위험만 키우므로 **범위 밖(한계로 명시)**.

> 커플링의 "인터페이스"는 단 하나의 물리량 집합이다:
> **본드라인(삭마재 뒷면 = CMC 앞면)의 시간이력 T(t) 또는 열유속 q(t),
> 그리고 미션 종료 시점의 삭마재 후퇴량 Δ.**
> 이 인터페이스만 표준화하면 두 코드는 서로의 내부를 몰라도 된다.

---

## 2. 스케일 브리징 — 매크로 열해석 + RVE CDM 서브모델링

CMC 열충격 CDM은 **메조스케일 RVE**(야른+매트릭스)에서 돈다. 그런데 TPS는
**부품(패널) 스케일**이다. 둘을 잇는 권장 방식은 **서브모델링**이다:

```
[1] 삭마 해석 (기존 코드)
        └→ 본드라인 T(t)/q(t),  후퇴량 Δ           ← 인터페이스 파일 (CSV/amplitude)
[2] 매크로 TPS 열해석 (삭마재+CMC 스택, 1D→축대칭→3D)
        └→ CMC 내 임계위치의 국소 온도장 이력 T_local(t)
[3] RVE 열충격 CDM (본 저장소 UMAT, 서브모델)
        └→ 손상장 D(x,t), 잔류강성/강도, 균열밴드
```

- **[2] 매크로 열해석**은 얇은 스택이므로 우선 **1D/축대칭**으로 충분. 삭마재는
  후퇴 경계(이동경계) 또는 등가 절연저항으로 처리.
- **[3] RVE는 가장 뜨겁고 위험한 국소 지점 1~수 개**만 돌린다 → 비싼 CDM을
  국소화하면서 시스템 효과(후퇴에 따른 가열 심화)를 담는다.
- 대안(A안): CMC를 RVE 균질화 유효물성으로 매크로 CDM 패널에 직접. 빠르지만
  균열 국소화 표현력이 약함. → **1차는 서브모델링(B안) 권장**, 필요 시 A안 병행.

## 3. 재사용(다중미션) 루프 — 이 연구의 심장

한 미션이 아니라 **여러 번 재사용**이 핵심. 미션 k → k+1 로 넘길 때 두 가지 상태가 이월된다:

1. **기하 이월(삭마재):** 후퇴량 Δ_k 만큼 삭마재가 얇아짐 → 절연 감소 →
   다음 미션에 CMC가 더 뜨겁고 빠른 열충격을 받음(가혹도 증가).
2. **손상 이월(CMC):** 미션 k의 잔류 손상 D_k·소성변형·잔류응력을 미션 k+1의
   초기조건으로 전달 → 누적 열화.

```
초기: TRS 생성(1050°C→상온)
반복 k=1..N:
    삭마재 두께 = t0 - Σ Δ         # 기하 이월
    CMC 초기상태 = (D_{k-1}, ε^p, σ_res)  via *Restart/SDV 전달   # 손상 이월
    → 매크로 열해석 → 국소 T(t) → RVE 열충격 1미션 → D_k, 잔류물성
    if CMC 잔류강도 < 임계  →  "재사용 한계 도달" 기록
결과: 잔류강도/강성 vs 미션수  곡선  →  안전 재사용 횟수
```

> 본 저장소 덱은 이미 `*Restart, write` + 20 SDV(매트릭스)/16 SDV(야른)로
> 손상·소성·응력 이월이 가능한 상태이므로, **손상 이월(2)은 기존 인프라로 바로 구현**된다.
> 새로 얹을 것은 **기하 이월(1, 삭마 연동)**과 **사이클당 손상항 dD/dN**(현재 열충격 연구 Step 3의 산출물).

## 4. 균열을 "뷰어로 보이게" 하기 (요구사항 4)

삭마 트랙은 이미 코드+뷰어로 균열을 보여준다. CMC 쪽도 **같은 뷰어 파이프라인**에
얹어, 최종 애니메이션이 "삭마재 후퇴 → 안쪽 CMC에 균열밴드 성장"으로 이어지게 한다.

본 UMAT은 스칼라 손상(D=1−E/E0)을 SDV로 내보낸다. 균열 시각화 3단계:

1. **손상 컨투어(가장 쉬움, 지금 바로 가능):** SDV를 필드출력으로 뽑아 컨투어.
   손상이 국소화된 띠 = 균열밴드. 핵심 SDV:
   - 매트릭스: `SDV1 DMT`(인장), `SDV2 DMC`(압축)
   - 야른: `SDV9 DY1`(종방향 결합손상), `SDV10 DYT`(횡방향 결합손상)
2. **요소 삭제로 "불연속 균열" 연출:** 결합손상이 dmax에 도달하면 `STATUS` SDV=0
   → Abaqus/Viewer가 요소를 지워 이산 균열처럼 보임. UMAT에 STATUS SDV 1개 추가 +
   덱에 `*Depvar, delete=<n>` 지정이면 됨(소량 수정).
3. **크랙밴드 후처리 스크립트:** `postprocess/`에 손상 임계 초과 요소를 추출해
   삭마 뷰어와 동일 포맷으로 내보내는 파이썬 추가 → 두 트랙 통합 뷰.

> 주의: 본 저장소 최신(V3_1_FAST)은 크랙밴드(Gf) 대신 고정 소성계수 A를 써
> **메시 민감성**이 있을 수 있음. 균열밴드를 "정량 폭"으로 보여주려면
> crack-band Gf(야른 12.5 / 매트릭스 1.0 N/mm, Ge2018) 재도입 또는 메시 고정 통제 필요.

## 5. 노벨티 (현재 열충격 연구와의 차별)

| | 현재 열충격 CDM 연구(석사) | 이 후속 연구(박사 스코프) |
|---|---|---|
| 하중 | 이상화된 균일 열사이클 | **삭마 연동 실경계조건**(후퇴로 가혹도 증가) |
| 범위 | CMC RVE 단일 재료 | **TPS 스택 시스템**(삭마재+본드라인+CMC) |
| 시간축 | 사이클수 | **미션(재사용) 횟수** — 기하+손상 이중 이월 |
| 산출 | 열화맵(온도·사이클) | **재사용 손상지도** = "안전 재사용 횟수" |
| 기여 | 열피로항 이식·연계 | **연구실 두 트랙 통합** + 시스템 수명예측 |

**한 줄 노벨티:** 검증된 C/SiC CDM(Ge/Zhang) + 삭마 후퇴 경계 + 다중미션 상태이월을
결합해, "삭마재 뒤 CMC가 몇 번의 재사용까지 안전한가"를 해석으로 답하는 최초의
통합 재사용 TPS 손상예측 프레임워크.

## 6. 단계별 실행계획

| 단계 | 할 일 | 선행 | 기간(대략) |
|---|---|---|---|
| **P0 인터페이스 정의** | 삭마↔CMC 교환량 표준 규격 확정: 본드라인 T(t)/q(t) + 후퇴량 Δ 의 파일 포맷(CSV→Abaqus `*Amplitude`) | — | 1~2주 |
| **P1 매크로 스택 열해석** | [삭마재│CMC] 1D/축대칭 열모델. 삭마 후퇴는 이동경계/등가절연으로. 본드라인 온도 연속성 검증 | P0 | 2~4주 |
| **P2 단방향 연계(1미션)** | 삭마 출력 → 매크로 열 → RVE 국소 T(t) → 열충격 CDM 1회. 손상장·잔류물성·**균열 뷰어** 확보 | 현 열충격 연구 CDM 동작 + P1 | 4~8주 |
| **P3 다중미션 루프** | 기하 이월(후퇴로 삭마재 축소) + 손상 이월(`*Restart`/SDV) 자동화 → 잔류강도 vs 미션수 곡선 | P2 | 6~10주 |
| **P4 재사용 손상지도** | 파라메트릭 스윕(삭마재 두께·열유속·냉각속도) → "안전 재사용 횟수" 지도 + 과도 열충격 대표 케이스 | P3 | 8~12주 |
| **P5 검증·집필** | 아래 검증전략 종합 + 논문화 | P4 | 병행 |

> 안전판 = P2까지(1미션 연계, 결과 보장). 노벨티 핵심 = P3~P4(다중미션 지도).
> 시간이 빠듯하면 P4 스윕 축소, 여유 있으면 3D 스택·복수 임계위치로 확장.

**당장 할 수 있는 것(해석엔진 없이도):** P0 인터페이스 규격 문서화 +
삭마 코드가 이미 내보내는 출력 항목 목록 확보 + 본 저장소 SDV→뷰어 매핑 확정.

## 7. 검증 전략 (직접 실험 없이, 부분별 대조)

통합 시스템의 완벽한 검증데이터는 드무므로 **구간별로 쪼개서** 신뢰를 쌓는다.

- **V-삭마:** 삭마 트랙은 이미 학위논문 수준으로 검증됨 → 그대로 인용.
- **V-CMC:** 현재 열충격 연구의 L1~L5(Zhang2022 강도, XRD TRS ~125MPa, A03 포화 등) 재사용.
- **V-연계(신규):** 본드라인 온도 연속성(에너지 보존)·후퇴량-절연 감소의 물리적
  단조성 등 **정성 정합성**으로 검증. "정확값"이 아니라 "경향·크기"가 맞으면 성공.
- **한계 명시:** 산화(공기 중 탄소 소모), 양방향 강연계, 삭마재-CMC 계면 박리는
  범위 밖으로 선 긋기.

## 9. 확정이 필요한 결정사항 (사용자 확인용)

1. **스케일 전략:** 서브모델링(권장) vs 균질화 매크로 CDM — 1차는 서브모델링 가정.
2. **CMC 스케일 산출물:** RVE 국소 손상만 볼지, 패널 전체 손상장까지 볼지.
3. **삭마 출력 접근성:** 삭마 코드가 현재 내보내는 항목(본드라인 온도? 열유속?
   후퇴량 시간이력?)의 실제 포맷 — P0 인터페이스 설계의 입력.
4. **뷰어 통합 수준:** 손상 컨투어까지 vs 요소삭제 이산균열까지 vs 삭마 뷰어와
   완전 통합 애니메이션까지.
