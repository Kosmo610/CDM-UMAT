# 용어 사전 — `원문(쉬운 뜻)` 정본

**규칙은 `CLAUDE.md` §7-1.** 모든 채팅과 모든 `.md`에서 전문용어는
**`원문(쉬운 뜻)`** 형태로 처음 한 번 풀어 쓴다. 괄호 안 문구가 답변마다 달라지면
안 되므로 **이 파일이 정본**이다. 새 용어를 처음 풀었으면 여기에 추가한다.

## 1. 재료와 만드는 법

| 원문 | 괄호에 넣을 쉬운 뜻 | 조금 더 |
|---|---|---|
| **CMC** | Ceramic Matrix Composite, 세라믹 안에 섬유를 넣어 잘 안 깨지게 만든 재료 | 세라믹은 단단하지만 잘 깨진다. 섬유가 균열을 붙잡아 준다 |
| **C/SiC** | 탄소 섬유 + 탄화규소 반죽으로 만든 복합재 | `섬유/기지` 순서로 읽는다 |
| **matrix** | 기지, 섬유 사이를 메우는 바탕 재료 | 우리 것은 SiC |
| **fibre / yarn / tow** | 섬유 / 얀, 섬유 수천 가닥을 묶은 실다발 | 얀 = tow = 실다발. 셋이 같은 말이다 |
| **interface** | 계면, 섬유와 기지가 맞닿는 얇은 껍질층 | 여기가 미끄러져야 안 깨진다 |
| **plain weave** | 평직, 실을 한 올 걸러 한 올 위아래로 짠 가장 기본 무늬 | 우리 재료의 짜임 |
| **2D / 3D** | 2D는 천을 겹쳐 쌓은 것, 3D는 두께 방향으로도 실을 꿰맨 것 | `[28]`은 2D, `[17]`은 3D |
| **warp / weft** | 날실(세로 실) / 씨실(가로 실) | |
| **preform** | 프리폼, 반죽을 넣기 전 섬유만 짜 놓은 뼈대 | |
| **CVI** | Chemical Vapour Infiltration, 기체를 스며들게 해 굳히는 제조법 | 우리 재료·`[28]`·`[43]` 전부 이 방식 |
| **PIP** | Polymer Infiltration and Pyrolysis, 액체를 붓고 태워 굳히는 제조법 | CVI보다 구멍이 많다 |
| **porosity** | 공극률, 재료 안에 빈 구멍이 차지하는 비율 | 강성과 열전도를 둘 다 떨어뜨린다 |
| **T300** | 가장 흔한 표준 탄소섬유 상표 이름 | 탄성계수 약 230 GPa |

## 2. 시험과 재료의 거동

| 원문 | 괄호에 넣을 쉬운 뜻 | 조금 더 |
|---|---|---|
| **off-axis** | 섬유 방향에서 비스듬히 기울여 자른 | 15°·30°·45° 시편 |
| **on-axis** | 섬유 방향과 나란하게 자른 | 0° 시편 |
| **GCS** | Global Coordinate System, 시편을 기준으로 본 축 | 잡아당기는 방향 |
| **MCS** | Material Coordinate System, 실이 놓인 방향을 기준으로 본 축 | 파손 판정은 항상 이쪽 |
| **monotonic** | 단조, 한 번에 쭉 당겨 끊는 시험 | |
| **cyclic** | 반복, 당겼다 놨다를 되풀이하는 시험 | |
| **hysteresis loop** | 이력 고리, 당길 때와 놓을 때 길이 다른 고리 모양 | 안쪽 넓이가 빠져나간 에너지 |
| **unloading modulus** | 제하 기울기, 힘을 뺄 때 그려지는 직선의 기울기 | 손상량을 이걸로 잰다 |
| **elastic modulus** | 탄성계수, 얼마나 뻣뻣한지를 나타내는 값 | 기호 `E` |
| **Poisson's ratio** | 푸아송비, 당기면 옆이 얼마나 홀쭉해지는지 | 기호 `ν` |
| **proportional limit (PLS)** | 비례한도, 직선이던 그래프가 휘기 시작하는 지점 | 첫 균열이 생기는 곳 |
| **ultimate strength** | 최대강도, 끊어지기 직전 버틴 최대 힘 | |
| **inelastic strain** | 비탄성 변형률, 힘을 다 뺐는데도 남아 있는 늘어남 | 계면 미끄럼 때문에 생긴다 |
| **softening** | 힘이 떨어지는 구간, 무르는 것 | 「연화」를 쓰지 않는다 |
| **quasi-brittle** | 준취성, 유리처럼 툭 깨지되 아주 조금은 버티는 성질 | |
| **Iosipescu** | 아이오시페스쿠, 가운데를 V자로 판 전단 시험용 시편 | 규격 ASTM C1292 |
| **AE** | Acoustic Emission, 재료가 금 갈 때 내는 소리를 마이크로 듣는 것 | |
| **Kaiser effect** | 카이저 효과, 예전 최대 힘을 넘기 전에는 새 소리가 안 나는 현상 | 우리 shakedown 문제의 뿌리 |
| **SEM** | Scanning Electron Microscope, 아주 크게 확대해 보는 전자현미경 | 부러진 면을 본다 |
| **XRD** | X-Ray Diffraction, 엑스선으로 속에 남은 힘을 재는 방법 | `[15]`의 TRS 실측 |
| **thermal shock** | 열충격, 뜨거운 것을 갑자기 식히는 것 | |
| **quench** | 급랭, 공기나 물로 확 식히는 것 | |
| **residual strength** | 잔여강도, 학대받고 난 뒤에도 남아 있는 힘 | |

## 3. 모델과 수식

| 원문 | 괄호에 넣을 쉬운 뜻 | 조금 더 |
|---|---|---|
| **CDM** | Continuum Damage Mechanics, 금이 간 정도를 0~1 숫자 하나로 뭉뚱그려 다루는 방법 | 이 논문의 뼈대 |
| **damage variable** | 손상 변수, 처음보다 얼마나 물러졌는지를 0~1로 적은 숫자 | `d = 1 − 지금 기울기 / 처음 기울기` |
| **damage deactivation** | 손상 비활성화, 눌러서 금이 다시 맞물리면 뻣뻣함이 되살아나는 것 | 우리 `HCLO` 스위치 |
| **crack closure** | 균열 닫힘, 벌어졌던 금이 다시 붙는 것 | 위와 같은 이야기 |
| **unilateral behaviour** | 한쪽만 다른 거동, 당길 때와 누를 때가 딴판인 성질 | |
| **TRS** | Thermal Residual Stress, 식으면서 저절로 갇혀 버린 속 힘 | 이 논문의 핵심 변수 |
| **CTE** | Coefficient of Thermal Expansion, 1도 올라갈 때 얼마나 늘어나는지 | 기호 `α` |
| **stress-free temperature** | 응력자유온도, 속 힘이 0이라고 보는 기준 온도 | 물성 가정이지 솔버 설정이 아니다 |
| **failure criterion** | 파손기준, 어떤 힘 조합에서 깨지는지 정한 규칙 | Hashin·Tsai-Wu 등 |
| **fracture energy** | 파괴에너지, 금 하나를 끝까지 벌리는 데 드는 에너지 | 기호 `Gf` |
| **crack band** | 균열대, 금을 선이 아니라 한 칸 두께의 띠로 퍼뜨려 보는 요령 | 메시를 바꿔도 답이 안 변하게 한다 |
| **mesh dependency** | 메시 의존성, 격자를 잘게 나눴다고 답이 달라지는 나쁜 성질 | |
| **homogenisation** | 균질화, 복잡한 속 구조를 매끈한 한 덩어리 물성으로 바꾸는 것 | |
| **RVE** | Representative Volume Element, 무늬가 반복되는 최소 한 칸 | 이거 하나만 계산한다 |
| **PBC** | Periodic Boundary Condition, 한 칸만 계산하려고 양쪽 면을 묶는 조건 | |
| **effective property** | 유효물성, 균질화해서 나온 대표 물성값 | `C̄`, `ᾱ`, `k̄` |
| **multi-scale** | 다중스케일, 실 한 올 크기와 부품 크기를 이어 붙여 푸는 것 | 우리 노벨티의 절반 |
| **shakedown** | 셰이크다운, 몇 번 하다 보면 더는 나빠지지 않고 자리 잡는 것 | 우리 핵심 문제 |
| **cycle jump** | 사이클 점프, 100번을 다 계산하지 않고 건너뛰어 미는 요령 | |
| **plasticity** | 소성, 힘을 빼도 안 돌아오는 찌그러짐 | |
| **dissipation** | 에너지가 빠져나가는 것 | 「소산」을 쓰지 않는다 |

## 4. 해석과 수치

| 원문 | 괄호에 넣을 쉬운 뜻 | 조금 더 |
|---|---|---|
| **UMAT** | User MATerial, Abaqus에 내 재료 계산식을 직접 끼워 넣는 프로그램 | 우리가 짠 Fortran |
| **SDV** | State Dependent Variable, 매 순간 기억해 두는 내부 숫자들 | 손상값이 여기 산다 |
| **tangent / consistent tangent** | 접선(그 점에서의 기울기) / 일관접선(Abaqus가 수렴하려고 요구하는 기울기 행렬) | |
| **secant** | 할선, 원점에서 그 점까지 곧게 그은 기울기 | |
| **convergence** | 수렴, 계산이 답에 가서 붙는 것 | 안 붙으면 잡이 죽는다 |
| **cutback** | 컷백, 안 붙으면 시간 간격을 줄여 다시 해 보는 것 | |
| **increment** | 증분, 한 번에 나아가는 시간·하중 토막 | |
| **residual** | 잔차, 아직 안 맞은 나머지 오차 | |
| **restart** | 리스타트, 중간부터 이어서 다시 돌리는 것 | |
| **field output** | 필드 출력, 결과 파일에 남기는 값 목록 | 빠뜨리면 재실행 |
| **element / mesh** | 요소 / 메시, 물체를 잘게 나눈 조각과 그 격자 | |
| **CELENT** | Abaqus가 알려주는 그 요소의 대표 크기 | 균열대 폭으로 쓴다 |
| **Biot number** | 비오 수, 겉만 식는지 속까지 같이 식는지 가늠하는 숫자 | 급랭 해석의 판정값 |
| **boundary layer** | 경계층, 표면 가까이 온도가 급히 변하는 얇은 층 | 메시가 이걸 풀어야 한다 |

## 5. 문헌과 데이터

| 원문 | 괄호에 넣을 쉬운 뜻 | 조금 더 |
|---|---|---|
| **constituent** | 구성재, 섬유·기지·계면 각각의 재료 | **카드 입력은 여기서만** |
| **composite** | 복합재, 그것들을 합쳐 놓은 최종 재료 | 측정값은 **검증 전용** |
| **card** | 카드, UMAT에 넣는 물성 숫자 묶음 | |
| **knob** | 노브, 맞춰 볼 여지가 있는 조절 손잡이 값 | 근거 있는 값과 구분한다 |
| **calibration** | 보정, 실험을 맞히도록 값을 조절하는 것 | |
| **digitize** | 디지타이즈, 논문 그림에서 점을 찍어 숫자를 되찾는 것 | |
| **provenance** | 출처 계보, 이 숫자가 어느 논문 어느 표에서 왔는지 | |
| **misattribution** | 출처를 잘못 붙인 것 | 「오귀속」을 쓰지 않는다 |
| **orphan reference** | 고아 참고문헌, 목록에는 있는데 본문 어디서도 안 부르는 것 | |
