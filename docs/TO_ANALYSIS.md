## 미처리

### [A1] 공극률은 질문에 따라 값이 다르다 — 하나로 쓰지 말 것
- 무엇이 바뀌나 : 서술과, 공극을 넣을 경우의 입력값
- 값 : **열전도·열해석 → 총량 19.6 %** / **산화·사이클 손상 k → 열린 공극 10–15 %**
- 출처 : `refs/[28]` §2.1 (fulltext) + 같은 논문 밀도의 혼합칙 역산
- 카드 적법성 : 구성재 수준 ✔ (복합재 강도값이 아님)
- 무효화되는 것 : 없음. 기존 RVE는 공극 0이며 그 사실 자체가 한계로 기록되어 있음
- 검증 : `python3 data/properties/conductivity_bounds.py --check` (34항목)

### [A2] 전단 회복 계수 HCLOS는 [0,1] 전 범위를 받아야 한다
- 무엇이 바뀌나 : `HCLOS` 슬롯 설계 (M6 이후 구현 예정)
- 근거 : `refs/[28]` §3.2 — *"damaged shear modulus **partly or even fully**
  recovers"*. 작은 보정이 아니라 **완전 회복까지** 가능하다.
- 출처 : `refs/[28]` (fulltext, 2026-08-04 전문 재독)
- 검증 : 구현 시 T2 회귀 (기본값 0에서 비트 동일)
