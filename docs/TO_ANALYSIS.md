## 미처리

### [A1] 공극률은 질문에 따라 값이 다르다 — 하나로 쓰지 말 것
- 무엇이 바뀌나 : 서술과, 공극을 넣을 경우의 입력값
- 값 : **열전도·열해석 → 총량 19.6 %** / **산화·사이클 손상 k → 열린 공극 10–15 %**
- 출처 : `refs/[28]` §2.1 (fulltext) + 같은 논문 밀도의 혼합칙 역산
- 카드 적법성 : 구성재 수준 ✔ (복합재 강도값이 아님)
- 무효화되는 것 : 없음. 기존 RVE는 공극 0이며 그 사실 자체가 한계로 기록되어 있음
- 검증 : `python3 data/properties/conductivity_bounds.py --check` (34항목)

### [A2] 전단 회복 계수 HCLOS는 [0,1] 전 범위를 받아야 한다
- 무엇이 바뀌나 : `HCLOS` 슬롯 설계 (M6 이후 구현 예정)
- 근거 : `refs/[28]` §3.2 — *"damaged shear modulus **partly or even fully**
  recovers"*. 작은 보정이 아니라 **완전 회복까지** 가능하다.
- 출처 : `refs/[28]` (fulltext, 2026-08-04 전문 재독)
- 검증 : 구현 시 T2 회귀 (기본값 0에서 비트 동일)
- **보강 (2026-08-06)** : `refs/[54]` Chaboche 1995를 OCR로 전문 판독. 닫힘
  가중계수 $\eta$가 **"values between 0 and 1"** 로 출판되어 있다 — [0,1] 전
  범위는 [28] 관측에 더해 **정식화의 원전이 이미 규정한 범위**다. 같은 논문이
  닫힘 시 **부호 바뀐 수직 변형률의 대각 강성항만** 수정해야 연속성이 보장됨을
  보인다(식 16) — 현행 "전단 비회복 + 수직항만" 구현과 같은 원리. 제3장 §3.4.2에
  기록.

### [A3] 사이클 손상 검증·보정 표적 통합본 — 신규 8편 반영 최신판 (2026-08-06)
- 무엇이 바뀌나 : **M6 이후 사이클 보정의 표적과 목적함수 설계 전부.**
  제6장 골격(`docs/CH6_RESULTS_DISCUSSION.md`)과 판정기
  `data/literature/thermal_cycling_dataset.py --check` (31항목)가 정본이다.
- **표적 목록 (T1–T6)** :

  | # | 값 | 출처 | 용도 |
  |---|---|---|---|
  | T1 | 60사이클 후 **모듈러스 45 %** (900↔300 °C 공기) | `refs/[03]` | **1차 보정 표적** — E(N) 프로브가 읽는 값 |
  | T2 | 60사이클 후 강도 63 % | `refs/[03]` | 검증(보정에 안 씀) |
  | T3 | >100사이클 후 강도 83 % (1300↔300 °C 공기) | `refs/[02]` | k **부호** 정성 확인 전용 |
  | T4 | 강도 526→498→473→463 MPa (10/20/30사이클, 1300 °C) | `refs/[65]` | 포화 곡률 |
  | T5 | **구속응력 +62.5 → −14.0 MPa** (50사이클, 900↔1200 °C, 습윤 O₂), 손상변형률 0.06 % | `refs/[68]` | **구속 BC 재현 표적** — 부호 반전이 1급 판정 |
  | T6 | 아르곤 98.90 / 건조 O₂ 96.46 / 수증기 95.82 / 습윤 O₂ 88.92 % | `refs/[43]` | 분위기 고정 근거 |

- **덱·카드에 걸리는 제약 4개** :
  1. $C(T)$·$k$는 **ΔT가 아니라 $T_{max}$의 함수**. 근거는 심각도 역설 —
     사이클당·K당 [03]이 [02]보다 **6.05배** 손상적. ΔT 단조 카드로는 두
     데이터셋 중 하나가 반드시 틀린다.
  2. 보정 분위기는 **공기/습윤 O₂ 계열 하나로 고정**. 아르곤 값(98.90 %)을
     목적함수에 섞지 말 것.
  3. **무응력 온도는 사이클 수와 무관한 상수.** `refs/[71]`(XRD: 가열 시 줄고
     냉각 시 복귀)·`refs/[72]`(라만: 영구 변화 없음). "사이클이 돌수록 TRS가
     풀린다"는 모델링은 근거 없음.
  4. 지표 분리 — **사이클 손상 = 모듈러스, TRS 이완 = PLS.** 같은 목적함수
     금지 (a1-0012 정정, `refs/[03]` 원문 명시).
- 검증 : `python3 data/literature/thermal_cycling_dataset.py --check` (31),
  `python3 verification/check_ch6_numbers.py` (27)
- 무효화되는 것 : 없음 (기존 카드가 이 표적들을 아직 안 쓰고 있으므로 순수 추가)
