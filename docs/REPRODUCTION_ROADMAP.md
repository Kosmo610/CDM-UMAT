## 1. 먼저 알아야 할 벽

**논문의 냉각 상태는 올바른 3D RVE 에서 원리적으로 못 만든다.**
이것은 추측이 아니라 세 절이 각각 다른 경로로 도달한 결론이다.

| 무엇 | 값 | 출처 |
|---|---|---|
| 논문 Fig.4 가 요구하는 잔류응력 상승률 | 1.512 MPa/K | §5.3 |
| 등2축 **완전구속** 이론값 | 1.500 MPa/K | §5.3 |
| 우리 모델 실측 | 0.443 MPa/K (**구속효율 37 %**) | §5.3 |
| 얀이 **무한히 단단해도** 천장 | 0.411 MPa/K (27 %) | §5.4 |
| 논문 손상률을 내는 데 필요한 유효 기지강도 | **113 MPa (88 %) / 33 MPa (100 %)** | §5.29C |
| 논문 자신의 Table 2 기지강도 | **310 MPa** | 논문 |

**PBC 는 결함이 아니다** — Driver 반력 6개 전부 0, 정식화 등가성
잔차 4e−8 로 검증됐다 (§5.2, B4). 즉 **고칠 버그가 없다.**

논문 Fig.4 는 기지가 "강체 위 박막" 처럼 완전히 갇혀야만 나오는
값이고, 기지가 체적의 50 % 인 3D RVE 에서는 어떤 얀 물성으로도
불가능하다 (§5.3C).

> **따라서 "논문 그림과 똑같이" 는 물성 카드를 논문 값으로 두고는
> 달성할 수 없다.** 달성하려면 논문 Table 2 를 벗어나야 한다.
> 그것을 할지 말지가 아래 결정 게이트다.

## 5. 경로 B — 그림 재현 우선 (3~5주, 해석 6~9회)

### B-1. P5 배치 — 기지 강도 역보정 (준비 1일 + 해석 1.5~3일)

**변수 하나**: 기지 `PROPS(4) XT` **310 → 113 MPa** (§5.29C 의 88 % 목표값).
나머지는 P4 그대로. `setup_p5.py` 를 `setup_p4.py` 틀로 만든다
(계보 가드 + 자체시험 포함).

**부수 효과에 주의** — X_m 을 낮추면 크랙밴드 A 도 같이 바뀐다:

```
g0 = X_m^2/(2E)  이므로  X_m 310->113 이면 g0 가 (113/310)^2 = 1/7.5 로 준다
ATEFF = 2*GLE/(GFT-GLE)  ->  0.653  ->  약 0.068
```

A 가 10배 완만해지므로 **손상장이 저절로 펴진다.** 이것이 §5.32 가
지목한 이진화를 푸는 두 번째 손잡이다. 즉 X_m 하나로 (a) 손상 요소
수와 (b) 손상장 연속성을 **동시에** 건드린다 — 단일변수 규칙(§4)은
지키면서 두 지표가 같이 움직인다.

### B-2. P5 판정 (1일) — **여기가 진짜 게이트**

| 확인 | 통과 기준 | 실패 시 |
|---|---|---|
| 냉각 기지 손상률 | 58.8 % → **85 % 이상** | 경로 A 로 복귀 |
| 냉각 얀 횡손상률 | 34.3 % → **80 % 이상** | 경로 A 로 복귀 |
| 기지 손상장 분포 | 0/0.95 양극단 → **0.4~0.85 연속** | 경로 A 로 복귀 |
| 강도 | 내려갈 것 (예상) | B-3 에서 재보정 |

### B-3. P6 배치 — 강도 재보정 (준비 1일 + 해석 1.5~3일)

P4 에서 A1T=50 이 강도를 올렸으므로 같은 손잡이를 쓴다.

B-2/B-3 가 한 번에 안 맞을 가능성이 높다. 배치 1회 반복분을 잡아둔다.

## 7. 권고

**경로 A 를 먼저 끝내고, 그 결과를 손에 쥔 채 B 를 결정할 것.**

이유:
1. 경로 A 산출물은 경로 B 에서도 그대로 쓴다 (비교 기준선).
2. 경로 B 가 실패해도(§5.29 가 100 % 는 불가라 함) A 의 결과는 남는다.
3. 0단계 진단이 B 의 성공 확률을 크게 바꿀 수 있다 — 특히 0-3
   (냉각 응력 분포)이 "얼마나 뾰족한가" 를 주면 X_m=113 이
   88 % 를 낼지 미리 계산할 수 있다. **해석 0회로 B-2 를 예측**하는
   셈이다.

경로 B 는 논문 Table 2 를 벗어나므로, 하더라도 **"논문 그림을 내려면
유효 기지강도가 113 MPa 여야 한다" 는 발견**으로 보고해야 한다.
그것은 재현 실패가 아니라 **논문의 내부 비일관성을 정량화한 결과**다
(§5.29C 가 이미 해석적으로 계산했고, B 는 그것을 FE 로 확인하는 것).
