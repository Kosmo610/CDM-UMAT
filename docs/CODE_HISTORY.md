## V2_7 감사에서 고친 것

1. **MCRIT 완만밴드 희석 (실질 결함, 미발현 경로).**
   V2_5/V2_6의 `FIT=(1−GW)·Q/XTE, FIC=GW·Q/XC` 분배는 |I1|<0.1Xc 밴드
   안에서 **두 분기를 동시에 희석**했다 — I1=0에서 각각 0.5·Q/X, 즉 손상
   개시에 논문의 2배 응력 필요. 지배 가중치로 정규화(`/max(GW,1−GW)`)해서
   전 구간 `max(FIT,FIC)=Q/X`가 되도록 수정. 밴드 밖·BAND→0 극한은 종전과
   동일. 수치 검증: 연속성/단조성/논문극한 모두 통과.
   *완료된 어떤 해석도 MCRIT=1을 쓰지 않았으므로 기존 결과 무영향.*
2. **GF1T 카드 가드.** 음수 또는 0.5 N/mm 초과(지수 2.0 등을 32번 자리에
   잘못 넣은 경우)를 침묵 통과시키지 않고 XIT. 기지 KGUARD와 동형.
3. **버전 문자열 정리.** 파일 머리가 "V2_2", 에러 메시지가 "V2_1"로 남아
   있던 것 정정 + 헤더에 V2_5/V2_6/V2_7 변경 이력 추가.
