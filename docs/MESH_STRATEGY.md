# 메시 전략 — 거친 메시로 먼저, 수렴성은 나중에

**결론: 제안하신 방식이 맞습니다.** 다만 "나중에 수렴성 검증"이 **모든 출력에 대해**
필요한 건 아니고, **어느 출력이 메시에 민감한지가 갈립니다.** 그걸 알면 검증 범위가
크게 줄어듭니다.

---

## 1. `.ori` 는 메시와 한 몸입니다

TexGen의 `.ori`는 **요소별** 섬유 방향 벡터입니다 (`*Distribution, Location=Element`).
즉 **메시를 새로 뽑으면 `.ori`도 반드시 같이 새로 뽑아야 합니다.** 옛 `.ori`를 새 메시에
쓰면 요소 번호가 어긋나서, 에러 없이 **섬유 방향이 뒤죽박죽인 채로 수렴합니다.**
가장 잡기 어려운 종류의 오류입니다.

TexGen 내보내기 시 mesh `.inp`와 `.ori`를 **항상 쌍으로** 관리하세요.

### 이제 파일을 잃어버릴 일은 없습니다

`assemble_inp.py --inline-ori` 를 쓰면 `.ori` 내용을 덱 안에 **붙여넣어** 자기완결
파일로 만듭니다. 외부 참조가 사라지므로 zip으로 옮기다 빠뜨릴 수 없습니다.

```bash
python3 abaqus/assemble_inp.py coarse_mesh.inp --inline-ori --prefix ZHANG2022_coarse
```

요소당 한 줄이 늘어나므로 **거친 메시(2~4만)와 특히 잘 맞습니다.**
17만 요소짜리 현재 메시에 쓰면 덱이 커지니 그때는 외부 참조를 유지하세요.

## 2. 무엇이 메시에 민감하고 무엇이 아닌가

이게 핵심입니다. **거친 메시로 뽑아도 되는 것과 안 되는 것이 분명히 갈립니다.**

| 출력 | 메시 민감도 | 이유 | 2~4만 요소로 충분? |
|---|---|---|---|
| **균질화 강성 C̄** | **낮음** | 체적 평균. 적분의 수렴은 빠름 | ✅ 충분 |
| **균질화 CTE ᾱ** | **낮음** | 같은 이유 (구속 상태의 체적 평균) | ✅ 충분 |
| **균질화 열전도율 k̄** | **낮음** | 정상 확산장, 매끄러움 | ✅ 충분 |
| **TRS 분포(냉각 후)** | **중간** | 얀/매트릭스 계면의 응력 집중 | ⚠️ 경향은 OK, 피크값은 주의 |
| **손상 개시 위치·패턴** | **높음** | 국부 응력 집중이 지배 | ❌ 수렴성 필요 |
| **균질화 강도 X̄, Ȳ, S̄** | **높음** | 국부화(localization) | ❌ 수렴성 필요 |
| **연화 거동 / 파괴에너지** | **원래는 매우 높음** | 국부화 밴드 폭이 요소 크기 | ⚠️ §3 참조 |

**따라서 초기 단계에서 거친 메시로 해도 되는 일:**
- 워크플로 전체 점검 (덱이 도는지, 후처리가 붙는지, 드라이버 순서 확인)
- `RVE_ELAS`, `RVE_CTE`, `RVE_COND` → **C̄, ᾱ, k̄ 는 거의 최종값**
- 파라미터 보정의 **1차 탐색** (어느 knob이 어느 방향으로 움직이는지)

**정밀 메시가 필요해지는 시점:**
- `RVE_STR_*` 로 균질화 **강도**를 확정할 때
- 논문에 실을 **손상 분포 그림**을 만들 때

## 3. 다행히 이 UMAT은 연화가 메시 정규화되어 있습니다

일반적인 CDM은 연화 구간이 요소 크기에 직접 의존해서, 메시를 바꾸면 강도가 통째로
달라집니다. **우리 UMAT은 crack-band 정규화(`KABAND`, Ge Eqs.19–21)를 이미 구현**하고
있습니다. 파괴에너지 `Gf`를 주면 요소 특성길이 `CELENT`로 연화 계수 `A`를 자동 보정합니다.

```
A = 2·g0·le / (Gf − g0·le)      (g0 = X²/2E, le = CELENT)
```

**즉 강도의 메시 의존성이 원리적으로 제거되어 있습니다.** 그래서 거친 메시가
생각보다 잘 통합니다.

> ### ★ 그런데 이게 수렴성 검증을 논문의 검증 항목으로 만들어 줍니다
>
> crack-band 정규화가 실제로 작동하는지는 **보여야 하는 것**입니다.
> 메시 수렴성 연구를 돌리면 그 그림이 그대로 **Ch.3 코드 검증 절**이 됩니다:
>
> - `Gf = 0`(정규화 끔, 고정 `A`)으로 3개 메시 → 강도가 메시에 따라 **흩어짐**
> - `Gf > 0`(정규화 켬)으로 같은 3개 메시 → 강도가 **모임**
>
> 두 곡선을 나란히 그리면 "우리 모델은 메시 객관적이다"가 **주장이 아니라 결과**가
> 됩니다. 심사에서 반드시 나오는 질문이고, 비용은 해석 3개 추가뿐입니다.

### ⚠️ 3-1. 정규화에는 조건이 있습니다 — 요소가 스냅백 한계보다 작아야 합니다 (2026-08-06)

위 문장 "거친 메시가 생각보다 잘 통합니다"는 **무조건이 아닙니다.** 균열대 공식이
성립하려면 분모가 양수여야 합니다.

```
A = 2·g0·le / (Gf − g0·le)        분모 > 0  ⟺  le < Gf/g0
```

여유를 2 %만 두면 실제 조건은 **`le < Gf/(1.02·g0)`** 이고, 이보다 큰 요소는 `A`가
50으로 클램프되어 **연화 없이 취성 파괴**합니다. 그 요소에서는 정규화가 하는 일이
없으므로, **메시 독립성이 바로 거기서 깨집니다.**

그리고 이 한계는 물성이 바뀌면 함께 움직입니다. `g0 = X²/(2E)` 이므로 **E가 낮아지면
한계가 내려갑니다.** 지금 두 가지가 동시에 E를 낮추거나 요소를 키우는 방향으로
작용합니다.

| 조합 | 스냅백 한계 | 현재 메시에서 초과하는 기지 요소 |
|---|---|---|
| Zhang 카드 (E = 350 000) | 0.2214 mm | **0개** |
| 공극 강하 카드 (E = 213 110) | 0.1348 mm | 0개 |
| 공극 강하 + $\kappa$ 보정(1.92) | **0.0702 mm** | **1 624 / 15 369 = 10.6 %** |

($X_t$ = 310 MPa, $G_f$ = 0.031 N/mm. $\kappa$는 사면체의 `CELENT`가 균열대 폭을
과소평가하는 것을 보정하는 계수로, 제4장 §4.3.3-a에 있습니다.)

**즉 지금 메시는 "카드가 Zhang 값일 때만" 안전합니다.** 공극을 반영하고 사면체
보정까지 켜면 기지 요소의 10 %가 조건 밖으로 나갑니다. 기지 `CELENT`의 90분위가
0.0705 mm라서, 0.0702 mm라는 한계선이 **정확히 메시 분포의 어깨에 걸립니다.**

**그래서 §4의 수렴성 연구가 "나중에 하면 좋은 일"에서 "$\kappa$를 켜기 위한
전제조건"으로 바뀌었습니다.** 순서가 정해집니다.

```
메시 수렴성 검증  →  κ 활성화  →  공극 강하 카드로 강도 확정
```

거꾸로 하면 안 됩니다. κ를 먼저 켜면 기지 요소 10 %가 취성으로 끊긴 채 강도가
나오고, 그 값은 메시를 바꾸면 달라집니다 — 정규화를 켜 놓고 정규화가 안 되는
상태입니다.

> **덱 생성기가 이것을 막습니다.** κ를 켰는데 스냅백이 발생하면 어느 모드인지
> 밝히고 **거부**합니다. 그래서 κ 기본값은 1.0(비활성)이며, 1.92는 측정값으로
> 문서에만 남아 있습니다. 사용자가 명시적으로 요청할 때만 적용됩니다.

## 4. 권장 절차

### 현재 사용 중인 거친 메시 (2026-07-28 확인 완료)

`abaqus/meshes/CSiC_RVE_0135.inp` — TexGen 0.135 mm 설정.

| 항목 | 값 |
|---|---|
| 요소 / 노드 | **26,452 C3D4** / 5,686 |
| RVE 치수 | 3.5 × 3.5 × 0.44 mm, V = **5.39 mm³** |
| 충전율 | 100 % (공극 없음) |
| ElSet | Matrix + Yarn0~3 |
| PBC | `*Equation` 57식, 드라이버 5681–5686 |
| **섬유체적비** | 얀 0.4982 × Vf_yarn 0.79194 = **39.46 %** |

**섬유체적비 39.46 %는 검증된 카드(39.6 %)와 상대차 0.35 %입니다.**
즉 이 메시는 미세 메시와 **같은 복합재**를 나타내므로, 두 메시의 결과 차이는
재료 차이가 아니라 **순수하게 이산화 차이**입니다. 수렴성 검증의 전제가 성립합니다.

**전단 순서 확정:** TexGen이 파일에 명시 —
`driver0=e_x, 1=e_y, 2=e_z, 3=e_xy, 4=e_xz, 5=e_yz` → `--shear-order xy-xz-yz` (기본값).
PBC 식이 `FaceA − FaceB − Lx·U_d0 = 0` 이므로 **U(driver) = 거시 변형률** 그대로입니다.

> 새 메시를 받으면 **돌리기 전에 위 표를 반드시 다시 계산**하세요.
> 특히 섬유체적비가 어긋나면 재료가 바뀐 것이고, 그 상태의 메시 비교는 무의미합니다.

TexGen에서 **2~4만 요소** 메시 + `.ori` 를 뽑고:

**어느 파라미터가 어느 방향으로 얼마나 움직이는지** 파악하는 것입니다.

메시 **3개**를 준비합니다. 요소 수를 대략 **2배씩** 키우는 게 표준입니다:

| 관측량 | M-coarse | M-medium | M-fine | fine 대비 변화 |
|---|---|---|---|---|
| Ē₁, Ē₂, Ḡ₁₂ | | | | **≤1 %면 수렴** |
| ᾱ₁, ᾱ₃ | | | | ≤2 % |
| k̄₁, k̄₃ | | | | ≤2 % |
| X̄t (Gf 켬) | | | | **≤5 %면 정규화 성공** |
| X̄t (Gf 끔) | | | | 비교군 — 크게 흩어져야 정상 |
| 해석 시간 | | | | |

**판정 기준을 미리 정해두는 게 중요합니다.** 돌리고 나서 "이 정도면 됐다"고 하면
심사에서 약합니다. 위 표의 허용 오차를 논문에 먼저 쓰고, 결과가 그 안에 드는지 보이세요.

#### 크기 목표가 어림이 아니라 숫자로 정해져 있습니다 (2026-08-06)

§3-1에서 나온 결론입니다. **기지 요소 전부가 `CELENT` < 0.0702 mm 를 만족해야**
공극 강하 카드에 $\kappa$ 보정을 켤 수 있습니다. 그래서 수렴성 연구의 각 메시는
관측량 표에 더해 다음 한 줄을 반드시 보고합니다.

| 메시 | 기지 `CELENT` 최대 | 0.0702 mm 초과 요소 수 | 판정 |
|---|---|---|---|
| M-coarse (현재) | — | **1 624 (10.6 %)** | ❌ κ 못 켬 |
| M-medium | | | |
| M-fine | | | **0개여야 통과** |

- **필요한 세분화 배율은 CELENT 분포에서 직접 계산합니다.** 현재 90분위가 0.0705 mm
  이므로 최소한 그 자리가 내려와야 하지만, 실제로 필요한 배율은 **최대값**이 정하므로
  메시를 뽑을 때마다 분포를 다시 재세요. 요소 수는 배율의 세제곱으로 늘어납니다.
- **기지만 세분화하면 되는지는 확인 전입니다.** 한계 `Gf/(1.02·g0)`는 상(phase)마다
  다르므로 얀에도 각자의 한계가 있습니다. 얀 쪽 노출은 아직 세지 않았으니
  **기지만 줄이면 된다고 가정하지 마세요.**
- 이 한 줄이 논문에서 **왜 수렴성 연구를 했는지에 대한 정량적 답**이 됩니다.
  "정밀도를 위해"가 아니라 "0.0702 mm를 만족시키기 위해"라고 쓸 수 있습니다.

## 5. 거시 모델은 별개입니다

위는 **RVE** 얘기입니다. 거시 열충격 모델(`make_macro_thermalshock.py`)의 메시는
전혀 다른 제약을 받습니다: **열경계층을 두께방향으로 분해**해야 합니다
(현재 표면층 0.143 mm / 두께 3 mm). 그쪽은 `--list-checks` 의 검증 1번에서 확인합니다.

RVE를 거칠게 해도 거시 메시는 거칠게 하면 안 됩니다 — 둘은 독립적으로 정해집니다.
