## 수록 데이터

### YIN2002 — 주 검증 기준 ★ (원문 확보: `refs/[02] yin2002 S.pdf`)

> *Thermal shock behavior of 3-dimensional C/SiC composite*, **Carbon** 40 (2002).
> ScienceDirect: `S0008622301002251`

| 항목 | 값 |
|---|---|
| 재료 | 3D C/SiC, CVI 공정 |
| 저자 | **Yin, Cheng, Zhang, Xu** (인용키를 SUN2002 → YIN2002로 정정) |
| 열충격 방식 | **공기 급랭(air quench)** 1300 °C → 300 °C (ΔT = 1000 °C) |
| 100회 후 잔여 굽힘강도 | **원래의 83 %** |
| 임계 사이클 수 | **약 50회** |
| 50회 이후 거동 | **강도가 더 이상 감소하지 않음 — 균열밀도 포화(crack density saturation)** |
| 연소환경 임계 ΔT | 700 °C |

**모델링에 주는 시사점 (중요):**
"50회 이후 포화"는 사이클 손상 법칙의 **형태를 지정**합니다.
`UMAT_CSIC_THERMSHOCK_V3_0.for`의 누적식

```
Δd_cyc = C · <r − RTH>^n · (1 − d_cyc)^(−k) · ΔN
```

에서 지수 `k`의 **부호**가 거동을 가릅니다.

| k | 거동 | 대응 물리 |
|---|---|---|
| `k > 0` | 가속(runaway) — d_cyc↑ 할수록 더 빨리 손상 | 산화 침투가 지배하는 경우 |
| `k = 0` | 선형 누적 | 중립 |
| **`k < 0`** | **감속·포화** — d_cyc가 DCYMAX로 수렴 | **균열밀도 포화 (YIN2002가 관측한 것)** |

따라서 C/SiC 공기 급랭 기준 케이스는 **k < 0** 으로 두고,
`DCYMAX`가 포화 수준(=잔여강도 83 %)을, `C`가 포화까지 걸리는 사이클 수(≈50)를
결정하도록 보정합니다. 이 2-앵커 보정을 `verification/verify_thermshock.py`가 수행합니다.

### UNVERIFIED1 — 인용 금지

"1000 °C에서 12사이클 후 강도 25 % 저하"는 검색 요약에서만 확인되었고
원 논문을 특정하지 못했습니다. `confidence=secondary`로 표기했으며,
**원문을 찾기 전에는 논문에 쓰지 마세요.**

### ZHANG2013 — ★ 새 주 검증 기준 (`refs/[03] zhang2012 S.pdf`)

> **C. Zhang, X. Wang, B. Wang, Y. Liu, D. Han, S. Qiao, Y. Guo**,
> *Thermal Shock Properties of a 2D-C/SiC Composite Prepared by Chemical Vapor
> Infiltration*, **JMEPEG 22 (2013) 1680–1687**

| 항목 | 값 |
|---|---|
| 재료 | **2D** C/SiC, CVI + 다층 자기치유 코팅 |
| 열충격 | 대기 중 **900 ↔ 300 °C** 반복 |
| 강도 | **20 사이클 이내에서는 인장강도 유지** |
| 강성 | **탄성계수는 사이클 수 증가에 따라 점진적으로 감소** |

**YIN2002보다 이 논문이 우리 논문에 더 잘 맞습니다:**
(1) **2D** — 우리 아키텍처와 동일 (YIN2002는 3D),
(2) **잔여 탄성계수 vs 사이클 수** — 우리 거시 모델의 **주 출력**,
(3) 굽힘이 아닌 **인장**.

강도는 유지되는데 강성만 떨어지는 거동은 CDM에서 자연스럽게 나옵니다
(손상이 강성을 낮추지만 파손지수는 아직 임계에 못 미침). **좋은 검증 시나리오입니다.**

## 파손기준 데이터 (2026-07-28 추가) — `failure_criteria.csv`

C4(Hashin / Tsai–Wu / D-criterion 비교)를 위한 데이터입니다. 30행.

### `role` 열 — 이 파일에서 가장 중요한 열

| 값 | 뜻 |
|---|---|
| `input` | UMAT 카드에 넣어도 되는 값 |
| `validation` | **복합재 측정값. 모델이 예측해야 할 대상.** 카드에 넣으면 TRS 이중계산 |

D-criterion의 임계손상(`D11max` 등)은 애매한 경우라 따로 설명을 달아 두었습니다:
Tsai–Wu가 `Xt/Xc/S12`로 정의되듯 이 기준은 임계손상으로 **정의**되므로 `input`이지만,
**기준의 성질**이지 우리 재료의 성질이 아닙니다. M3 이후 우리 RVE 값으로 교체합니다.

### 수록 출처

| 키 | 출처 | 내용 |
|---|---|---|
| `YANG2015` | `refs/[27]` Compos. A 77 (2015) 181 | D11max=0.5224, D22max=0.5224, D66max=0.5405, 손상진화식 계수, off-axis 강도 3점 |
| `YANG2014` | `refs/[33]` TAML 4 (2014) 021007 | D-criterion 원전. 포락선 그림에 쓰인 두 재료의 강도, 전단 knockdown 계수 η₁/η₂ |
| `YAN2011` | `refs/[35]` Mater. Des. 32 (2011) 3504 | **면내전단강도 vs 온도 7점 (디지타이즈)** |

### 검증한 것

- `D11max`: `3.6e-3·226 − 5.7e-6·226² = 0.5225` → 논문이 적은 0.5224와 일치.
  **PDF 텍스트 레이어에서 `B`의 지수(10⁻⁶)가 날아가 있었고**, 논문 자신이 적은
  0.5224를 만족하도록 역산해 복구했습니다.
- `D66max`: `4.3e-3·125.7 = 0.5405` → 논문 값과 일치.
- `YAN2011` 온도축 보정: 자동 검출한 피크가 **1273 K에 정확히 떨어짐**.
  논문 결론이 "최대는 1273 K"라고 명시하므로 축 보정이 맞다는 독립 확인입니다.

### ★ `YAN2011`이 TRS 검증점이라는 것

면내전단강도가 상온→1273 K에서 **39 % 증가**한 뒤 감소합니다. 논문은 이유를
**제조온도에 가까워지며 계면 열잔류 인장응력이 완화되기 때문**이라고 설명합니다.
→ TRS를 실제로 푸는 모델이면 이 곡선 모양이 **입력 없이** 나와야 합니다.
우리 무응력 온도는 1323 K이므로 **우리 피크는 1323 K 근처**여야 합니다.
자세한 논의는 `docs/NOVELTY.md` §4.

## 열전도 데이터 (2026-07-28 추가) — `thermal_conductivity.csv`

**`k2` 공백이 닫혔습니다.** 역보정이 아니라 **문헌에서 직접** 나왔습니다.

| 값 | 출처 | 비고 |
|---|---|---|
| 탄소섬유 `k11 = 8`, **`k22 = 1` W/(m·K)** | `refs/[22]` Table 1 **및** `refs/[17]` Table 1 | **두 논문이 독립적으로 같은 값** |
| SiC 매트릭스 `k = 25` W/(m·K) | `refs/[17]` Table 3 | Snead 단결정 293을 대체해야 함 |
| 공극 `k = 0.025` (공기) | `refs/[22]`, `refs[17]` | |
| **복합재 두께방향 `k̄₃ = 6.29`** | `refs/[12]` 본문 | **역보정 목표값** |

`refs/[17]`은 섬유가 `E11=230 GPa, Xt=3530, Xc=2470 MPa` — 사실상 **우리 섬유**라
값이 그대로 이전됩니다.

분석은 `data/properties/conductivity_bounds.py` (`--check`로 11개 자체검사).
결론 세 줄:

1. **`k2`는 2차 불확실성.** 문헌 범위(1→8) 전체를 훑어도 `k̄₃`가 2.2배 움직이는 반면,
   **매트릭스 전도율은 9.3배** 움직입니다. 고칠 순서가 정해집니다.
2. **Snead 단결정 값(293)은 입력으로 쓸 수 없습니다.** 섬유 횡방향 전도율을 **0으로
   놔도** `k̄₃`가 61 W/(m·K) 아래로 안 내려갑니다 — 측정값 6.29의 10배. 추정이 아니라
   **증명**이고 솔버가 필요 없습니다.
3. **공극이 빠져 있습니다.** `k_m=25, k2=1`의 직렬 하한이 6.74인데 측정값이 6.29 —
   **하한이 측정값보다 높습니다.** 치밀 2상 모델로는 위에서 접근할 수 없다는 뜻이고,
   PIP/CVI 매트릭스에서 그건 공극입니다. 4.5 %면 메워지는데, `[22]`가 X선 CT로 측정한
   값은 24 %입니다 — **간극이 작고 공극이 그것을 여러 배로 덮는다**는 뜻이지,
   공극률이 4.5 %라는 뜻이 아닙니다.

> **M4 전에 정해야 할 것:** 우리 메시는 **충전율 100 %**입니다. 그대로 돌리면
> `k̄₃`를 과대예측 → 급랭 구배가 **너무 완만** → **비보수적** 방향입니다.
> `make_rve_virtual_tests.py --porosity 0.24` 로 괄호를 치거나, 감가율을 명시하세요.

## 강도 vs 온도 (2026-07-28) — `strength_vs_temperature.csv`

**마지막 구성재 공백이 닫혔습니다.** Snead 2007 **Fig. 15**의 세로축이
*"Strength Retention = 고온강도 / 상온강도"* — 곧 카드의 `fX` **그 자체**입니다.
단위 변환이 필요 없습니다.

Fig.15는 공정별로 **추세선 3개**를 그리는데, **1300 K 위에서 4배 넘게 갈라집니다.**

| 공정 | 1200 K | 1700 K |
|---|---|---|
| Sintered / CVD / FB | 1.05 | **1.26** |
| Hot-pressed / HIP | 0.93 | (하락) |
| Reaction-bonded / CVD+과잉Si | 1.35 | **0.20 (붕괴)** |

우리 매트릭스는 **PIP**라 셋 다 아닙니다. Reaction-bonded는 **화학적으로 배제**됩니다
— 그건 **자유 실리콘** 때문에 무너지는데 PIP엔 자유 Si가 없습니다. 남은 둘이
**Sintered/CVD(기준)** 과 **HP/HIP(비관적 하한)** 입니다.

**우리 범위(296~1323 K)에서 둘이 `fX`를 +8 / −11 %로 감쌉니다.**
→ 기존 `fX = 1.0`은 **틀린 게 아니라 근거가 없었던 것**이고, 이제 근거와 오차한계가
붙었습니다.

> **적용 한계:** 이 카드를 **1400 K 위로 연장하지 마세요.** 거기선 공정이 지배해서
> 단일 배수가 정당화되지 않습니다. 우리 무응력 온도(1323 K)보다 위라 문제되지 않습니다.

### ★ 여기서 정량적 예측이 하나 나옵니다

| 1273 K에서의 강도 증가 | |
|---|---|
| SiC 매트릭스 (Snead) | **+6.0 %** |
| 탄소섬유 (Sauder) | **+8.8 %** |
| **2D C/SiC 면내전단, 실측 (`[35]`)** | **+38.9 %** |

**구성재로는 6~9 포인트밖에 설명이 안 됩니다. 나머지 ~30 포인트는 계면 열잔류응력의
완화에서 나와야 합니다** — `[35]` 자신이 그렇게 결론짓습니다.

이건 카드에 넣을 수 있는 값이 아니라 **모델이 스스로 만들어내야 하는 숫자**이고,
**TRS 미반영(케이스 A)은 원리적으로 못 냅니다.** C1 비교의 채점 기준이 하나 더
생겼습니다. `eval_correlations.py --check`가 이 30 포인트를 assert합니다.

## 디지타이즈 (2026-07-28) — `digitize.py`

`digitized` 등급 행은 **더 이상 사람이 읽은 값이 아닙니다.** `digitize.py`가
PDF를 렌더링 → 축 프레임 검출 → 눈금 격자 보정 → 마커/곡선 기하 검출까지 해서
CSV 값을 **그대로 재생성**합니다. 재현하려면:

```bash
python3 data/literature/digitize.py --check    # 검증만
python3 data/literature/digitize.py --write    # 곡선 CSV까지 재생성
```

### ★ 이 파일이 강제하는 규칙

**모든 그림은 논문이 "글로 적은" 숫자로 검증한다.** 그림에서 읽은 값이 논문 본문의
진술을 재현하지 못하면 축 보정이 틀린 것이고, 스크립트가 **실패**합니다.

| 그림 | 논문의 글 | 디지타이즈 결과 |
|---|---|---|
| YIN2002 Fig.8 | "100회 후 원래의 **83 %**" | **0.840** ✅ |
| ZHANG2013 Fig.4(a) | "60사이클 후 강도 **63 %**" | **0.620** ✅ |
| ZHANG2013 Fig.4(b) | "60사이클 후 계수 **45 %**" | **0.474** ✅ |
| ZHANG2013 Fig.3 | Fig.4(a)와 정합해야 | 259.3 MPa, 비 0.60 ✅ |
| YAN2011 Fig.5 | "최대는 **1273 K**" | **1273.2 K** ✅ |

### 잡아낸 함정 두 가지

1. **프레임 ≠ 축 범위.** Origin 그림은 프레임이 첫/마지막 눈금 바깥까지 갑니다.
   ZHANG2013 Fig.4(a)는 프레임이 −5.1 ~ 65 사이클이라, 프레임을 축으로 쓰면
   **사이클 수가 17 % 틀립니다.** 그래서 눈금 격자를 검출해 최소제곱으로 보정합니다.
2. **곡선을 열 평균으로 읽으면 안 됩니다.** 같은 열에 프레임·눈금·범례 글씨
   ("As-received")·주석 화살표가 같이 있습니다. 평균을 쓰면 무손상 피크가
   258 → 200 MPa로 **22 % 낮아지는데, 여전히 σ–ε 곡선처럼 보입니다.**
   그래서 원점부터 좌→우로 **곡선을 추적**합니다.

### ★★ `zhang2013_stress_strain.csv` — 가장 강력한 검증 자산

Fig.3의 **σ–ε 전 곡선 2개**(무손상 + 60사이클), 69점. 다른 데이터는 점 몇 개지만
이건 곡선 전체이고, **거시 모델이 내놓는 것과 정확히 같은 물건**입니다.
초기 기울기(계수) · 무릎(매트릭스 균열) · 피크(강도) · 그 사이 형상이 **전부**
맞아야 합니다.

### ⚠️ ZHANG2013의 두 그림이 서로 안 맞습니다

| | 무손상 | 60사이클 | 비 |
|---|---|---|---|
| Fig.3 (0~0.03 %) | ~140 GPa | 80.9 GPa | **0.579** |
| Fig.4(b) | 97.7 GPa | 46.3 GPa | **0.474** |

절대값이 **43 % 차이**, 열화비도 다릅니다. Fig.4(b)의 "modulus"는 본문 표현대로
"초기 선형구간 기울기"를 **더 넓은 변형률 구간**에서 맞춘 값(=제하계수)으로 보이며,
이 정도로 비선형인 곡선에서는 진짜 초기 접선보다 한참 낮게 나옵니다.
`refs/[27]`이 비슷한 2D C/SiC에서 **145.7 GPa**를 측정한 것도 Fig.3 쪽입니다.
