# 문헌 검증 데이터 (L3 거시 검증용)

`docs/THESIS_PLAN.md` §5의 **3층 방어** 중 **L3(거시 검증)** 에 쓰는 데이터입니다.
실험을 하지 않는 논문이므로, 거시 모델이 맞는지를 보이는 유일한 방법은
**공개된 반복 열충격 실험 데이터와의 대조**입니다.

---

## ⚠️ 신뢰도 표기 규칙 (반드시 지킬 것)

CSV의 `confidence` 열은 그 숫자를 어디서 얻었는지를 나타냅니다.

| 값 | 의미 | 논문에 인용해도 되는가 |
|---|---|---|
| `fulltext` | 원문 본문/표/그림에서 직접 확인 | ✅ 인용 가능 |
| `abstract` | 논문 **초록**에서 확인 (본문 그림은 미확인) | ⚠️ 인용 가능하나 원문 확인 권장 |
| `digitized` | 원문 그림을 디지타이즈 | ✅ 인용 가능 (디지타이즈 오차 명시) |
| `secondary` | 2차 요약(검색 스니펫 등)에서만 확인, **원문 미확인** | ❌ **인용 금지** — 원문 추적 후 승격 |

> 현재 상태: 이 저장소에는 **논문 원문 PDF가 없습니다.** 아래 데이터는
> 초록/2차 요약 수준에서 확보한 것이며, **`abstract` 행도 원문을 구해
> 그림을 디지타이즈하여 `digitized`로 승격시키는 것이 다음 할 일**입니다.
> 검증 곡선(잔여강도 vs 사이클 수)을 그리려면 점 2개가 아니라 곡선이 필요합니다.

## 수록 데이터

### SUN2002 — 주 검증 기준 ★

> *Thermal shock behavior of 3-dimensional C/SiC composite*, **Carbon** 40 (2002).
> ScienceDirect: `S0008622301002251`

| 항목 | 값 |
|---|---|
| 재료 | 3D C/SiC, CVI 공정 |
| 열충격 방식 | **공기 급랭(air quench)** 1300 °C → 300 °C (ΔT = 1000 °C) |
| 100회 후 잔여 굽힘강도 | **원래의 83 %** |
| 임계 사이클 수 | **약 50회** |
| 50회 이후 거동 | **강도가 더 이상 감소하지 않음 — 균열밀도 포화(crack density saturation)** |
| 연소환경 임계 ΔT | 700 °C |

**모델링에 주는 시사점 (중요):**
"50회 이후 포화"는 사이클 손상 법칙의 **형태를 지정**합니다.
`UMAT_CSIC_THERMSHOCK_V3_0.for`의 누적식

```
Δd_cyc = C · <r − RTH>^n · (1 − d_cyc)^(−k) · ΔN
```

에서 지수 `k`의 **부호**가 거동을 가릅니다.

| k | 거동 | 대응 물리 |
|---|---|---|
| `k > 0` | 가속(runaway) — d_cyc↑ 할수록 더 빨리 손상 | 산화 침투가 지배하는 경우 |
| `k = 0` | 선형 누적 | 중립 |
| **`k < 0`** | **감속·포화** — d_cyc가 DCYMAX로 수렴 | **균열밀도 포화 (SUN2002가 관측한 것)** |

따라서 C/SiC 공기 급랭 기준 케이스는 **k < 0** 으로 두고,
`DCYMAX`가 포화 수준(=잔여강도 83 %)을, `C`가 포화까지 걸리는 사이클 수(≈50)를
결정하도록 보정합니다. 이 2-앵커 보정을 `verification/verify_thermshock.py`가 수행합니다.

### UNVERIFIED1 — 인용 금지

"1000 °C에서 12사이클 후 강도 25 % 저하"는 검색 요약에서만 확인되었고
원 논문을 특정하지 못했습니다. `confidence=secondary`로 표기했으며,
**원문을 찾기 전에는 논문에 쓰지 마세요.**

## 아직 확보해야 할 것 (우선순위 순)

1. **SUN2002 원문 PDF** → 잔여강도 vs 사이클 수 **곡선 전체**를 디지타이즈
   (현재는 N=100의 점 하나 + 임계 N≈50 서술뿐. 곡선이 있어야 제대로 된 검증 그림이 됨)
2. **잔여 탄성계수(강성) vs 사이클 수** 데이터 — 본 논문의 주 출력이 강성 저하이므로
   강도보다 강성 데이터가 더 직접적인 검증이 됨. 후보:
   - *Nonlinear Mechanical Behavior of C/SiC Composites after Cyclic Thermal Shock*
     (Han, Guo, Wang, Liu, Su, Xie, Gao — SSRN, 최신)
   - *Cyclic Thermal Shock Damage Behavior in CVI SiC/SiC High-Pressure Turbine
     Twin Guide Vanes* (2021, PMC8541570)
3. **열물성** — 균질화 검증용 C/SiC 열전도율 k(T), 비열, 밀도
4. **온도의존 물성** — T300 섬유와 CVI/PIP SiC의 E(T), α(T), 강도(T)
   (`UMAT_CSIC_THERMSHOCK_V3_0.for`의 온도 테이블 입력값)
5. **경계조건 확보** — SUN2002의 시편 치수와 급랭 조건(대류계수/유속)
   → 거시 모델을 이 시편으로 만들어야 직접 비교가 됨 (THESIS_PLAN §5)
