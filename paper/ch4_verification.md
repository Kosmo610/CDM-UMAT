# 4. 검증 및 보정

본 장에서는 구축한 UMAT 및 RVE 해석 모델이 기준 논문(Zhang et al., 2022)과 그 구성 모델(Ge et al., 2018)을 충실히 구현하고 있음을 확인하기 위한 검증 방법과, 논문이 공개하지 않은 파라미터를 결정하기 위한 보정(calibration) 전략을 기술한다. 본 장의 범위는 검증의 **방법**과 보정의 **전략**에 한정하며, 보정을 통해 최종 채택된 파라미터 값과 그 결과 응력–변형률 곡선은 3장에서 제시한다.

## 4.1 검증 전략: 3단 분리

기준 논문의 최종 결과인 온도별 거시 극한강도(Table 3)를 재현하려면 116k–174k 규모의 사면체 요소로 이산화된 직조 RVE에 대해 주기경계조건 하의 3-스텝 비선형 해석을 수행해야 하며, 이는 상용 해석기 Abaqus의 실행을 전제로 한다. 그러나 해석 실행 이전에 모델의 구현 자체가 올바른지를 확인하는 작업은 해석기 없이도 엄밀하게 수행할 수 있다. 이에 본 연구는 검증을 다음의 세 층위로 분리하였다.

| 검증 층위 | 대조 기준 | 해석기 필요 여부 | 결과 |
|---|---|:---:|---|
| (a) 재료 상수 | 논문 Tables 1–2 + Chamis/Schapery 마이크로역학 | 불필요 | 일치 (§4.2) |
| (b) 구성방정식 | Ge (2018) 폐형식 수식의 독립 재구현 | 불필요 | 전 항목 PASS (§4.3) |
| (c) 해석 절차 | 논문 §3.2.4의 스텝 구성·경계조건 | 불필요 (입력덱 감사) | 일치 (§4.4) |
| (d) 거시 σ–ε 및 극한강도 | 논문 Table 3 | **필요** | 보정 대상 (§4.5) |

이러한 분리의 요지는 다음과 같다. 층위 (a)–(c)가 모두 통과하면, 층위 (d)에서 발생하는 논문과의 편차는 코드 오류가 아니라 **논문이 공개하지 않은 파라미터**와 메시 차이에서만 기인한다고 논증할 수 있다. 즉 검증(verification)과 보정(calibration)의 책임 경계가 명확해지며, 보정은 물리적으로 정당한 소수의 knob에만 국한된다. 각 층위의 검증은 재현 가능한 스크립트(`micromech_check.py`, `verify_constitutive.py` 등)로 자동화하였다.

## 4.2 재료 상수 검증: Chamis/Schapery 재현

매트릭스(SiC)의 재료 카드(22개 상수)는 논문 Table 2와 직접 대조하였다. $E_m=350$ GPa, $\nu_m=0.20$, $X_{m,t}=X_{m,c}=310$ MPa, $\alpha_m=4.5\times10^{-6}$ /K가 모두 정확히 일치하며, $G_m$은 등방성 관계 $E/2(1+\nu)=145.83$ GPa로 논문의 146 GPa와 0.1 % 이내에서 정합한다.

얀의 재료 카드(38개 상수 중 탄성·열 상수 12개)는 논문에 직접 값이 표기되어 있지 않고, 논문 §3.2.3이 T300 필라멘트(Table 1)와 SiC 매트릭스(Table 2)로부터 Chamis(강성) 및 Schapery(열팽창) 마이크로역학으로 계산하였다고만 기술한다. 이에 카드의 $E_1$으로부터 얀 내 섬유 체적분율을 역산하면 $V_f = 0.79194$가 얻어지며(복합재 전체 섬유 체적분율 약 39.6 %로 논문의 "약 40 %"와 일치), 이 단일 $V_f$로 2장에 제시한 Chamis/Schapery 관계식을 적용하면 12개 얀 상수 전부가 재현된다.

| 상수 | Chamis/Schapery 계산치 | 카드 값 | 상대오차 |
|---|---|---|---|
| $E_1$ | 254967.23 MPa | 254967.228 MPa | 0.000 % |
| $E_2=E_3$ | 44321.74 MPa | 44321.738 MPa | 0.000 % |
| $\nu_{12}=\nu_{13}$ | 0.247516 | 0.247516 | 0.000 % |
| $\nu_{23}$ | 0.395833 | 0.395814 | 0.005 % |
| $G_{12}=G_{13}$ | 26430.91 MPa | 26431.52 MPa | 0.002 % |

12개 얀 상수 전체에 대한 최대 상대오차는 **0.142 %**로, 얀 탄성·열 물성 카드가 논문의 구성재 데이터로부터 유도된 마이크로역학 균질화 결과임이 확인된다. 이로써 기호 사전의 $E_1$–$G_{23}$, $\alpha_1$–$\alpha_3$, $V_f$는 검증된 값으로 확정되어 보정 대상에서 제외된다.

## 4.3 구성방정식 단위검증

UMAT의 모든 커널(얀 손상, 매트릭스 탄소성–손상, 손상발전, 균열대 정규화)을 Python으로 독립 재구현하고, Ge (2018)의 폐형식 수식과 단위 테스트로 대조하였다. 검증 항목과 결과는 다음과 같으며, **전 항목 PASS**이다.

| 검증 대상 (2장 대응 수식) | 내용 | 결과 |
|---|---|---|
| 유효응력 정의 | $\tilde{\boldsymbol\sigma} = C_0:\boldsymbol\varepsilon^e$, 명목응력 $\boldsymbol\sigma = C(d):\boldsymbol\varepsilon^e$ | PASS |
| 3D Hashin 개시 (섬유 인장/압축, 횡 인장/압축) | 4개 모드 손상 개시 지표 $r_I$ | PASS |
| 매트릭스 von Mises 개시 | $\varphi = \sigma_{vM}/X_{m,t}$ 또는 $/X_{m,c}$ ($I_1$ 부호 분기) | PASS |
| 지수 손상발전 | $d = 1 - \exp[A_I(1-r_I)]/r_I$ | PASS |
| 혼합 선형–지수 법칙 (얀 종방향 인장) | Ge (2018) 식 (16)–(17)의 $X_{PO}, r_F, K_1$ | 구현 확인 (스위치 제어) |
| 매트릭스 소성 (연합 유동, 등방 경화) | $\boldsymbol\varepsilon = \boldsymbol\varepsilon^e+\boldsymbol\varepsilon^p+\boldsymbol\varepsilon^{th}$ | 구현 확인 (스위치 제어) |
| 균열대 정규화 | $G_{f,I}$와 특성요소길이 $l_c$로부터 $A_I$ 결정 | PASS |

단위 테스트 출력의 일부를 발췌하면 다음과 같다.

```
Eq.17/19 A=2.0 r=1.5:  code=0.754747 ref=0.754747  PASS
Eq.15/16 vonMises   :  code=155.81078 ref=155.81078  PASS
Eq.11 Hashin fib-t  :  code=1.003466 ref=1.003466  PASS
Eq.13 Hashin trn-t  :  code=0.982379 ref=0.982379  PASS
Eq.19-21 crack-band :  code=0.320359 ref=0.320359  PASS
OVERALL: ALL KERNELS REPRODUCE THE PAPER EQUATIONS -> PASS
```

아울러 단일 재료점 구성거동 곡선에서 각 모드의 응력 최대치가 입력 강도와 일치함을 확인하였다(얀 종방향 인장 1198 MPa vs 입력 $X_t$=1200 MPa, 얀 횡방향 인장 78.7 MPa vs $Y_t$=80 MPa, 매트릭스 309.9 MPa vs $X_{m,t}$=310 MPa — 이때의 강도는 검증용 임시값이며 최종 보정값이 아님). 각 최대치 이후 올바른 지수 연화 분지가 나타난다. 또한 UMAT 소스는 독립 Fortran 컴파일 검사(gfortran, Abaqus 암묵형 규약)를 통과하여 모든 서브루틴 인터페이스의 정합성이 확인되었다. **구성방정식 구현에서 정확성 결함은 발견되지 않았다.**

## 4.4 해석 절차 검증

세 온도의 입력덱(RT23/T500/T1000)이 논문 §3.2.4의 해석 절차를 그대로 따르는지 감사하였다.

1. **스텝 ① (냉각):** 무응력온도 $T_0=1050\,^\circ$C(PIP 공정온도)에서 23 °C까지 냉각하여 열잔류응력과 초기 손상을 형성한다. 무응력온도는 두 재료 모두 `*Expansion, zero=1050`으로 지정되어 논문과 일치한다.
2. **스텝 ② (재가열):** 시험온도가 상온이 아닌 경우 23 °C에서 시험온도(500 또는 1000 °C)까지 가열한다. RT23 덱에는 이 스텝이 없다.
3. **스텝 ③ (인장):** 시험온도를 유지한 채 $x$ 방향 인장을 가한다. 적용 변형률 한계는 온도별로 $\bar\varepsilon_{xx} \le$ 0.15 / 0.32 / 0.48 %로, 고온일수록 커지는 논문의 연성·강도 경향과 정합한다.

열변형률은 Abaqus의 `*Expansion`이 공급하고 UMAT은 기계적 변형률만 받는 분담 구조이며, 주기경계조건은 6개의 `ConstraintsDriver` 더미 절점을 통한 통합 주기경계(Xia 방식)로 부과되어 거시 응력·변형률 $\bar\sigma_{xx}$–$\bar\varepsilon_{xx}$의 추출점 역할을 겸한다. 세 덱 모두 이 구조가 확인되어 해석 절차 층위의 검증을 통과하였다.

## 4.5 미공개 파라미터와 보정 전략

### 4.5.1 보정이 필요한 이유와 대상

층위 (a)–(c)의 검증에도 불구하고 Table 3 수치의 정확한 재현을 막는 요인은 코드 오류가 아니라 **논문이 값을 공개하지 않은 파라미터**들이다. 구체적으로 ① 얀 강도($X_t, X_c, Y_t, Y_c, S_{12}, S_{13}, S_{23}$), ② 얀 연화계수 $A_I$(또는 파괴에너지 $G_{f,I}$), ③ 얀 종방향 인장의 혼합법칙 파라미터($X_{PO}, r_F, K_1$), ④ 매트릭스 소성($\sigma_{Y0}, H_{iso}$)이며, 여기에 ⑤ 메시 차이(본 연구 174,405 C3D4 vs 논문 116,724 C3D4)가 더해진다. 이들은 유도가 불가능하므로 Table 3의 목표치(23/500/1000 °C에서 128.45/179.42/199.15 MPa)에 대해 보정으로 결정한다.

보정 시작값은 물리적 근거를 갖도록 선정하였다. 얀 종방향 강도는 섬유지배 혼합법칙으로 $X_t = V_f \cdot 3580 = 2835$ MPa, $X_c = V_f \cdot 2470 = 1956$ MPa(T300 강도는 Ge (2018) Table 2 = Zhang Table 1), 종방향 파괴에너지는 Ge (2018) Table 3의 $G_{f,1t}=12.5$ N/mm를 차용하였다. 그 외 횡·전단 강도($Y_t$=80, $Y_c$=350, $S$=100–120 MPa), 혼합법칙($X_{PO}$=700, $r_F$=3.0, $K_1$=8000), 매트릭스 소성($\sigma_{Y0}$=250, $H_{iso}$=10⁵ MPa)은 모두 **보정 시작값**이며 논문 발표값이 아니다. UMAT 코드는 수정하지 않고 입력덱의 `*User Material` 카드 숫자만 변경하며, 세 온도 덱의 카드는 항상 동일하게 유지한다(구성재 물성의 온도 독립 가정, 논문 §3.2.3).

### 4.5.2 Knob–관측량 대응

효율적 보정을 위해 각 파라미터가 곡선의 어느 특징을 지배하는지를 먼저 대응시켰다.

| 관측량 | 지배 파라미터 | 조정 방향 |
|---|---|---|
| 초기 기울기 (겉보기 탄성계수) | $Y_t, S_{23}$ (냉각 후 횡방향 얀 예비손상) | $Y_t$↓ → 예비손상↑ → 기울기↓ |
| 비선형 개시 시점 | $Y_t, S_{12}, S_{13}$ | 강도↓ → 조기 비선형 |
| 23 °C 극한강도 (목표 128.45 MPa) | $X_t$ + 혼합법칙 ($X_{PO}, r_F, K_1$) | $X_t$↑, $X_{PO}$↑ → 강도↑ |
| 파단 변형률 | 혼합법칙 tail ($r_F, K_1, X_{PO}$) | $r_F$↑, $X_{PO}$↑ → 연성↑ |
| 잔류(영구) 변형 | $\sigma_{Y0}, H_{iso}$ (매트릭스 소성) | $\sigma_{Y0}$↓, $H_{iso}$↓ → 잔류변형↑ |
| 온도 상승 시 강도 증가 추세 | 자동 (열잔류응력 재분포) | 구성재 강도는 온도독립 유지 |

특히 논문의 핵심 현상인 "고온일수록 강해짐"은 별도 knob 없이 냉각–재가열 스텝의 열잔류응력 재분포(매트릭스 잔류인장의 잔류압축 전환)에서 자동으로 발현되어야 하며, 온도 추세를 맞추기 위해 구성재 강도를 온도별로 달리하는 것은 금지한다.

### 4.5.3 단계별 보정 순서 (Stage A–E)

한 번에 하나의 파라미터 군만 변경하는 원칙 하에 다음 5단계로 진행한다.

- **Stage A (안정성·기저 확인):** 소성 OFF($\sigma_{Y0}=0$)·혼합법칙 OFF($X_{PO}=0$) 상태로 세 해석의 수렴을 확인하고, 냉각 후 매트릭스 손상이 논문과 같이 광범위(≈100 %, 논문: 845 °C에서 완전 손상)한지 상태변수로 점검한다.
- **Stage B (얀 횡·전단):** $Y_t, Y_c, S$를 조정하여 23 °C 곡선의 초기 기울기와 비선형 개시를 맞춘다.
- **Stage C (얀 종방향 + 혼합법칙):** $X_t$와 $X_{PO}, r_F, K_1$으로 23 °C 극한강도(128.45 MPa)와 파단 변형률(≈0.15 %)을 맞춘다.
- **Stage D (매트릭스 소성):** $\sigma_{Y0}, H_{iso}$로 잔류변형과 곡선 형상을 미세조정한다.
- **Stage E (온도 검증):** 동일 카드로 500/1000 °C가 179/199 MPa 근방에 도달하는지 확인한다. 추세가 어긋나면 파라미터가 아니라 냉각 수렴·열팽창계수를 재점검한다.

연화 해석의 수렴 안정화를 위해 점성 정규화 $\eta$(기본 0.02, 필요시 0.05까지), 손상 점프에 따른 자동 증분 감축, $d_{max}=0.99$ 상한, 배정밀도 실행을 적용한다.

### 4.5.4 원장 기반 실행 체계와 추적성

Stage A–E의 시행착오가 자의적 피팅으로 흐르지 않도록, 보정 절차를 상태와 게이트를 갖는 자동화 루프로 구성하였다. 한 번의 반복은 네 노드로 이루어진다: **A0** `make_cards.py`가 knob 이름 단위로 파라미터를 변경하여 3온도 덱의 카드를 동일하게 갱신하고(검증된 탄성·열팽창 슬롯은 잠금 처리) 변경 의도와 함께 원장에 기록, **A1** Abaqus 3온도 해석 실행, **A2** ODB로부터 거시 응력–변형률 곡선 추출, **A3+A4** `evaluate.py`가 극한강도·초기기울기·완주 여부를 산출하고 Table 3 대비 손실(RMS)과 Stage별 PASS/FAIL 게이트를 판정하여 원장에 기록한다. 게이트 통과 시 다음 Stage로 진행하고, 실패 시 제안된 knob 조정으로 같은 Stage를 반복한다.

원장 `ledger.json`에는 반복마다 `{iter, stage, params, changed, results, loss, gates, note}`가 누적되어 모든 파라미터 변경의 이력과 근거가 보존된다. 3장에 실리는 최종 파라미터와 결과 수치는 이 원장의 최종 채택 iteration에서만 인용함으로써, 보정 과정 전체의 추적성과 수치 인용의 일관성을 보장한다.

## 4.6 검증의 한계

본 장의 검증이 보장하는 범위와 보장하지 않는 범위를 명확히 한다.

첫째, 본 연구 환경에는 Abaqus 해석기가 없으므로 층위 (d), 즉 RVE 3-스텝 해석의 **실행 재현은 아직 수행되지 않았다.** 본 장에서 "검증 완료"라 함은 재료 상수·구성방정식·해석 절차의 구현 정합성(층위 a–c)에 한정되며, 거시 응력–변형률 곡선과 극한강도가 논문과 일치한다는 주장은 포함하지 않는다. 이는 사용자 Abaqus 환경에서 4.5절의 보정 루프를 완료한 뒤 3장에서 보고한다.

둘째, RVE 메시가 논문과 다르다. TexGen 기하·메시를 재생성하였기 때문에 본 연구는 174,405개, 논문은 116,724개의 C3D4 요소를 사용하며, 균열대 정규화가 요소크기 의존성을 완화하더라도 이산화 차이에 따른 소폭의 결과 편차는 불가피하다. 따라서 보정 완료 후에도 Table 3 수치와의 잔여 편차 일부는 메시 차이로 귀속될 수 있다.

셋째, 보정으로 결정되는 파라미터들은 논문 미공개 값의 추정이므로, 목표 곡선을 재현하더라도 그것이 논문 저자들이 사용한 값과 동일하다는 보장은 없다(비유일성). 이를 완화하기 위해 시작값에 물리적 근거를 부여하고(§4.5.1), 단계별 게이트와 원장으로 조정 과정을 공개 가능한 형태로 남겼다(§4.5.4). 이러한 한계의 명시적 구분이야말로 "물성·수식·절차는 검증되었고, 남은 것은 미공개 파라미터의 보정"이라는 본 연구 검증 주장의 정직성을 담보한다.
