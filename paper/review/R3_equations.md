## 1. 요약

**수식 건전성 총평.** 식 (2.1)–(2.21) 전부가 UMAT의 실제 구현과 **식 수준에서 정확히 일치**한다 (BLOCKER 없음). Chamis/Schapery 6개 식은 VERIFICATION_REPORT §2.2와 문자 그대로 동일하고, Hashin 4개 식·지수 발전식·균열대 폐형식·반환사상·점성 갱신식 모두 코드 라인과 대응됨을 확인했다. 균열대 폐형식 (2.14)는 독립 유도로 재확인했다(지수 법칙의 총 소산 g₀(1+2/A)·l_c = G_f에서 A = 2g₀l_c/(G_f−g₀l_c)가 정확히 나옴). 다만 두 건의 MAJOR가 있다: ① 혼합법칙 (2.15)–(2.16)의 **문장 해석**("r ≤ r_F에서 선형 연화")은 파라미터 정합조건 하에서만 참이며, 본문이 권하는 시작값(X_PO≈0.25X_t, r_F=3, K1≈3%E₁)에서는 손상이 개시 순간 d≈0.22–0.27로 **점프**한다(수치 검증 완료, 부록 A). ② 식 (2.1)–(2.6)의 입력인 **섬유(필라멘트) 물성 기호·값이 OUTLINE §2에도 ch2에도 없어** 자기완결성이 깨진다.

**최신성 총평.** 채택된 조합(3D Hashin + Matzenmiller계 지수 CDM + 균열대 + Duvaut–Lions 점성 + Xia 주기경계 RVE + 음해법 UMAT)은 2024–2026년 직조/편조 복합재 메소스케일 문헌에서도 **여전히 주류**다. 상대적으로 오래됐지만 통용되는 것은 Chamis/Schapery 해석적 균질화와 얀 Hashin 개시이고, 물리적으로 가장 취약한 고리는 SiC 매트릭스의 **von Mises 유사소성**(취성 세라믹의 미세균열 기구에 대한 현상학적 대체물)이다. 어느 것도 모델 교체가 필요한 수준은 아니며, 각 1문장의 정직한 포지셔닝(§4 제안 문장)으로 방어 가능하다. 위상장(phase-field) 파괴와 ML 다중스케일은 향후 연구로 언급할 것을 권한다.

## 3. 논리 전개 감사

**전개 순서 — 양호.** 탄성/균질화(2.1) → 얀: 유효응력·강성저감(2.2.1) → 개시(2.2.2) → 발전+정규화(2.2.3) → 특수법칙(2.2.4) → 매트릭스: 탄소성(2.3.1) → 개시·발전(2.3.2) → 수치 안정화(2.4). 개시→발전→정규화의 표준 구조를 따르고, 전방 참조 없음(혼합법칙이 쓰는 A₁t·r₁t는 모두 선행 정의). 3·4장이 번호만 인용하는 OUTLINE §3 규칙과도 부합.

**기호 정의 점검** (과제 지정 항목 포함):
- g₀,I — (2.14)에서 정의·명명("개시 시점까지의 탄성 변형에너지 밀도") ✓
- l_c — (2.14)에서 CELENT로 정의 ✓ (OUTLINE §2.2 등재 ✓)
- I₁ — §2.3.2에서 σ̃₁₁+σ̃₂₂+σ̃₃₃로 명시 정의 ✓
- r_I 이력 최댓값 — (2.12)에서 max(1, max_τ φ)로 정의, 비가역성 언급 ✓
- d_F, r_L, r_E, p̄ — 본문 정의 ✓. 순환 정의 없음.
- **MAJOR-2: 섬유상 기호 미등재.** (2.1)–(2.6)의 입력 E_f1, E_f2, G_f12, G_f23, ν_f12, α_f1, α_f2가 OUTLINE §2 기호 사전에 없고, ch2는 "아래첨자 f는 섬유"라는 일반 규약과 "Zhang Table 1" 참조만 준다. 값이 본문 어디에도 없어 (2.1)–(2.6)→§2.1 수치 재현이 **논문 단독으로 불가능**(자기완결성 훼손). 조치: OUTLINE §2.1에 섬유상 행 추가 + T300 필라멘트 물성 표를 2장(또는 3장 물성표)에 수록하고 ch2에서 표 번호로 인용.
- 부속 MINOR (위 표의 MINOR-7): 열변형률 제거(*Expansion) 설명이 매트릭스 절(§2.3.1)에만 있으나 얀에도 적용됨 — §2.1/§2.2.1로 승격.

**논리 일관성 특기.** §2.2.4의 권장 시작값과 branch 해석 문장의 모순(MAJOR-1)이 유일한 실질 결함이다. 그 외 §2.3.2 말미의 물리 서사(냉각 손상 → 온도 상승 시 강도 증가)는 이론장 안의 결과 예고이지만 Zhang 인용이 붙어 있어 허용 범위. (2.20)에서 X_m,t=X_m,c=310으로 부호 분기가 실질 무효인 점은 형식상 문제 없음.

## 5. 트렌드 포지셔닝 문단 초안 (1장 말미 또는 2장 도입부용)

> 본 연구가 채택한 구성 모델 — 3차원 Hashin 손상 개시, Matzenmiller 계열 지수형 손상발전, 균열대 정규화, Duvaut–Lions 점성 안정화, 주기경계 RVE 균질화 — 는 2010년대에 정립된 메소스케일 연속체 손상역학의 표준 조합으로, 직조·편조 복합재 해석에서는 2024–2026년 문헌에서도 여전히 주류로 사용되고 있다. 다만 최근 연구동향은 두 방향의 고도화를 보인다. 첫째, 균열 경로와 섬유–매트릭스 계면 슬라이딩을 비국소적으로 포착하는 위상장(phase-field) 파괴 모델이 세라믹기 복합재에도 적용되기 시작하였고, 둘째, 계산 균질화와 기계학습을 결합한 데이터 기반 다중스케일 예측 프레임워크가 부상하고 있다. 그럼에도 본 연구는 Zhang (2022)이 보고한 열잔류응력–고온 인장 거동을 정량적으로 재현·검증하는 것을 일차 목표로 하므로, 원 논문이 사용한 Ge (2018) 모델을 수식 단위로 동일하게 채택하는 것이 검증 논리상 필수적이다. 즉 본 모델 선택은 최신성 경쟁이 아니라 재현성 요구에 의해 고정된 것이며, 동일 조합이 현재도 광범위하게 통용된다는 점에서 공학적으로도 유효하다. 한편 SiC 매트릭스의 von Mises 유사소성은 미세균열·계면 슬립에 기인한 비가역 변형의 현상학적 대체물이라는 한계를 가지므로, 위상장 정규화, 균열 개폐를 고려한 편측 손상, 기계학습 기반 보정으로의 확장을 후속 연구로 제시한다(5장).

코드(KMIX1T)와 동일한 구현으로 V2_0 카드 시작값 X_PO=700 MPa (=0.247X_t), r_F=3.0, K1=8000 MPa (=0.031E₁), G_f,1t=12.5 N/mm에서:

|---|---|---|---|
| 0.02 | 0.052 | 0.220 | 개시 순간 22% 응력 강하 |
| 0.05 | 0.135 | 0.237 | 개시 순간 24% 응력 강하 |
| 0.10 | 0.289 | 0.268 | 개시 순간 27% 응력 강하 |

- 개시 이후(r>1) 구간에서는 카드값에서도 d(r)가 매끄러움(스캔 최대 국소 증분 1.7×10⁻⁴). 즉 문제는 오직 **개시점의 불연속**이며, 이는 (b)안(서술 수정) 또는 (a)안(정합조건 부과) 중 하나로 해소된다.

## 부록 B. 균열대 폐형식 (2.14) 독립 유도 확인

연화 구간에서 σ(r) = X e^{A(1−r)} (r=ε/ε₀)이므로 단위부피 총 소산 g = g₀ + Xε₀∫₁^∞e^{A(1−r)}dr = g₀(1+2/A), g₀=X²/2E. 균열대 등가 G_f = g·l_c를 풀면 A = 2g₀l_c/(G_f−g₀l_c) — 식 (2.14) 및 KABAND와 일치. A>0 ⇔ **l_c < 2E_I G_f,I/X_I²** (요소 크기 제한; 1t 시작값 기준 l_c,max=2·254967·12.5/2835² ≈ 0.79 mm).
