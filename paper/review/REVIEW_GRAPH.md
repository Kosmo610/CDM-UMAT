# 이론 검증 리뷰 그래프 (반복 실행 프로토콜)

**목적:** 해석(Abaqus)을 최소화한다. 이론·참고문헌·입력값·논리의 결함을
해석 **전에** 전부 잡아서, 물성 오입력·논리 결함으로 해석을 다시 돌리는
일이 없게 한다. 이 문서는 리뷰 한 라운드의 절차 정의이며, 초안이 바뀔
때마다 재실행한다.

## 노드 구성

| 노드 | 역할 | 산출물 | 병렬성 |
|---|---|---|---|
| R1 참고문헌 감사 | 인용-출처 대조, PDF 실체 확인, 누락 문헌 제안, 서지 초안 | `R1_references.md` | R1–R4 동시 |
| R2 물성·입력 감사 | 카드 슬롯별 대조(논문표·원장·make_cards), 덱 설정, 단위계, **해석 전 GO/NO-GO** | `R2_properties.md` | 〃 |
| R3 수식 감사 | 수학적 건전성(차원·극한·연속성), 코드-논문 일치, 최신성 평가 | `R3_equations.md` | 〃 |
| R4 논리 감사 | 계약(OUTLINE) 준수, 장내 논증 사슬, 장간 연결, ch3/ch5 스펙 도출 | `R4_coherence.md` | 〃 |
| S 종합 | 교차 검토(소견 충돌 중재), 수정 반영, 미해결 이슈 등재 | `SYNTHESIS.md` + 초안 수정 커밋 | 단일 (fan-in) |

## 판정 규칙

- **BLOCKER** — 사실 오류·수치 불일치·논리 모순. 1건이라도 남아 있으면
  **Abaqus 실행 금지** (해석 최소화 게이트).
- **MAJOR** — 핵심 주장의 근거 누락, 산문 수치 오류. 다음 라운드 전 해결.
- **MINOR** — 표기·형식. 모아서 일괄 반영.

충돌 중재: 두 감사가 상반된 소견을 내면 S가 근거 소스(검증 리포트 >
논문 원문 > 일반 지식 순의 우선순위)로 판정하고, 판정 근거를
SYNTHESIS.md에 남긴다.

## 한 라운드의 흐름

```
초안 변경 → [R1 ∥ R2 ∥ R3 ∥ R4] → S 종합·수정 반영 → 커밋
                                        │
                          BLOCKER 잔존? ─ yes → 다음 라운드 (해당 감사만 재실행 가능)
                                        └ no  → R2의 GO 판정 시 Stage A 해석 승인
```

- 재실행 시 변경된 파일에 관련된 감사만 부분 재실행해도 된다
  (예: ch2만 수정 → R3·R4만).
- 각 감사 파일 상단 요약에 라운드 번호와 BLOCKER/MAJOR/MINOR 집계를 남긴다.
