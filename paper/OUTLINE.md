**구성 모델:** Ge et al., *Compos. Sci. Technol.* 157 (2018) 86–98 (Zhang (2022) 논문 내 참고문헌 [17]; 저장소 PDF 파일명의 개인 번호 [17]과는 무관)

### 장 간 인터페이스 (누가 무엇을 넘기는가)

- 1장 → 2장: 모델 채택의 정당화(연구동향 근거)는 **1장 §1.4의 소관**이다.
  2장은 채택 사실과 수식·한계만 진술하고 정당화 논리를 반복하지 않는다.
- 2장 → 3장: 식 번호 체계(아래 §3). 3장은 수식을 재기술하지 않고 번호로 인용한다.
- 4장 → 3장: 보정된 최종 파라미터 표는 4장이 아니라 **3장**에 싣는다.
  4장은 "어떻게 보정했는가(방법)"만, 3장은 "그 결과 값과 곡선"을 담당.
- 4장 ↔ 5장: 검증 한계의 **상세 논의는 4장 §4.6**이 소유하고, 5장은 요약 인용만 한다.
- 5장은 새로운 수치를 도입하지 않는다 (모든 수치는 3·4장에서 인용).

## 3. 식 번호 규칙

- 본 논문의 식 번호는 장별 일련번호 (예: 식 (2.5)).
- 원 논문 수식 인용 시: "Ge (2018) 식 (17)" / "Zhang (2022) 식 (11)" 형식으로 출처 명시.
- 2장이 식 번호의 단일 소유자. 3·4장은 2장의 번호만 인용.
- **4장은 (2.x)만 인용한다** (원 논문 번호는 괄호 병기만 허용). 검증 스크립트의
  **원문 출력 코드블록**은 원 논문 번호를 유지하되, (2.x) 대응 범례를 블록 직후에 둔다.
- 본문 인용은 번호제 [n] (Ceramics International 형식)을 따르며, 참고문헌 목록은
  `paper/references.md`가 정본이다. 서지 미확정(LIKELY) 항목은 "[n? DOI 확인 필요]"로 표기한다.

## 4. 수치 인용 규칙 (정직성)

- **검증된 값** (물성, Chamis 재현치)은 `VERIFICATION_REPORT.md` §2 수치를 그대로 인용.
- **보정 대상 값** (Yt, S, X_PO, SY0 등)은 반드시 "보정 시작값" 또는 "보정값"으로
  명시하고, 논문(Zhang/Ge)이 발표한 값처럼 기술하지 않는다.
- **보정 대상 파라미터(knob)의 공식 목록은 `calibration/ledger.json`의 params 키 집합**이다.
  장별 서술($X_t \cdot X_c$의 "유도 시작값·미세조정" 지위, $G_{f,m} \cdot A_m$ 포함 여부)은 이 목록에 맞춘다.
- Table 3 목표: 128.45 / 179.42 / 199.15 MPa (23/500/1000 °C, 논문 시뮬레이션).
  실험값 116.17±8.78 / 160.19±14.83 / 173.28±12.94는 참고 밴드로만.
  본문 수치 표기는 **1장 1회(동기)·4장 1회(목표 정의)로 제한**하고, 결과 비교는 3장이 전담한다.
- 해석 결과 수치는 `calibration/ledger.json`의 최종 채택 iteration에서만 가져온다.
- **시제 규칙:** 본문은 집필 시점의 도구·환경 상태를 서술하지 않는다
  (예: "해석기가 없으므로", "사용자 환경에서" 금지). 진행 상태는 시점 중립 문구로 쓰고,
  3장 확정 시 4장 §4.6의 범위 서술을 갱신한다.
