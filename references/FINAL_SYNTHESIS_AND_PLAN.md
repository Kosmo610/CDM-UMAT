## 0. 25편이 집단적으로 확정하는 것

1. **저장소 UMAT = Ge 2018(B01) + Zhang 2022(A05)의 충실한 구현** (2D plain-weave C/SiC). 무응력온도 **1050°C**(A05 PIP; C08은 CVI 1000°C — 공정별 상이). 기준선 검증표(Table3: 128/179/199 MPa, 오차 10–15%).
2. **통일 손상척도 `D = 1 − E/E₀`** — 약 7~8편 일치(Yang&Liu, Niu, A06, A11, C05, C06, KOR1, Xie). → 논문 전체 뼈대.
3. **계보의 미완과제 = 사이클 + 온도.** Ge 2018 결론이 명시. Zhang 2022가 온도(TRS) 채움. **KOR1(Zhang·Ge 2026)이 기계적 loading-unloading 사이클을 이미 채움** → **본 논문은 반드시 "열 사이클/열충격 + TRS + 열화맵"으로 차별화.**
4. **고온 강화 물리 = TRS 완화**: 냉각 시 매트릭스 잔류인장/야른 잔류압축 → 가열 시 매트릭스 압축전환(균일)·계면강화 → ~1000–1273K서 강도·강성 최고 후 감소(A05, A01, A04, C08 일치).

**계획에 미치는 영향**
1. **Step 0 재정의**: 기존 "V2 덱 재현"이 아니라 → **기둥 B(3D Zhang2022 RVE) 해석을 에러 없이 돌려 Table3 재현**이 Step 0의 실제 완료 조건. (기둥 A는 이미 완료 → 별도 Step 불필요, 이론·계수 자산으로 보유.)

## 1. 핵심 결정 — 사이클 열화 메커니즘 (Staged A→B)

네 가지 템플릿을 확보:
- **A03(Peng Zhang 2024)** — 단조 UMAT + 반복 열사이클, **N사이클 잔류응력→N+1 초기조건** 전달, 요소파손·응력재분배로 누적·포화. **불활성 검증**. → 저위험.
- **KOR1(Zhang·Ge 2026)** — 동일 RVC 기계 사이클, 언로드/리로드·잔류변형·언로드모듈러스. 검증됨. → 언로드/리로드 machinery.
- **B02(Chao Zhang 2018)** — 피로 PFDM + **사이클점프 Nj=10^(n/m)−10^((n-1)/m)** + 사이클당 잔류강성/강도(Shokrieh-Lessard). → 다사이클 계산효율.
- **Yang&Liu 2020** — 가법 `D = D_열충격 + D_피로`(모듈러스 저하 구동). → 열피로 개념 골격.

**결정: 단계적 A→B.**
- **경로 A(안전판, 우선)**: 기존 단조 UMAT + 반복 균일 열사이클(상태 전달, A03식). RVE 응력재분배로 강성·강도 저하 + 포화 재현. → 결과 보장.
- **경로 B(노벨티 핵심, 여유 시)**: 사이클당 **열피로 dD/dN 항**(Yang&Liu 가법구조, 열응력진폭 구동) + Niu C/SiC 언로드/리로드 + **cycle-jump(B02)**. → A03(피로법칙 無)·KOR1(기계뿐)과 차별.

> **왜 단계적인가**: A만으로도 A03이 (needled C/C-SiC서) 열화·포화를 냈으므로 plain-weave C/SiC + TRS로 결과 확보 가능. B가 진짜 모델 노벨티지만 계수 보정 리스크가 있어 A를 안전판으로.

## 2. 열하중 — 균일 사이클(주) + 과도 shock(대표 확장)
- **균일 온도장 사이클(주)**: A03이 소형 RVE서 구배 무시 정당함을 검증. 저장소 냉각스텝 + 반복 스텝루프.
- **과도 shock(대표 1~2케이스)**: **A07=A08(Yang 2024)** 프레임 — 1D 과도 열전달 + 열응력 + 계면박리 에너지방출률(G∝CTE²), 강제대류 HTC 경계. **coupled temp-displacement(A09)** 절차. 균일가정과의 차이 규명 자체가 기여.

## 8. 실행계획 (순서대로)

### Step 0 — 재현 2편 완료 (현재 진행 중, 크리티컬 패스)
- **기둥 A (2D 사이클 손상법칙 재현) — ✅ 완료**: Yang&Lu ox/ox CDM UMAT 코딩·실행, Fig10·Fig11 재현 성공. 사이클당 dD/dN 수식·계수를 자산으로 보유.
- **기둥 B (3D C/SiC RVE 재현) — 🔄 진행 중, 최우선**: TexGen RVE 추출 완료. `.ori` 배치, `abaqus … double`, ifort 확인 후 **CSIC_ZHANG2022 덱을 에러 없이 solve → Zhang2022 Table3 대조 + 실행시간 벤치**. **현재 해석 에러 디버깅이 즉시 현안**(로그 확보 시 원인 진단).

### Step 1 — TRS 추출·검증 (Week 1–3)
- 냉각(1050→23°C) **TRS 추출 스크립트 신규**(상별 잔류응력·초기손상). **A01 XRD(~125 MPa) 대조**.
- **온도의존 CTE(A04) 도입** → 온도무관 한계 극복.

### Step 2 — 사이클 덱 + 경로 A (Week 3–6)
