# Korean (ko) Humanize Rules

## AI tells

격식 종결의 단조로움
- "~입니다 / ~습니다 / ~할 수 있습니다 / ~하는 것이 중요합니다"가 거의 모든 문장의 끝.
- 한 글 안에서 종결어미 다양성이 2종 이하.

번역체 구문
- `~로부터`, `~에 대하여`, `~에 있어`, `~을 가지다`, `~에 의해`, `~을 통해`, `~함에도 불구하고`, `~하기 위해`, `위치하다`
- `~로 인하여`, `~에 다름 아니다`, `~을 요하다`

대명사 직역
- `그것은 / 그는 / 그녀는` — 한국어는 주어 생략이 자연스러움.

수동태 남발
- `~에 의해 ~되어진다`, `~로 알려져 있다`

소유격 '의' 남용
- `회사의 미래의 전략의 방향성`

복수 '~들'
- `학생들이, 사람들이, 것들이` — 한국어는 가산성 불표지가 기본.

진행형 직역
- `~하는 중이다` (영어 -ing 직역)

추상명사 스택
- `효율성, 중요성, 가능성, 필요성, 다양성, 지속성` 연속.
- `~적 N` 체인: `전략적 함의, 기술적 토대, 구조적 변화`가 한 글에 줄줄이.
- `~능력` 연쇄: `사고 능력, 추론 능력, 수행 능력` — 동사로 풀 수 있는데 명사구로 굳힘.

두루뭉술 hedging
- `일반적으로, 다양한, 여러 가지, 많은 경우, ~할 수도 있다`
- 안전 균형: `양쪽 모두 일리가 있다, 장점도 있지만, 신중하게 접근해야 한다, 균형 잡힌 시각` — 어느 쪽에도 서지 않음.
- 이중 완곡: `~할 가능성이 있을 수 있다, ~로 보여질 수 있다`
- 추측 종결 남발: `~로 보인다, ~로 판단된다, ~라고 여겨진다`가 문장마다.

AI 상투구 (발견 즉시 삭제·치환)
- 의의 과장: `시사하는 바가 크다, 주목할 만하다, 간과할 수 없다, 매우 중요하다`
- hype 어휘: `혁신적인, 획기적인, 전례 없는, 압도적인, 파격적인, 폭발적인, 대대적인`
- `~의 지평을 연다, ~의 새로운 장을 열다, ~시대가 도래했다, ~의 가능성을 열어준다`
- 열거 도입: `크게 세 가지로 나눌 수 있다, 다음과 같은 특징을 가진다`
- 결말 공식: `~해야 할 때입니다, ~로 나아갈 시점입니다, ~할 순간입니다`
- 변환 공식: `'X에서 Y로', 'X를 넘어 Y로'` — 전환·진화를 말할 때 자동으로 나오는 슬로건.
- 권고 결말 반복: 문단마다 `~해야 한다 / ~할 필요가 있다`로 끝남.

의인화·추상 주어
- 사건·기술·개념이 주어가 되어 인간 동사를 수행: `~의 등장은 ~을 보여준다`, `이 기술은 ~을 제공한다`, `두 지능의 충돌이 질문을 던진다`, `시대가 부른다`.
- 행위자(사람·팀·회사)를 주어로 되돌리거나 주어·동사를 없애고 직접 서술.

대구 반복
- `A인가, B인가` / `단순히 A가 아니라 B다` / `A라기보다 B다` 평행구가 한 글에서 여러 번. 사람이 거의 안 만드는 리듬 — 측정상 가장 강한 AI 신호 축.
- 문단 문두 `먼저 ~ / 반면 ~ / 결국 ~` 3단 공식.

쉼표 티
- 연결어미(-고/-며/-지만/-면서/-는데) 바로 뒤 쉼표: `발전하고 있지만, / 정제하고, / 낮아지면서,` — 연결어미가 이미 호흡을 만드는데 영어 쉼표 감각을 얹은 것. 단일 신호 중 가장 강함.
- 문장 절반 이상에 쉼표가 들어감 (사람 글은 다섯에 한둘).

형식명사 결산
- `~다는 뜻이다`, `~라는 것이다`, `핵심은 ~라는 점에 있다` — 결산 문장을 형식명사로 마무리.
- 앞 문장 받아치기: `이는 ~을 의미한다`, `이 점에서`, `이 관점에서 보면`, `이 말은`

리듬
- 장문 부재: 모든 문장이 30~50자 부근. 사람 글엔 100자 넘는 장문이 곳곳에 섞임.
- 단문 일변도: 단문만 줄줄이. 사람은 단문과 복문을 무의식적으로 섞어 호흡을 만듦.

관형절·조사
- 명사 앞 관형구 3중 중첩: `사고를 일으킨 화학물질을 생산한 회사에서 일했던 남자` — 핵심 명사에 닿기 전에 숨이 참.
- 이중 조사: `-에서의, -으로의, -에의, -으로부터의`

메타 문구
- 시작: "오늘날 급변하는 ~", "최근 ~이 주목받고 있다"
- 중간: "이는 ~이다", "즉, ~이다" ("즉" 남발 포함 — 한 글에 두 번 넘으면 티)
- 마무리: "결론적으로, 따라서, 요약하자면, 정리하자면, 종합하면, 이를 통해"

서식
- 모든 문단 같은 길이, 모든 문장 비슷한 구조.
- 불릿/번호 리스트 과다, "콜론: 설명" 패턴 반복, 숫자 괄호 인덱싱 `1) 2) 3)`.
- 콜론 부제 헤딩 반복: `## 서론: 제조업의 미래, AI에 달려있다`
- em-dash(—) 남용, 본문 볼드 남발, 개념어 따옴표('') 강조 남발, 이모지(✅🚀💡) 장식.

군더더기 (불필요한 표현)
- 접미사 '-적': `사회적 현상, 경제적 문제` — 빼도 뜻이 통하는 '-적'.
- 추상화 접미사 '-성': `효율성, 가능성, 중요성, 필요성` — 동사로 풀 수 있는데 명사로 굳힘.
- 조사 '-의' 연쇄: `문제의 해결의 방법`.
- 의존명사 '것': `~라는 것은 ~라는 것이다`, `~할 수 있다는 것`.
- 접미사 '-들': 문맥상 복수가 분명한데 붙은 '-들' (`우리들, 사건들`).
- 접속사 남발: 문장마다 `그러나 / 그리고 / 그러므로 / 그런데`.
- 지시대명사 남발: `이 / 그 / 저`, `이렇게 / 그렇게`.
- 형용사·부사 과다: `너무 / 아주 / 매우 / 정말` 등 빼도 되는 수식어.
- 중언부언: 한자어에 뜻이 이미 든 군더더기 (`전액 완납, 직접 대면, 지나치게 과다`), 서술어 반복 (`시작하도록 하겠습니다`).
- 군더더기 서술: `-있다`(덮여 있는→덮인), `-수 있다`(불필요한 가능·능력), `-가 되다`(논의가 된→논의된).
- `-한 상태·상황·모습이다`: `구름이 낀 상태를 보이고 있다`.
- `-것 같다 / 개인적으로`: 어차피 글은 다 글쓴이 생각.
- `-같은 경우`: 특정 대상 하나만 가리키는데 붙은 경우.
- 조사 겹침: `-로의, -에게로`.
- `-들 중 한 사람 / 하나`.
- 쉼표 남용: 한 문장에 쉼표 여러 개.
- 수식어-피수식어 거리: 꾸미는 말이 꾸밈 받는 말에서 멀리 떨어짐.
- 주술 불일치: 주어와 서술어가 호응 안 함, 문장이 길어 주어가 도중 실종.

## Human signals

종결어미 다양화
- `~거든요, ~잖아요, ~네요, ~더라고요, ~죠, ~ㄴ것같아요, ~게 되더라고요`
- 비격식: `~거든, ~잖아, ~더라, ~네, ~지, ~ㄴ듯`

격식 흔들기
- 해요체와 합쇼체 혼용 OK. 한 글 안에서 한두 번 톤이 풀려도 됨.

주어·조사 생략
- "나는 그것을 봤습니다" → "그거 봤어요" / "봤어"

괄호 부연
- "그 카페 갔는데 (사실 좀 별로였어요)"

구어 마커
- `근데, 사실, 솔직히, 막, 진짜, 좀, 약간, 그치만, 암튼, 어쨌든`

문장 마커
- `ㅋㅋ, ㅎㅎ, …, ~` (글의 톤이 캐주얼한 경우에만)

도치·끊김
- "이게 진짜 중요한 건데, 사람들이 잘 모름."
- 한 단어 문장 OK: "어렵죠." "맞아요."

화제화
- "그것은 X이다" → "X 말인데, ~" / "X은요, ~"

구체화
- 추상명사 → 동사로. "효율성을 높이다" → "더 빠르게 한다".
- 두루뭉술 hedging → 1인칭 추측 또는 구체적 수치.

## Rewrite rules

| Before (AI) | After (human) |
|---|---|
| ~할 수 있습니다 | ~할 수 있어요 / ~할 수도 있고 / ~하면 돼요 |
| ~하는 것이 중요합니다 | ~가 중요해요 / ~해야 해요 |
| ~하는 것이 좋습니다 | ~하면 좋아요 / ~하는 게 나아요 |
| 그것은 X이다 | X예요 (주어 생략) / X 말인데요, |
| A에 의해 운영된다 | A가 운영한다 / A가 굴린다 |
| ~에 대하여 / ~에 대한 | ~에 / ~ 관련 |
| ~에 있어 / ~에 있어서 | ~에서 / ~할 때 |
| ~로부터 | ~에서 / ~한테서 |
| ~을 통해 | ~로 / ~을 거쳐 |
| ~하기 위해 | ~하려고 / ~하느라 |
| ~함에도 불구하고 | ~인데도 / ~지만 |
| ~로 인하여 | ~ 때문에 / ~ 탓에 |
| 학생들이 / 사람들이 | 학생이 / 사람이 (맥락상 복수 분명할 때) |
| 회사의 미래의 전략 | 회사 미래 전략 / 회사가 앞으로 갈 방향 |
| 효율성을 높인다 | 더 빠르게 한다 / 시간이 덜 든다 |
| 가능성이 있다 | ~할 수도 있다 / ~할지도 모른다 |
| 비가 오는 중이다 | 비 와요 / 비 오고 있어요 |
| 결론적으로, ~이다 | (삭제하고 바로 결론 진술) |
| 따라서 ~이다 | 그래서 ~예요 / 그러니까 ~ |
| • 첫째 ... • 둘째 ... • 셋째 ... | "일단 ~. 그리고 ~. 마지막으로 ~." 산문화 |
| A — B (em-dash) | A. B / A (B) / A, 근데 B |
| 판단되어진다 (이중 피동) | 판단된다 / 판단한다 |
| 발전하고 있지만, ~ (연결어미 뒤 쉼표) | 쉼표 삭제. 호흡이 길면 마침표로 분리 |
| 단순히 A가 아니라 B다 (반복 시) | B다 / B가 핵심이다 (대구는 한 번만) |
| X의 등장은 ~을 보여준다 | 사람·회사 주어로: "X는 ~을 증명했다" |
| 시사하는 바가 크다 / 주목할 만하다 | (삭제) 또는 구체 결론으로 |
| 압도적인 / 파격적인 / 폭발적인 | 구체 수치·사실로 |
| ~해야 할 때입니다 / ~시점입니다 | 구체 동사 단언 (한 글에 한 번 이하) |
| 'X에서 Y로' 변환 공식 | 직접 단언: "이제 X는 ~다. Y가 ~한다" |
| ~다는 뜻이다 / ~라는 점에 있다 | ~다 (직접 종결) |
| ~해야 한다 (문단마다 반복) | 주체 명시 동사 / 조건문으로 변주 |
| 긴 관형구 중첩 | 문장 분리: "~를 만났는데, 그는 ~였다" |
| 2층에서의 살림 / 긴장으로부터의 해방 | 2층에서 꾸린 살림 / 긴장에서 벗어남 |
| 양쪽 모두 일리가 있다 | 한쪽 단언 또는 "X일 땐 A, Y일 땐 B" |
| 회의를 가졌다 | 회의를 했다 / 회의를 열었다 |

### 간결성 — 불필요한 표현 빼기 (격식·구어 공통)

위 표가 톤을 바꾸는 규칙이라면, 이 표는 군더더기를 덜어내는 규칙이다. 합쇼체를 유지하는 글에도 그대로 적용한다. 기계적으로 다 지우지 말고, **빼도 뜻이 그대로면 뺀다**.

| Before | After |
|---|---|
| 사회적 현상 / 경제적 문제 | 사회 현상 / 경제 문제 |
| 문제의 해결은 그다음의 일이다 | 문제 해결은 그다음 일이다 |
| 음악 취향의 형성 시기 | 음악 취향이 형성되는 시기 |
| 살아 있다는 것에 대한 증거 | 살아 있다는 증거 |
| 사랑한다는 것은 배려한다는 것이다 | 사랑이란 서로 배려하는 것이다 |
| 우리들 / 수많은 사건들 | 우리 / 수많은 사건 |
| 전액 완납 / 직접 대면하다 / 지나치게 과다하다 | 완납 / 대면하다 / 과다하다 (또는 지나치게 많다) |
| 시작하도록 하겠습니다 | 시작하겠습니다 |
| 옳은 주장이라고 할 것입니다 | 옳은 주장입니다 |
| 눈으로 덮여 있는 마을 | 눈으로 덮인 마을 |
| 작은 숲이 이어지고 있었다 | 작은 숲이 이어졌다 |
| 항상 깨끗한 상태에 있었다 | 항상 깨끗했다 |
| 1등이 될 수 있는 가능성 | 1등이 될 가능성 |
| 그제야 깨달을 수 있었던 것이다 | 그제야 깨달은 것이다 |
| 구름이 많이 낀 상태를 보이고 있다 | 구름이 많이 끼었다 |
| 생필품이 부족한 상황 속에서도 | 생필품이 부족한데도 |
| 중국 같은 경우는 향후 | 중국은 향후 |
| 낯선 세계로의 진입 | 낯선 세계로 진입 |
| 아버지에게로 갔다 | 아버지에게 갔다 |
| 독일 여자들 중 한 사람이었다 | 독일 여자였다 |
| 논의가 된 / 발견이 된 / 준비가 된 | 논의된 / 발견된 / 준비된 |
| 그 문제에 대해 나도 책임이 있다 | 그 문제에 나도 책임이 있다 |
| 꿈에 대한 이야기 | 꿈 이야기 |

판단으로 거르는 항목 (표로 못 박지 말 것):
- **접속사**: 문장이 자연스럽게 이어지면 `그러나 / 그리고 / 그러므로` 삭제. 흐름이 끊기면 남긴다.
- **형용사·부사**: 반드시 있어야 할 이유가 없으면 뺀다. 단, 사실·정보 전달이 핵심인 글은 예외.
- **지시대명사(이/그/저)**: 가리키는 대상이 분명하면 삭제. 한 문단에 여러 개 섞이면 글이 헤맨다.
- **'-것 같다', '개인적으로'**: 글은 어차피 글쓴이 생각. 추측·완곡이 꼭 필요할 때만.
- **능동형**: 수동(`~에 의해 ~된다`)을 능동으로. 행위 주체를 주어로 세운다.
- **주술 호응**: 한 문장 안에서 주어와 서술어가 맞는지 본다. 길어져 주어가 실종되면 문장을 끊는다.
- **수식어 거리**: 꾸미는 말은 꾸밈 받는 말 바로 앞에 둔다. 멀면 가까이 옮긴다.
- **쉼표**: 한 문장에 하나 정도. 열거·구별·호흡에 꼭 필요할 때만. 마침표로 끊는 게 나으면 끊는다.

마지막엔 소리 내어 읽어보고, 한 호흡에 안 읽히는 문장은 끊는다 (호흡 끊어 쓰기 → `_common.md`의 버스티니스).

#### Ctrl+F 점검 목록
- 적·의·것·들 (검토하며 걸러내기)
- -성 (효율성·가능성·중요성 → 동사로)
- 이·그·저 / 이렇게·그렇게
- 그러나·그리고·그러므로·그런데 (불필요한 접속사)
- 너무·아주·매우·정말 (불필요한 수식어)
- -있다 / -수 있다 / -가 되다·-이 되다
- -상태·상황·모습
- -것 같다 / 개인적-
- -같은 경우
- -로의 / -에게로 / -에서의 / -에의 (조사 겹침)
- -들 중
- -에 대해 / -에 대한 / -에 관한
- 고, / 지만, / 면서, / 는데, (연결어미 뒤 쉼표)
- 가 아니라 (대구 반복)
- 시사하 / 주목할 / 간과할 (의의 과장)
- 되어진 / 보여진 (이중 피동)
- 해야 한다 / 할 필요가 있다 (권고 결말 반복)
- 다는 뜻이다 / 라는 점에 (형식명사 결산)

## Examples

### Example 1 — 격식 설명문

Before:
> 인공지능 기술의 발전은 다양한 산업 분야에 있어 혁신을 가져오고 있습니다. 특히 자연어 처리 분야에서는 그 활용 가능성이 무궁무진하다고 할 수 있습니다. 이는 효율성의 증대와 비용 절감이라는 측면에서 매우 중요한 의미를 가집니다.

After:
> AI 기술이 발전하면서 산업 곳곳이 바뀌고 있어요. 자연어 처리는 특히 쓸 데가 많죠. 일을 더 빠르게 하고 돈도 덜 들게 해주거든요.

### Example 2 — 번역체 가득

Before:
> 그것은 학습자들로 하여금 자기주도적인 학습을 가능하게 하는 도구로서 활용될 수 있다. 이러한 접근은 교육의 효과성에 있어 긍정적인 영향을 미친다.

After:
> 학습자가 알아서 공부할 수 있게 도와주는 도구로 쓸 만해요. 이렇게 하면 교육 효과가 확실히 좋아져요.

### Example 3 — 불릿 산문화

Before:
> 다음과 같은 장점이 있습니다:
> • 첫째, 시간을 절약할 수 있습니다.
> • 둘째, 비용이 감소합니다.
> • 셋째, 정확도가 향상됩니다.

After:
> 장점 몇 가지 있는데요. 일단 시간이 줄어요. 돈도 덜 들고, 정확도까지 올라가요.

### Example 4 — 군더더기 빼기 (격식 유지)

톤을 캐주얼하게 바꾸지 않고 합쇼체를 유지하되, 불필요한 표현만 덜어낸 경우.

Before:
> 이번 프로젝트의 성공적인 완수를 위해서는 팀원들 간의 원활한 소통이 매우 중요하다고 할 수 있을 것입니다. 그리고 각자의 역할에 대한 명확한 이해 또한 반드시 필요한 부분이라고 생각됩니다.

After:
> 이번 프로젝트를 잘 마치려면 팀원 간 소통이 중요합니다. 각자 맡은 역할을 분명히 이해하는 일도 꼭 필요합니다.

### Example 5 — 상투구·대구·쉼표 티

Before:
> 이번 발표가 시사하는 바는 큽니다. AI 경쟁은 단순히 속도의 문제가 아니라 방향의 문제입니다. 기술이 빠르게 발전하고 있지만, 기업의 대응은 더딥니다. 이제 '추격'에서 '선도'로 나아가야 할 시점입니다.

After:
> 이번 발표에서 볼 대목은 방향입니다. AI 경쟁은 속도보다 방향 싸움이에요. 기술은 빠르게 발전하는데 기업 대응은 더디죠. 이제는 추격 말고 선도를 준비할 차례입니다.

## 주의사항

- 공식 문서, 법률·계약서, 학술 논문은 합쇼체 유지. humanize 전에 사용자 의도 확인.
- 비속어·은어는 원문 톤이 그쪽이 아니라면 넣지 말 것.
- ㅋㅋ/ㅎㅎ는 원문이 명백히 캐주얼할 때만.
- 의견·일화 임의 추가 금지 — 원문이 함의하지 않는 내용 만들지 않기.
- 간결성 규칙(`### 간결성`)은 톤과 무관하다. 합쇼체를 유지하는 글에도 군더더기는 뺀다.
- 단, **빼도 뜻이 그대로일 때만** 뺀다. 적·의·것·들·접속사·부사를 강박적으로 다 지우면 오히려 어색해진다. 사실·정보 전달이 핵심인 글은 수식어를 남겨도 된다.
- 사람도 흔히 쓰는 표현을 AI 티로 오인하지 말 것. `첫째/둘째` 열거, `~것이다` 종결, `~를 통해` 한두 번은 자연스러운 한국어다. 한 글에서 반복되어 기계적으로 읽힐 때만 손댄다. 열거는 기본 보존 — 한 문단에 4개 이상 메트로놈처럼 이어질 때만 일부를 산문화.
- 원문에 이미 있던 대시, 감탄, 반문, 구어 표현은 사람 손의 증거 — 지우지 말고 보존.
- 학술 논문·보고서의 실제 절 제목(번호 절, 장 제목)은 문서 구조다. 제거·개작·본문 흡수 금지. 헤딩 정리는 칼럼·에세이의 장식 헤딩에만.
- 윤문하면서 위 상투구(`시사하는 바가 크다` 류)를 새로 넣지 말 것. 치환은 티를 빼는 방향으로만.
- 원문보다 격식을 올리지 말 것 — `-했-`을 `-하였-`으로 바꾸는 식의 역주행 금지. `~인데요 / ~거든요` 같은 구어 종결은 보존.
