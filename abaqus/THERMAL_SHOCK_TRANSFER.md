# RVE → 열충격 시편으로 넘기는 방법

검증된 RVE(주기경계조건 + ZHANG2022 손상 UMAT)를 열충격 시편 해석으로 어떻게
연결할지에 대한 설계안. 아직 실행 전 단계이며, **막는 입력이 하나 있다(구성재 열물성)**.
그것을 포함해 필요한 것과 위험요소를 명시한다.

---

## 1. 무엇을 예측하려는가

열충격 시험(고온 유지 → 급랭, 또는 한쪽 면 화염/레이저 가열)에서 알고 싶은 것:

- 과도 열구배가 만드는 **거시 응력/변형률 이력**
- 그 이력 아래에서 **직물 내부의 어느 상이 언제 깨지는가**
  (매트릭스 균열 먼저 → 얀 횡방향 → 얀 종방향, 논문이 냉각 시퀀스에서 보고한 순서)
- 사이클 후 **잔류 강도** 예측으로 넘어갈 수 있는 상태량

즉 거시(시편)와 메소(직물) 둘 다 필요하다. 어느 한쪽만으로는 답이 안 나온다.

## 2. 왜 RVE를 시편에 그냥 못 넣는가

| | RVE | 열충격 시편(예: 50 × 10 × 3 mm) |
|---|---|---|
| 부피 | 5.39 mm³ | ≈ 1,500 mm³ (≈ 280 배) |
| 요소 | 174,405 C3D4 | 같은 해상도면 **≈ 4,800만** 요소 |
| 재료 | UMAT, SDV 20/16개, 비선형 | 동일 |

같은 메쉬 밀도로 시편을 채우는 것은 불가능하다. 그래서 **스케일을 분리**해야 한다.

## 3. 세 가지 경로

| | 방식 | 비용 | 무엇을 잃는가 | 판단 |
|---|---|---|---|---|
| **A** | 균질화 물성 + 거시 CDM | 낮음 | 메소 손상 순서. 거시 CDM을 **새로 보정**해야 함 — ZHANG2022 UMAT은 얀/매트릭스용이라 그대로 못 씀 | 선형 예비검토용 |
| **B** | 단방향: 거시 해석 → 핫스팟 이력 → RVE 재생 | 중간 | 손상의 거시 되먹임(1차) | **추천** |
| **C** | FE² (모든 적분점마다 RVE) | 불가 | — | 제외 |

**B를 추천하는 이유**: 지금 있는 것을 그대로 쓴다. RVE의 여섯 개 ConstraintsDriver DOF가
**정확히 거시 변형률 6성분**이므로, 거시 해석이 뱉은 ε(t)를 그 DOF에 물리면 그게 곧
"큰 물체 안의 한 재료점이 겪는 경계조건"이다. 새로 만들 구속이 없고,
`check_pbc.py`와 패치 테스트로 검증한 구속 집합을 **그대로** 재사용한다.

`abaqus/make_history_driven_rve.py`가 이 재생 덱을 만든다 (§6.5).

## 4. 필요한 입력 — 있는 것 / 없는 것

### 이미 있는 것

| 항목 | 값 | 출처 |
|---|---|---|
| RVE 격자 | 3.5 × 3.5 × 0.44 mm, V = 5.390000 mm³ | `check_pbc.py` |
| 상 분율 | 얀 50.51 %, 매트릭스 49.49 % | `check_pbc.py` (tet 부피 적분) |
| 전체 섬유 Vf | **0.4000** (= 0.5051 × 0.792) | 논문 Vf ≈ 40 %와 일치 |
| 균질화 탄성 C(6×6) | 2단계 실행하면 나옴 | `extract_stiffness.py` |
| 균질화 CTE α | 같이 나옴 (LC7) | `extract_stiffness.py` |
| 메소 손상 모델 | ZHANG2022 UMAT | `src/` |

> C와 α는 이 모델에서 **온도 비의존**이다(매트릭스 E = 350 GPa, α = 4.5e-6 /K 고정,
> 얀도 고정). 온도에 따라 달라지는 것은 잔류응력 상태와 그로 인한 손상뿐이므로,
> 균질화 탄성 카드는 **한 세트면 충분**하다. 이건 이 논문 모델에 한정된 편의다.

### 없는 것 — 이게 현재 병목

열해석을 하려면 **구성재 열물성**이 필요한데 ZHANG2022는 역학 논문이라 주지 않는다.

| 필요 | 왜 | 어디서 |
|---|---|---|
| SiC 매트릭스 k(T), c(T), ρ | 열전도 균질화 | 문헌 / 실측 (CVI SiC는 공정 의존이 큼) |
| T300 섬유 k∥, k⊥ (T) | 얀은 **열적으로 강한 이방성** — 축방향이 횡방향의 수 배 | 문헌 |
| 표면 열전달 조건 | 급랭이면 h와 싱크온도, 화염이면 표면 열유속 | 시험 조건 |

섬유의 열이방성 때문에 직물의 **면내 전도 ≫ 두께방향 전도**가 되고, 이게 열충격
구배를 지배한다. 등방으로 뭉개면 안 된다.

## 5. 빠진 조각을 채우는 법 — 주기 열전도 균질화

역학 PBC와 **구조가 같다**. 온도 자유도(DOF 11)에 대해 같은 짓을 한다.

- 요소: C3D4 → **DC3D4**
- 재료: `*Conductivity`(얀은 `type=ORTHO`), `*Density`, `*Specific Heat`
- 주기성: 거시 온도구배 **G**에 대해 `T(x + L) − T(x) = G · L`.
  오프셋 **d**인 면 쌍 하나당 방정식 **하나**(역학은 셋이었다):

  ```
  *Equation
  4
  FaceA, 11, 1.0, FaceB, 11, -1.0, GradDriverX, 11, -d_x
  ```
  (0인 항은 생략. 모서리/꼭짓점도 같은 규칙, d만 바뀜)
- 드라이버 **3개**(G_x, G_y, G_z), 절점 하나의 온도를 고정해 상수 자유도 제거
- 하중 케이스 3개: G = (1,0,0), (0,1,0), (0,0,1) [°C/mm], `*Heat Transfer, steady state`
- 추출: `HFL`의 부피평균 q̄ 로부터 **k_ij = −q̄_i / G_j**
- 열용량: 혼합법칙 `(ρc)_hom = Σ f_i ρ_i c_i` (§4의 부피분율 사용)

검증은 역학과 똑같이 **패치 테스트**로 한다. 균질 등방 전도체를 넣으면 온도장이
선형(구배 균일)이고 k_hom이 입력 k와 같아야 한다.

> 이 생성기는 **아직 만들지 않았다.** 위 레시피는 정확하지만, Abaqus로 확인하지 않은
> 코드를 검증된 것처럼 얹지 않기 위해 의도적으로 미구현으로 둔다. 열물성 숫자가
> 확보되는 시점에 `make_pbc_check.py`와 같은 골격으로 작성하는 게 순서다.

## 6. 실행 절차 (경로 B)

### 6.1 RVE 균질화 (선행 — 지금 바로 가능)

```bash
python3 abaqus/make_pbc_check.py abaqus/ZHANG2022_RT23_V1_0.inp
abaqus job=PBC_PATCH   input=PBC_PATCH.inp   double interactive
abaqus python postprocess/extract_stiffness.py PBC_PATCH.odb --patch      # 반드시 통과
abaqus job=PBC_ELASTIC input=PBC_ELASTIC.inp double interactive
abaqus python postprocess/extract_stiffness.py PBC_ELASTIC.odb
# -> PBC_ELASTIC_constants.csv : E1..G23, alpha_x/y/z
```

### 6.2 열물성 확보 + 열전도 균질화

§4·§5. 여기서 k_hom(직교이방성 3성분)과 (ρc)_hom을 얻는다.

### 6.3 시편 과도 열해석

- 요소 DC3D8(또는 DC3D4), 시편 실제 형상
- `*Conductivity, type=ORTHO` = k_hom, `*Density`, `*Specific Heat` = (ρc)_hom
- 경계조건: 급랭이면 `*Sfilm`(h, 싱크온도), 화염/레이저면 `*Dsflux`
- `*Heat Transfer` 과도 해석 → **온도장 ODB**

### 6.4 시편 열응력 해석 (순차 결합)

- **같은 메쉬**, 요소 C3D8
- 재료: `*Elastic, type=ENGINEERING CONSTANTS` = 6.1의 균질화 상수,
  `*Expansion, type=ORTHO, zero=1050.` = 균질화 α
- `*Temperature, file=<열해석 ODB>` 로 온도 이력을 읽어옴
- 출력: 전 시간에 걸친 **총 거시 변형률 E**와 온도

> **stress-free 온도 1050 °C를 양쪽에서 똑같이 쓸 것.** 그래야 거시 해석이 출력하는
> 총 변형률이 이미 열수축분을 포함하게 되고, RVE가 그걸 자기 힘으로 재현한다.
> 어긋나면 제조 잔류응력이 **두 번** 계산된다.

### 6.5 핫스팟에서 RVE 재생

거시 결과에서 위험 지점 2~4곳을 고르고(최대 주변형률, 최대 |ε|, 구배 최대 지점),
그 지점의 이력을 CSV로 뽑는다:

```
time,exx,eyy,ezz,gxy,gxz,gyz,T
0.0,   0.0009, 0.000765, 0.00126, 0.000108, 0, 0, 1200.0
0.5,  -0.00066,-0.00056, -0.00093,-0.000079, 0, 0,  939.6
...
```

```bash
python3 abaqus/make_history_driven_rve.py abaqus/ZHANG2022_RT23_V2_0.inp \
        hotspot_history.csv --out RVE_hotspot.inp
python3 verification/check_pbc.py RVE_hotspot.inp        # 구속 재확인
abaqus job=RVE_hotspot input=RVE_hotspot.inp \
       user=src/UMAT_CSIC_RVE_ZHANG2022_V1_0.for double interactive
```

생성되는 해석:

- **Step 1 Precondition** — 1050 °C → T(0), 거시 변형률 0 → ε(0).
  진짜 무응력 상태에서 출발하므로 **제조 잔류응력이 들어오는 길에 자연히 쌓인다.**
- **Step 2 Coupon_history** — 여섯 드라이버가 각자의 `*Amplitude`를, 온도가 또 하나의
  amplitude를 따라간다.

읽을 것: SDV로 `DMT`(매트릭스 인장손상), `DYTT`(얀 횡방향), `DY1T`(얀 종방향),
그리고 `TMINIT`/`TYINIT`(각 상의 손상 개시 온도).

### 6.6 인계 정합성 확인 (꼭 할 것)

손상을 **끈 상태**로 6.5를 한 번 돌려서, RVE가 돌려주는 거시응력이 거시 해석이
그 지점에서 예측한 응력과 일치하는지 본다(선형 영역이므로 일치해야 한다).
일치하면 인계가 정합적이라는 뜻이고, 그 다음 손상을 켰을 때 생기는 차이가 **정확히
메소 손상의 효과**다. 이 확인 없이 손상 결과를 해석하면 인계 오류와 물리를 구분할 수 없다.

## 7. 위험요소 — 미리 알고 갈 것

### 7.1 열경계층 vs RVE 두께 (스케일 분리)

C/SiC 열확산도 α ≈ 10 mm²/s 정도로 잡으면 침투깊이 δ ≈ √(αt):

| t | δ | RVE 두께(0.44 mm) 대비 |
|---|---|---|
| 1 ms | 0.10 mm | **0.23배 — 균질화 불가** |
| 20 ms | 0.44 mm | 1배 — 경계선 |
| 0.1 s | 1.0 mm | 2.3배 |
| 1 s | 3.2 mm | 7배 — 안전 |

즉 **급랭 초기 수십 ms는 1차 균질화의 가정이 깨진다.** 그 구간의 표면 응력은
정량적으로 믿지 말고, 경향 판단에만 쓰거나 별도 처리(표면층을 메소로 직접 모델링)가 필요하다.
위 α는 가정값이므로 §4의 실제 열물성이 나오면 이 표를 다시 계산할 것.

### 7.2 자유표면 문제 (가장 신경 쓸 부분)

열충격 손상은 **표면에서 시작**한다. 그런데 주기경계조건은 **내부 재료점**에 대한
경계조건이다. 표면 셀은 위쪽이 traction-free이지 주기적이지 않다.

대응: (a) 표면에서 한 셀 이상 안쪽 지점을 심문지점으로 쓰고, (b) 표면 거동이 중요하면
윗면을 자유면으로 둔 **표면 전용 RVE**를 따로 만들어 비교한다(z 방향 주기성만 해제).
지금 구조에서는 FaceE/FaceF 관련 방정식만 빼면 되므로 어렵지 않다.

### 7.3 단방향 결합의 한계

RVE가 크게 손상되면 실제 강성이 떨어져 거시 응력이 재분배되는데, 거시 해석은
탄성으로 남아 있으므로 **응력을 과대평가**한다. 대응: 손상된 RVE에서 열화된 균질화
카드를 다시 뽑아 거시 해석을 재실행하는 1회 반복(2-패스). 손상이 가벼우면 불필요하다.

### 7.4 그 외

- **두께방향 셀 수**: 3 mm 시편이면 두께에 셀이 ~7개뿐이다. 구배가 가장 가파른
  방향이라 스케일 분리가 아슬아슬하다.
- **C3D4 과강성**: 절대값 비교 시 감안. EasyPBC 비교는 같은 메쉬라 상쇄된다.
- **미보정 파라미터**: 얀 횡/전단 강도, Eq.18 파라미터 등은 아직 보정 전이다
  (`verification/CALIBRATION_GUIDE.md`). 열충격 결과의 절대값은 그 보정 이후에 의미를 갖는다.

## 8. 정리 — 지금 할 수 있는 것 / 막힌 것

**바로 가능**
1. PBC 검증 3단계 (`PBC_VALIDATION_GUIDE.md`) — 정적 감사는 이미 6개 덱 전부 통과
2. 균질화 C, α 추출
3. EasyPBC 교차검증
4. 임의의 거시 이력으로 RVE 재생 (`make_history_driven_rve.py`)

**막힌 것 — 구성재 열물성(k, c, ρ) 확보가 선행 조건**
5. 열전도 균질화 (레시피는 §5에 확정)
6. 시편 과도 열해석 → 열응력 해석 → 핫스팟 추출

그래서 다음 액션은 **문헌/실측으로 SiC 매트릭스와 T300 섬유의 열물성을 확보하는 것**이고,
그 전까지는 1~4를 끝내 두면 열물성이 들어오는 즉시 5~6으로 바로 넘어갈 수 있다.
